# 段考专题讲义 · 定稿模板（一册一份 JSON）

适用：`本地化/内容/段考-<年级学期>-<节点>.定稿.json`，例如 `段考-高一下-期中.定稿.json`。
共 16 册：高一上 / 高一下 / 高二上 / 高二下 × 期中前月考 / 期中 / 期中后月考 / 期末。

## 0. 生产顺序

1. 选题：`python3 -I 本地化/脚本/段考选题.py <年级学期> <节点>`（不带参数跑全部 16 个），得到 `段考-<年级学期>-<节点>.候选.json`。
2. 读候选：每个讲的专题（`讲` 为 true）看 `候选` 的 本节点 / 借用 / 合计，看 `子类`（考法）的题数，看每题的 `考查句`、`子类`、`疑似缺陷`。
3. 写定稿 JSON（照本文件的结构）。
4. 自检：
   ```bash
   python3 -I 本地化/脚本/定稿校验.py                 # 题干与出处能否在题库里唯一定位；必须「问题：无」
   python3 -I 本地化/脚本/段考排版.py <年级学期> <节点>  # 结构校验 + 排版；校验失败会列出错误并退出
   ```
   渲染后再跑 `指标.py`、`孤标题检查.py`、`pdffonts`（见 HANDOFF §3）。
5. 所有者验收前不得算完成。

下文规则以 `规范/05-所有者修改原则.md` 为准，其次是 `段考排版.py` 的 docstring，最后是 `段考-写作要求.md`。两者冲突处见 §7。

## 1. 册头与顶层字段

| 字段 | 含义 | 规则 |
|---|---|---|
| `data_no` | 册号，两位数字 | **推导值**，须等于 `节点.book_no(年级学期, 节点)`。全年连续：高一上 01–04、高一下 05–08、高二上 09–12、高二下 13–16；每学期内顺序为 期中前月考、期中、期中后月考、期末。写错排版会报错。 |
| `unit_book` | 册头 kicker | **推导值**，须为 `段考专题　<年级学期>`（中间是全角空格 U+3000）。 |
| `h2` | 册头标题 | 必须等于节点名，如 `期中后月考`。 |
| `stats` | 册头统计 | 校验要求 3 项，格式 `{"b": "12", "post": "套试卷"}`。**排版不输出**；05 §2.2 规定册头不放统计，页面上不会出现。 |
| `overview` | 考情总览 | 见 §2。 |
| `topics` | 讲的专题 | 见 §3。 |

册头的显示：kicker「段考专题　高一下」，页脚面包屑 data-unit「高一下期中」，标题「期中」。

## 2. 考情总览 `overview`

```json
"overview": {
  "title": "考情总览",
  "chip": "2020–2025 · 东莞真题",
  "lead": "（排版不输出，可留空）",
  "rows": [
    {"name": "非谓语", "cov": 1.0, "n": 67, "book": "（排版不输出）", "ahead": false,
     "go": "专题 1", "skip": false}
  ],
  "after": "表后一句，只写考情事实。"
}
```

- `title` 固定写「考情总览」。
- `chip`：年份范围（本节点卷的年份最小–最大，格式同现有定稿）+ ` · 东莞真题`。排版把 · 换成空格。
- `rows`：行顺序 = 讲的专题在前（按 `topics` 编号），不讲的在后。每行：
  - `name`：与 `topics[].name` 逐字相同（校验要求）。
  - `cov`：覆盖率 0–1，取 `段考专题.json` 的 覆盖率（候选 JSON 的 `覆盖率`）。格数 = round(cov × 10)。
  - `n`：题数，取 候选 的 `题数`（关键词题数）。
  - `go`：讲的写 `专题 n`；不讲的写去向（现有定稿用 `期中册` 这类写法），只写去向，不写理由（05 §1.1）。
  - `skip`：不讲的为 true，排版给整行加 `skip` 样式。
  - `book` / `ahead` / `lead`：排版不输出。05 §2.2 规定段考不放教材进度，可以不填。
- `after`：表后一句，可省略。

## 3. 专题 `topics`

```json
{
  "no": 1,
  "name": "非谓语",
  "vols": 20, "cov": 20, "n": 82,
  "explain": [ ...讲解块... ],
  "examples": [ ...例题... ],
  "keypoint": "要点，一到两句；没有则写空字符串。",
  "drill": [ ...练一练... ]
}
```

- `no`：从 1 起，严格递增，与候选的 `编号` 一致；按覆盖率降序，并列按题数，再按 TOPICS 顺序。
- `name`：TOPICS 名。讲义短称允许用「it 形式主宾语」代替候选的「it 形式主语／宾语」，但 `overview.rows[].name` 要写同样的名字。
- `vols`：本节点卷数（候选 `卷数`）。`cov`：覆盖卷数（候选专题的 `覆盖卷`）。`n`：题数（候选 `题数`）。芯片显示「覆盖 cov/vols 卷，n 道」。`cov` 不能大于 `vols`。

### 3.1 讲解块 `explain`

每一块是一个对象，按顺序输出。

| `type` | 排版输出 | 规则 |
|---|---|---|
| `subhead` | 小标题，排成药丸 | 每个小标题开一个**组**（`.group`），直到下一个小标题为止。小标题是考法名，不超过 6 个汉字；英文结构加「型」字，如「recommend 型」。 |
| `gloss` | 药丸右侧的柱注 | 最多 2 行，每行不超过 10 个汉字。英式版式把两行用「；」接成一行。只写触发信号或判断提示，如「介词后接 doing」「主语是物用被动」，**不写题数**（规范/05）。 |
| `p` | 正文段，悬挂主色小方块 | 一段一条要点，不首行缩进。每段不超过 4 行。直说规则和判断步骤。 |
| `pattern` | 英文句型，STIX | 一个专题最多一行。 |
| `note` | 「注」 | 最多 2 行，英式版式把两行用空格接成一行。 |

写法要求（05 §1、§3）：
- 只讲东莞这一站真考的出题样式；说明用平实的知识陈述，不写操作指令。
- 不写编辑说明：禁止「不单列」「本册不讲」「见同步讲义」「同上」「各 N 题，一句带过」「段考里几乎只考这一种」。考得少但值得讲的点，直接写成知识。
- 不用：「先看……再……」「抓住」「记住」「其实」「关键是」「核心」「本质」「一眼看出」、破折号、感叹号、反问句、为对仗硬凑的「不是……而是……」「既……又……」。
- 规则必须对。拿不准的说法宁可不写。

### 3.2 例题 `examples`

```json
{
  "group": "作主语",
  "gloss": ["主语位置", "→ 用 -ing 或不定式"],
  "stem": {"text": "___ (learn) English well is not easy.", "cue": [],
           "src": "2024 · 东莞市 · 高一上月考"},
  "ju": "学好英语并不容易。",
  "mid": {"label": "成分", "text": "句首作主语，用动名词。"},
  "ans": "Learning"
}
```

- `group`：指向讲解块的小标题文字。排版会把这道例题放在该组之后（讲一块练一块，05 §3.1）。没有 `group` 的例题排在所有讲解块之后。
- `gloss`：例题柱注，最多 2 行。
- `stem.text`：题干，原题文字（见 §5）。`stem.cue`：括号内的改写或翻译指令列表，如 `["用宾语从句改写"]`。`stem.src`：出处，用候选 `标签` 原样（见 §5）。
- `ju`：句意，一句中文。
- `mid.label`：只能是「成分」或「判断」。`mid.text`：一到两句，说空格是什么成分、凭什么信号判断。依据候选的 解析 改写，不照抄长段。
- `ans`：故填，必填。多解用「/」，可省略的部分用括号，如 `(should) take`。`ans` 不少于 6 个词时，排版自动用整句答案版式。

例题数量（05 §3.1）：
- **热门考法**（本节点该考法 ≥ 3 题）：讲解块 + 1–2 道例题。
- **冷门考法**（1–2 题）：也要有一个简短讲解块，讲清判断方法；**不设例题**，题全部进练一练。
- 「考法」指候选 `子类` 下的一类（或讲解块对应的一类），不是整个专题。

### 3.3 练一练 `drill`

```json
{"level": "必练", "stem": "Some of the students ___ (give) prizes yesterday.",
 "cue": [], "src": "2023 · 东莞外国语学校 · 高一上月考",
 "ans": "were given", "why": "被动，过去时", "long": false}
```

- `stem`：题干（不含 cue），`cue`：改写或翻译指令列表，排在句末。`src`：出处，放在题干段首（排版处理）。
- `ans`：答案，必填。`why`：可空，一句理由，不超过 20 字。
- `level`：`必练` 或 `选练`。缺省为必练。
- `long`：可省略。答案不少于 6 个词时自动为 true。

**分级（05 §3.1）：**
- 每个考法（候选 `子类`）题数 ≤ 10：该考法的题全部标为**必练**。
- 每个考法题数 > 10：挑 10 道必练。挑法：覆盖该考法不同的判断点，题目典型，同等条件下选新的，不与例题重复。其余标为**选练**。
- 必练是「练了就够学会通法」，选练是「想多练题量」。
- 冷门考法（1–2 题）的题全部必练。

**练一练的范围：** 候选中除例题以外的原题，原则上全部进练一练（05 §3.1「其余原题全部进练一练」）。`疑似缺陷` 为 true 的题不用；要用须先人工核对题干。

**排序：**
- 排版按 `level` 稳定排序，必练在前、选练在后；**同一级内的顺序以 JSON 为准**。
- 同一级内按年份从新到旧排（05 §3.1）。写 JSON 时按 `src` 里的年份倒序排，排版不重排年份。
- 练一练题号全册连续，由排版分配，不要在 JSON 里写题号。

排版输出：`<h4>练一练</h4>`。有选练的专题，必练与选练之间有分段小标签。答案区按专题分组，每组一个 `<ol class="key">`。

## 4. 行内标记

题干与说明文字都支持下列标记（排版时先转义，再替换）：

| 写法 | 显示 |
|---|---|
| `**词**` | 粗体 |
| `[[词]]` | 结构词（em-atom，主色） |
| `[_词_]` | 划线（强调句类题的划线部分，题库无划线信息，按答案标出） |
| `___` | 空位 |

- 题干中的换行（改写题的原句与待填句之间）显示为「 → 」，写成真实换行即可。
- 题干中的括号提示保留在 `text` 里，如 `(take)`；只有指令类括号才进 `cue`（见 §5）。

## 5. 题干、出处、答案的来源

- **题干用题库原文。** 只用候选里的东莞原题，不编题，不改题意。可以修明显的 OCR 错字和多余空格，不补词。
- **出处用候选 `标签` 原样**，格式为 `年份 · 学校 · 考试`，如 `2024 · 东莞市 · 高一上月考`。排版显示为「2024 东莞市高一上月考」（年份后空一格，校名与考试连写），数据里保留 ` · `。学校名用本名（题库已按 SCHOOL_CANON 处理）。
- **借用题**照写它自己的标签，不另加说明。
- **题库答案有错**：原题不改，答案页印改正写法，说明里写清改了什么。
- **答案**以候选 `答案` 为依据。候选答案里用 `|` 分隔的多解，写成 `/`，可省部分用括号。`定稿校验.py` 不比对答案，答案要人工核对。

## 6. 候选 JSON 怎么读

`段考-<年级学期>-<节点>.候选.json`：
- 顶层：`册`、`年级学期`、`节点`、`讲义专题来源`（手定，或默认规则）、`卷数`、`推定卷数`、`统计`。
- `专题[]`：每个专题一条。`讲` 为 true 的才写进定稿。`候选` = `本节点`（本节点的题）+ `借用`（从互补节点补的题）= `合计`。`子类`：每个考法的题数和题号。`题[]`：候选题。
- 每题：`id`、`标签`（出处）、`题型`、`题干`（已去掉指令括号）、`cue`、`答案`、`解析`、`句意`、`主考点`、`主考点来源`、`其他命中`、`考查句`、`子类`、`子类依据`、`借用节点`（若有）、`疑似缺陷` / `缺陷原因`。
- `讲义专题来源` 为「默认」的节点，讲的专题要先经负责人确认。
- 候选 `不足 8 题` 的讲专题，写定稿前先问负责人是保留还是去掉。

## 7. 已知冲突（以 05 为准，待负责人确认）

1. **练一练数量**：`段考-写作要求.md` 写「练一练每专题 4–8 道」；05 §3.1 写「其余原题全部进练一练」。本模板按 05。现有两册定稿的练一练数量也接近 05，但仍少于候选池（如期中 非谓语 候选 67，练一练 35，例题 5），生产时要核对。
2. **小标题数量**：写作要求「最多 3 个小标题」；05 按考法给讲解块，每个热门或冷门考法一块。现有定稿的非谓语有 5–6 个小标题。本模板按 05。
3. **例题数量**：写作要求「每专题 2 道（≥20 题可 3 道）」；05 按考法：热门考法 1–2 道，冷门不设例题。本模板按 05。
4. **册头统计**：校验要求 `stats` 3 项，但 05 规定段考册头不放统计。排版不输出，所以只是校验上的要求。
5. **讲的专题**：14 个新节点的讲法是默认规则（覆盖率 ≥ 30%、覆盖 ≥ 2 卷，不含被动、时态、情态动词、比较级、省略、反意疑问），须先经负责人确认。

## 8. 禁用与校验要点（自检清单）

- `topics[].no` 严格递增；每个专题名都在 `overview.rows` 里。
- `cov` 在 0–1 之间，且 ≤ `vols`。
- `gloss` 与 `note` 最多 2 行；`gloss` 每行不超过 10 个汉字。
- 例题的 `mid.label` 只能是「成分」或「判断」，`ans` 必填。
- 练一练的 `ans` 必填。
- `group` 必须指向本专题的一个 `subhead` 文字，否则例题会排在最后。
- 品牌词不得出现在内容中（清单见 `本地化/HANDOFF.md` §5）。
- 不写内联样式，不发明 class。

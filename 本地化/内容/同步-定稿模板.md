# 同步讲义定稿 JSON 写法（一册一份）

适用：东莞本地化的同步讲义（讲义一：同步课单元讲义），每册一份定稿，文件名 `本地化/内容/同步-<册>.定稿.json`。
册名：必修一、必修二、必修三、选必一、选必二、选必三、选必四（对应单元.json 的「册」字段，序 1–36 按册排）。

依据：字段以 `本地化/脚本/同步排版.py` 的 docstring 与校验函数为准；修改原则以 `规范/05-所有者修改原则.md` 为准；版式映射见 `规范/04-英式版式.md` §7。三者冲突时以 05 为准。本文只写内容与字段，不改版式。

已有范例：`本地化/内容/同步-必修一.定稿.json`（W、U1、U2 三个单元，可对照字段写法）。

---

## 一、流程

1. **出候选**：`python3 -I 本地化/脚本/同步选题.py 必修二`（只出一册；不带参数出全部 7 册）。输出 `本地化/内容/同步-必修二.json`。候选只是选题结果，不能直接排版。
2. **挑句式**：句式块的题不由脚本选，要人工从东莞原题里挑（题干带改写指令：同义句转换、用…改写、用…合并、句型转换等；只用原题，不编题）。挑好后写进 `同步选题.py` 的 `TRICK_PICKS['<册>']`，再跑第 1 步。`TRICK_PICKS` 的格式见脚本注释。目前只有必修一 W–U2 配置了句式。
3. **写定稿**：复制候选为 `同步-<册>.定稿.json`，逐单元补全：`gloss`、`formula`、各题 `reason`，必要时写 `answer_show`、短语的 `对照`。短语标题要改成原题实际考的搭配（见第三节）。
   - 续做已有定稿的册：候选里的 `families` 只含定稿里没有的新形式，要把新形式合并进定稿，不要覆盖已有内容。
   - 定稿里的题只用候选或题库里的题，题号不要自造。
4. **自检**（按 05 §四）：
   ```bash
   python3 -I 本地化/脚本/定稿校验.py                 # 渲染前必须通过
   python3 -I 本地化/脚本/同步排版.py 必修二           # 定稿 → 渲染/本地化/同步-必修二.html
   cd 渲染/本地化 && ../node_modules/.bin/vivliostyle build 同步-必修二.html -o _out/同步-必修二.pdf --timeout 120 --executable-browser /opt/pw-browsers/chromium-1243/chrome-linux64/chrome; cd ../..
   python3 -I 调研/视觉重做/工具/指标.py 渲染/本地化/_out/同步-必修二.pdf   # 半格对齐率 100%，英文最长行 ≤ 80
   pdffonts 渲染/本地化/_out/同步-必修二.pdf                                  # 不得出现 WenQuanYi / DejaVu / Liberation
   python3 -I 本地化/脚本/孤标题检查.py 渲染/本地化/_out/同步-必修二.pdf      # 无输出即通过
   ```
5. **交负责人过目**。视觉产出每一版都要负责人看过才算完成。

`同步排版.py` 不带参数时排全部存在定稿的册。HTML 必须放在 `渲染/本地化/` 下。

## 二、文件结构

顶层三个键：

| 键 | 内容 |
|---|---|
| `生成` | 候选脚本路径，照抄候选 |
| `书` | 书名，如 `必修第二册`、`选择性必修第一册`。排版据此推册名，文件名必须与之对应（`同步-必修二` ↔ `必修第二册`） |
| `单元` | 单元列表，按序排 |

每个单元：

| 键 | 说明 |
|---|---|
| `序` | 单元.json 的序（1–36），与候选一致 |
| `data_no` | `W`（Welcome Unit）或 `U1`…`U5` |
| `unit_book` | `<书名>　<单元英文名>`，中间是全角空格，如 `必修第二册　Unit 1`。排版取前半段作 kicker，后半段作页脚 data-unit |
| `chips` | `{year_range, n_questions, n_kaofa, n_phrase}`，候选自动填。`year_range` 与 `n_questions` 显示在单元考情标题旁（「2019–2026 东莞真题 78 道」） |
| `h2` | 英文单元名（大标题）。Welcome Unit 的 h2 为 `Welcome Unit` |
| `zh` | 中文单元名（14pt，跟在英文名后）。拿不准时可写英文名，排版会只显示英文一次 |
| `stats` | `{卷数, 词数, 短语数, 句式题数}`。页面不显示，只作记录。`句式题数` 必须等于 `tricks` 的题数合计（校验） |
| `freq` | 单元考情表，候选自动填。见下 |
| `families` | ② 词性转换，见下 |
| `spelling` | ③ 单词拼写，见下 |
| `phrases` | ③ 短语，见下 |
| `tricks` | ③ 句式转换（后半），见下 |
| `quiz` | ⑤ 单元小测，见下 |
| `numbered_total` | 本单元编号的总数，由候选自动填 |

注意：`spelling`、`families`、`phrases`、`tricks`、`quiz` 五节都必须存在（定稿校验会报缺节）。没有内容的节写空列表（`tricks` 可以为 0 块：本单元没有东莞改写题就不设，此时「句式转换」分隔行也不出）。

### 1. `freq`：单元考情（① 表）

`[{词头, forms[{form, n}], 考法[], 题数}]`，候选自动填，一般不改。

- 排版只显示 `forms` 的前 3 个，`考法` 最多 2 个。
- 频次按题数分档显示。
- 只写本单元考过的词，按题数降序。

### 2. `families`：词性转换（② 节）

`[{词头, 题数, gloss, chain[], atoms[]}]`

- `gloss`：词族的说明，一到两行，用 `<br>` 分隔。每行不超过 10 个汉字。排版时两行用「；」接成一行。
- `chain`：词族链，每项 `{词, 词性, 释义, hit, 来源}`。
  - `hit: true` 表示东莞考过的形式，排版时加主色圆点、半粗；`hit: false` 为其余词。
  - `来源` 取 `词头`、`派生`、`补入` 之一。
  - 最多 4 项。
  - `词性` 形如 `n.`、`adj.`；`释义` 不超过 8 个字。
- `atoms`：该词族下东莞考过的形式，每个形式一道题（原题，见第五节）。

### 3. `spelling`：单词拼写（③ 节）

题的数组，6–8 道，每个词一道。题干带中文提示，写英文单词。候选的 `spelling` 已按规则选好，定稿时检查数量、不重复即可。

### 4. `phrases`：短语（③ 前半）

`[{短语, 释义, 词头, gloss, atoms[], 对照?}]`，最多 6 条。

- `短语`：必须是下面原题真正考的搭配。狂K 等教辅只作参考（释义、变体），讲义里不标出处。例：原题考 make a good impression **on**，标题就写 `make a good impression on sb`，不能写狂K 的 `have a good impression of`。
- `释义`：中文释义，一般取自词汇表，如有需要改写为更贴近题的释义。
- `gloss`：最多两行，每行不超过 10 个汉字。
- `对照`（可选）：`{短语, 释义}`。教材常见、东莞没考的相关搭配。排版时对照在上（常规字重），实考搭配在下（主色圆点、半粗），提示写「原题考 …」。只在教材搭配与实考搭配不同时使用。
- `atoms`：候选每条取 1–2 道原题，跳过改写题（改写题只进句式块）。排版允许短语块无题（`atoms` 为空）。

### 5. `tricks`：句式转换（③ 后半）

`[{句式, gloss, formula, atoms[]}]`，0–4 块。

- `句式`：句式名，不超过 6 个字，如「被动改主动」「定语从句」。
- `gloss`：一行提示，不超过 10 个字，**不写题数**（规范/05）。
- `formula`：一行，不超过 50 个字符，写成「原句骨架 → 改后骨架」，取自本块的原题。
- `atoms`：1–3 道原题，题干带改写指令。

### 6. `quiz`：单元小测（⑤ 节）

题的数组，最多 8 道。候选已按规则选好。定稿后定稿里的小测不会因候选变化而变，除非手工改。

## 三、题（atoms）的字段

每道题是一个对象，字段如下。

| 字段 | 写法 |
|---|---|
| `id` | 题库里的题号（如 `155-09`）。必须在 `本地化/数据/题库.jsonl` 里存在 |
| `no` | 本单元内的编号。规则：② 词族的题、③ 拼写、③ 短语、③ 句式、⑤ 小测，按这个顺序在单元内连续编号，答案页同号。候选已编好，增删题后要重编，并保证连续（校验会报） |
| `标签` | 题库标签，形如 `2024 · 东莞高级中学 · 高一上月考`。排版显示为「2024 东莞高级中学高一上月考」，外加方括号（CSS 加），数据不改 |
| `题型` | 题库题型，如 语法填空、完成句子、单词拼写、翻译 |
| `题干` | 题库题干经过清洗（去掉通用指令，改写指令放到 `cue`）。与题库题干一致（定稿校验比对，规范化后） |
| `题干HTML` | 候选自动生成（空位换成 `<span class="blank">`）。不手改 |
| `cue` | 改写指令数组，排版放在句末，如 `["用 ask 改写"]`。没有则 `[]` |
| `提示词` | 题库提示词，如 `challenge`，没有则 `null` |
| `答案` | 题库答案，与题库一致（定稿校验比对，规范化后） |
| `解析` | 题库解析，原样保留 |
| `句意` | 题库句意，原样保留（可能为空） |
| `reason` | 答案页的说明，不超过 20 个字。平实的知识陈述，如「作表语，说明主语性质，用 -ing」 |
| `answer_show` | 答案页显示的答案。通常留 `null`，排版用 `答案`。只在题库答案有错时使用（见第四节） |

作答方式由排版根据题干自动判断（整句作答、空位加长、普通），定稿不用写。

## 四、写作规则

### 1. 原题与答案

- **只用东莞原题，不编题**。原题不够就少，不硬凑。
- 题库答案有错：原题不改，`answer_show` 写改正后的写法，`reason` 写清改了什么。例：题库漏了 but 后的主语 it，`reason` 写「补 but 后的主语 it」。
- 明显的录入错误（如 occasio → occasion）在语料里修，不在定稿里修。

### 2. 措辞（05 §一）

- 不写编辑说明：禁止「不单列」「本册不讲」「见同步讲义」「见例 2」「同上」「结构同上」「一句带过」。考得少的点，写成知识，或者列出来练。不值得讲的，整句删掉。
- 不散报数据：单元头不放统计，讲解小标题、句式块旁都不写「N 题」。
- 正文不用：「先看……再……」「抓住」「记住」「其实」「关键是」「核心」「本质」「一眼看出」、破折号、感叹号、反问句、为对仗硬凑的「不是……而是……」「既……又……」。
- 说明写成平实的知识陈述（如「分词与逻辑主语是被动关系时用 -ed」），不写成操作指令。

### 3. 归属与讲法（05 §三）

- 每个句式、短语要讲清它为什么放在这一节。冷门考法也要有一个简短的讲解，讲清判断方法。
- 一个考法归在某个节下，要说明理由，不把冷门考法塞在别的要点末尾一笔带过。

### 4. 校验对应的数量规则

以下由 `同步排版.py` 的 `validate()` 检查，不满足则排版报错：

- 每个 `gloss`、`formula` 的规则见第二节。
- 词族链不超过 4 项。
- `spelling` 为 6–8 道，题不重复。
- `phrases` 不超过 6 条。
- `tricks` 为 0–4 块；每块的句式名不超过 6 字；每块 1–3 道题；`gloss` 不写题数；`formula` 不超过 50 字符、单行。
- `quiz` 不超过 8 道。
- `no` 连续；`stats.句式题数` 与 `tricks` 题数一致。

**注意**：某个单元没有可用的改写题时不设句式块，不要硬凑。

### 5. 选题口径（同步选题.py）

- 本册年级：必修册以高一考卷为主，选必册以高二考卷为主（`GRADE`）。②③ 两个年级都收。
- 词头归属全书统一：每个词只进它在全书（序 1–36）中最早出现的那一册。
- 待校对的题默认排除。核对后的题写在 `CHECKED_OK` 中。
- 同一新形式多道题时，取年份最新的一道，同年优先本册年级。

## 五、常用检查清单

交付前逐条核对：

- [ ] 文件名 `同步-<册>.定稿.json`，顶层 `书` 与册名对应。
- [ ] 每单元 `spelling`、`families`、`phrases`、`tricks`、`quiz` 五节齐全。
- [ ] 所有题的 `id` 在题库中，题干与答案与题库一致（或有 `answer_show`）。
- [ ] 短语标题是原题真实考的搭配，狂K 只作参考，讲义里不标出处。
- [ ] 没有编辑说明，没有禁用词，没有破折号、感叹号。
- [ ] `no` 连续，`numbered_total` 正确。
- [ ] `定稿校验.py` 通过；`同步排版.py <册>` 无报错；PDF 指标与字体自检通过。
- [ ] 交负责人过目。

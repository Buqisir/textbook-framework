# 跨册重复题处理 brief（2026-11-06）

## 背景

所有者定：**同一套讲义内同一道题只出现一次**（同步 7 册之间、段考 16 册之间；同步与段考之间允许）。重复的题保留在最早的一册，后面的册删掉或换题。清单：`本地化/报告/跨册重复/清单.md`，每行是一处要处理的题（「要改的册」「位置」「题号」）。

接手前先读：`规范/05-所有者修改原则.md`、`本地化/内容/段考-写作要求.md`（段考）或 `本地化/内容/同步-定稿模板.md`（同步）。只改分给你的定稿文件。

## 怎么改

对清单里分给你的每一行：

1. 在定稿里找到这道题（位置写法：段考「专题名 例题[k] / 练一练[k]」，k 从 1 数；同步「单元 区块[k] 词头 no.编号」，区块是 families / phrases / tricks / quiz / spelling）。用题干核对，别找错。
2. **能换就换，换不了就删。** 换题的来源：
   - 段考：同一册的 `本地化/内容/段考-<年级学期>-<节点>.候选.json`，同一专题、尽量同一考法（`group`）。
   - 同步：同一册的 `本地化/内容/同步-<册>.json`（刚重出的候选），同一单元、同一词或同一区块。
   - 换上的题必须：是东莞原题；**题号不在 `本地化/报告/跨册重复/已印题号.json` 对应系列（"段考" 或 "同步"）的列表里**；不在本册其他位置已出现；符合写作要求或模板的选题规则（没有「疑似缺陷」等标记、空位和答案对得上）。
   - 写法照抄同一区块里相邻题的字段格式。段考练一练要有 stem、cue、src、ans、why、group、level；例题还要有 gloss、ju、mid。同步 atom 照候选里的字段原样搬过来，补 reason。说明、解析用编辑口吻，短，不用「先看……再……」「抓住/记住/其实/关键是」、破折号（见 05 一.3）。
3. 什么时候删就行：
   - 段考练一练：删后该考法仍有题，就直接删；必练不足时把同考法的选练升为必练。
   - 段考例题：该考法还有别的例题就删；没有了，从练一练里挑一道同考法的题升为例题（补 gloss、ju、mid），或从候选换。
   - 同步：词族、短语条删到没有题了，整条删掉；拼写 `spelling` 保持 6–8 道（不够就从候选补）；小测 `quiz` 能补就补，补不到就少。
4. 同步定稿改完要**重编 `no`**：本单元内按 ② 词族 → ③ 拼写 → ③ 短语 → ③ 句式 → ⑤ 小测 连续编号，`numbered_total` 改成对应总数（见模板）。
5. 改完跑 `python3 -I 本地化/脚本/定稿校验.py`，你负责的文件必须「问题：无」相关条目为零（别的文件的报错不用管）。

## 产出

写到 `本地化/报告/跨册重复/结果-<你的组名>.md`：一个表，每行一处：题号、位置、处理（删 / 换成 xxx-xx / 升为例题等）、一句理由。表后写「删 N 处，换 M 处」。

不要改分给你以外的文件，不要提交 git。

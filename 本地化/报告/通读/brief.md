# 成品通读 brief（2026-11-06）

## 背景

23 册东莞本地化讲义已出成品 PDF。所有者要求：**以第一次拿到这本讲义的读者身份**（高中生，或第一次用它上课的老师），从头读到尾，找出读着别扭、用着不顺、讲错了的地方。你只找问题、写报告，**不改任何文件**。

## 材料

- 成品：`渲染/本地化/_out/<册>.pdf`（以它为准，读者看到的就是它）。
- 底稿：同步 `本地化/内容/同步-<册>.定稿.json`，段考 `本地化/内容/段考-<年级学期>-<节点>.定稿.json`。只用于定位和核对，不要先读底稿再读 PDF。
- 规则参考（读完 PDF 再查）：`规范/05-所有者修改原则.md`。

## 怎么读

1. 把每页渲染成图：`pdftoppm -r 90 -png <pdf> <你的 scratchpad 目录>/<册>-p`，**每一页都用 Read 看图**，看版面。
2. 文字用 `python3 -I -c "import pymupdf,sys;d=pymupdf.open(sys.argv[1]);[print('=== p',i+1,'\n',p.get_text()) for i,p in enumerate(d)]" <pdf>` 抽出来，逐句读。
3. 按页序读，不要跳。读的时候假装你没见过题库、没读过规范。

## 查什么（七项）

1. **看不懂**：说明、标题、柱注、标签、图例读了不知道什么意思；术语没解释就用；指代不清（「上面」「这一类」指哪）；第一次读不知道这一页该怎么用。
2. **用着不顺**（视觉、排布）：字太小或太挤；题与答案、解析离得太远或找不到；一道题被分页截断；空白过大或页面头重脚轻；表格难读；标题与内容脱节；空位太短写不下；页眉页码不对。
3. **讲错、语法错**：讲解规则说错或说得太绝对；例句、题干、解析里的英文语法或拼写错；中文错别字、病句。
4. **答案错**：把答案填回题干读整句，不通或不是唯一合理答案；解析与答案对不上；解析讲的不是这道题考的点。
5. **前后不一致**：总览表里的题数、专题号、覆盖率与正文对不上；「专题 n」「第 x 页」之类的指引指错；同一个概念前后叫法不同；编号跳号、重号；同类区块格式不统一。
6. **教辅腔、AI 味**：「先看……再……」「抓住/记住/其实/关键是」、破折号、为对仗而对仗、空话套话、编辑说明漏进正文（「不单列」「本册不讲」「同上」等）。
7. **黑白打印**：只靠颜色区分的信息（灰度打印后分不出来）。

**不要报**：英式拼写；合乎语法只是不够地道的；纯个人审美偏好；原题本身的出题风格。拿不准写把握「中」。每条要具体到能定位。

## 产出

写到 `本地化/报告/通读/结果-<册>.md`（一册一个文件），格式：

```
# <册> 通读结果

页数 N，读完 N 页。

| # | 页 | 位置 | 类型 | 问题 | 建议 | 把握 |
|---|---|---|---|---|---|---|
| 1 | 3 | 专题 2 练一练 5 | 答案错 | 填回后 "has been built since 1990" 不通 | 答案应为… | 高 |
```

- 「类型」只用：看不懂 / 用着不顺 / 讲错 / 语法错 / 错字 / 答案错 / 不一致 / AI味 / 黑白。
- 「位置」写到区块和题号（如「Unit 2 词族 no.5」「专题 3 例题 1」「总览表」）。
- 表后写一段「整体印象」（3–5 句）：第一次读这本，最大的障碍是什么，最好用的是什么。
- 最后一行：「报 M 条（高 a，中 b）。」

不要改任何其他文件，不要提交 git。

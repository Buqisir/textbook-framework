## 1. 要做什么（需求方原话的提炼）

本项目是东莞本地化团队的内部研究，**不对外销售**。读者是东莞高中英语老师。

东莞考试跟着人教版走，但有自己的地方特色。特色分两层，分开处理：

1. **每个单元考什么。** 这是主干，不变。对应**讲义一：同步课单元讲义**。它跟人教版单元走，讲清东莞实际考这个单元的哪些词、什么形式、怎么考、考过几次。
2. **段考聚焦什么专题。** 对应**讲义二：段考专题讲义**。
   - 它跟考试节点走。每学期四个节点：**期中前月考 → 期中 → 期中后月考 → 期末**。
   - 期中、期末在文件名里写得很明显；月考必须区分期中前和期中后（需求方特别强调过）。
   - 每册讲清这一站段考聚焦哪些专题，先讲后练。

**验收标准：** 拿出来一看就知道是「东莞的」，而不是「人教版同步讲义 + 换了东莞题源」。

**需求方已定的事：**
- 出处格式：数据里是「2024 · 学校 · 高一上期中」，显示为「[2024 学校本名高一上期中]」（规范/05 一.4）。
- 教学进度由我们从题库反推，需求方不提供。
- 分工：负责人统筹，具体活派给 Haiku（high effort），负责人审。视觉每一版都要负责人过目。

**负责人定的默认做法（已告知需求方）：**
- 答案放在单元末或册末。
- 只用东莞原题，**不编题**。原题不够时，用狂K教材原句补，并注明来源。

## 3. 怎么跑

所有 Python 脚本只用标准库，一律用 `python3 -I` 运行（`指标.py` 例外，需 `pip install pymupdf`）。路径相对仓库根目录。新容器先在 `渲染/` 下跑 `PUPPETEER_SKIP_DOWNLOAD=1 npm ci` 装 Vivliostyle。

```bash
python3 -I 本地化/脚本/题干修订.py --apply     # 按 数据/题干修订.tsv 改语料与定稿的题干病句（幂等；先干跑看命中）
python3 -I 本地化/脚本/题库.py                 # 语料/东莞单句语法/*.md → 题库.jsonl
python3 -I 本地化/脚本/狂K.py                  # 语料/狂K重点/*.md → 单元.json、词族索引.json
python3 -I 本地化/脚本/对照.py                 # → 题-单元.jsonl
python3 -I 本地化/脚本/段考专题.py             # → 数据/段考专题.json、报告/段考专题.md
python3 -I 本地化/脚本/段考选题.py             # → 内容/段考-<年级学期>-<节点>.候选.json（不带参数跑 16 份；或 段考选题.py 高一下 期中 只跑一个）
python3 -I 本地化/脚本/定稿校验.py   # 渲染前必须通过
python3 -I 本地化/脚本/段考排版.py 高一上 期中前月考   # 定稿.json → 渲染/本地化/段考-高一上-期中前月考.html（只给节点名时年级学期为高一上；段考排版.py 样 为手样回放）
python3 -I 本地化/脚本/同步选题.py [册]         # 同步讲义候选 → 内容/同步-<册>.json（不带参数出 7 册，如 同步选题.py 必修二）
python3 -I 本地化/脚本/同步排版.py [册]         # 同步讲义定稿 → 渲染/本地化/同步-<册>.html（不带参数排全部定稿）
```

新册（16 册中的任一册）的定稿照 `本地化/内容/段考-定稿模板.md` 写，文件名 `段考-<年级学期>-<节点>.定稿.json`。

同步讲义（讲义一）每册一份定稿，文件名 `内容/同步-<册>.定稿.json`，写法照 `本地化/内容/同步-定稿模板.md`。

渲染和自检：

```bash
cd 渲染/本地化 && ../node_modules/.bin/vivliostyle build 段考-高一上-期中.html -o _out/段考-高一上-期中.pdf --timeout 120 --executable-browser /opt/pw-browsers/chromium-1243/chrome-linux64/chrome
python3 -I 调研/视觉重做/工具/指标.py 渲染/本地化/_out/段考-高一上-期中.pdf   # 半格对齐率必须 100%
pdffonts 渲染/本地化/_out/段考-高一上-期中.pdf                               # 不得出现 WenQuanYi / DejaVu / Liberation
```

HTML 必须放在 `渲染/本地化/` 下。字体、`基础.css`、`主线.css` 都通过这个目录里的符号链接引用；HTML 放到别处，Vivliostyle 会静默回退到系统字体。

## 4. 关键结论与数据口径（改之前先读）

**统计口径**
- **专题判定口径**，见 `节点.py` 的 `topic_hit`：
  - 东莞的解析会把一些专题当套话写，例如「考查时态和主谓一致」写在任何谓语题上。非谓语、各类从句、被动、时态这类容易被写成套话的专题，**只看解析里「考查……」那一句**。
  - it 形式主宾语、强调、虚拟、倒装这类特征词，看解析全文。非谓语也看全文，因为解析常把它写成「考查动词」。
  - 用这个口径之前，主谓一致被统计成 50% 的卷考，实际只有 2 题。
- **同卷多文件按一卷计**：两个文件共享的重复题达到较小文件的 80%，就算同一份卷。例如五校联考在题库里有 3 个文件。

**节点归属**
- 月考先看序号（第一次 / 第二次……），再看月份。
- 只能按月份推定的标「推定」：下学期 4 月的月考算期中前；高二上 11 月的月考算期中后。
- 节点卷数（高一上）：期中前月考 12、期中 20、期中后月考 **4**（太少，暂时不出册）、期末 9。高一下和高二的数据都不可靠。

**教学进度（反推结果）**
- 高一上第一次月考考到必修一 W–U2。
- 期中考到 W–U3，进度快的学校到 U5。
- 期末考到必修一全册加必修二 U1–2。

**本地特色**
- **段考语法不跟单元走。** 非谓语、it 形式主宾语几乎每卷都考。名词性从句、虚拟、强调在期中前月考就考，但人教版要到很后面才教，或者根本不单列。倒装从期中 30% 的卷升到期末 67%。人教版单元语法里的反意疑问、进行时表将来几乎不考。
- **借单元词考语法。** 期中前月考的虚拟语气几乎全是 recommend that … (should) do，而 recommend 是必修一 U1 的词。
- **狂K 的探究重点和东莞考点不一致。** 例如 U2 的 13 个探究词里有 8 个高一从没考过；东莞高频词（extremely 13 次、destination、unique）在狂K 里只列在基础表。
- **改写套路很多。** 同义句转换 85 题以上、定语从句合并 16、强调句 15、it 作形式宾语 6；翻译题常指定句型。

**题库已知问题**
- 「对划线部分强调」的题在题库里**没有划线信息**，讲义里按答案用 `[_…_]` 标出划线部分。
- 有个别答案错误，例如 160-22 的答案写成 fix，应为 focus。
- 题号前三位来自 `数据/卷号.json`，文件删了号也不复用。

## 5. 版式约定（CSS 是负责人写的，干活的 agent 不改 CSS）

- **网格**：u = 21pt，半格 10.5pt，左柱 96pt，柱与正文间距 12pt。
- **9pt / 10.5pt 的行内件**一律 `line-height: 1`，否则会撑高行盒、把基线推离网格。
- **题号**不用 `::marker`（会逐条漂移约 0.09pt），用 `data-no` + `::before`。
- **出处**放在题干句末（`.src`），不放进柱里，因为东莞出处标签太长。
- **段考讲义**：结构和 class 以 `渲染/本地化/段考-样.html` 为准，样式在 `段考.css`（它依次 import 同步.css → 主线.css → 基础.css）。定稿 JSON 的 schema 写在 `段考排版.py` 的 docstring 里，`段考-样.定稿.json` 可以回放出手样。
- **写作规则**：`内容/段考-写作要求.md`。要点：只讲东莞这一站真考的出题样式；柱注计数只写「M 题」；一题只进一个专题，主考点必须真是这个专题。
- **讲解段**：每段是一条独立要点，不首行缩进，柱与正文间距里悬挂主色小方块；小标题之间的各组空半格（同步.css 末尾）。
- **措辞**：用编辑口吻的教辅说法，不用 AI 腔。固定文字已定：单元考情、考情总览、东莞真题 N 道、覆盖 M/N 卷、N 套试卷、教学进度 Uk、短语与句式转换。正文避免「先看……再……」「抓住/记住/其实/关键是」「一句带过」、破折号、为对仗而对仗的句子。也不写编辑说明（「不单列」「本册不讲」「见同步讲义」「同上」等），见 `内容/段考-写作要求.md` 末节。出处显示为「[2023 学校考试]」（`src_text()`，数据不变）。
- **讲义一结构**：单元头 → ① 单元考情（词频表）→ ② 词性转换（按单词分组）→ ③ 短语与句式转换（句式块 `.phrase.trick`，只用东莞原题，少就少）→ ④ 单元小测 → 答案。①② 是需求方认可的写法，不加教辅对照列。
- **短语条按东莞实际考法写**（所有者定，2026-11-05）：短语标题必须是下面原题真正考的搭配（如原题考 make a good impression **on**，标题就不能写狂K 的 have a good impression **of**）。狂K 只作参考（释义、变体），讲义里不标出处；教材搭配与实考搭配不同时，两条都列（定稿 `phrases[].对照`）：教材的在上、常规字重；实考的在下、主色圆点加粗，提示里写「原题考 …」。
- **题库答案有错时**：原题不改，答案页用 `answer_show` 印改正写法，reason 说明改了什么。
- **品牌词**（「新东方易组卷」、xdf）不得出现在仓库内容里。

# 语料

中学英语真题语料，供云端 Agent / 教辅生产取用。

## 目录

- **`东莞单句语法/`** — 东莞市各中学英语试卷中的**单句语法题**（语法填空、完成句子、翻译、句型转换、单句改错等），162 卷、3107 题。来源：新东方易组卷。
- **`xdf单句语法/`** — 已并入 `东莞单句语法/`。

## 文件结构（`东莞单句语法/*.md`）

```
# <卷名>

## <大题节名，如 语法填空 / 完成句子 / 翻译>

### 原卷第 N 题
<题干（含原卷给的中文答题说明）>

**答案**：<参考答案>

**解析**：<解析>

### 原卷第 N+1 题
...
```

- 每题一个 `###` 块，按原卷题号排列
- 题号是**原卷全局题号**，不是本卷内连续编号（原卷前面有听力/阅读题）
- 翻译题可能给多个参考答案，以 `A. … B. …` 或直接多句并列呈现

## 使用注意

- **按 `### 原卷第 N 题` 块处理，别按 `##` 节名聚合**：约 6 个文件的节名是"完形填空""书面表达"等（原卷大题名），但里面实为单句题
- **无听力、无写作、无篇章题**：抓取时已过滤；仅保留单句语法题
- 空卷（全听力/全阅读的卷）不在此目录

## 题型分布（粗估）

| 题型 | 说明 |
|---|---|
| 语法填空 | 单句，用括号词的适当形式填空 / 用适当的词填空 |
| 完成句子 | 汉译英片段、根据提示完成句子 |
| 翻译 | 汉译英整句 |
| 句型转换 | 同义句、被动、倒装、强调句等改写 |
| 单句改错 | 一句话改一处错 |
| 反义疑问、强调 | 专项句式题 |

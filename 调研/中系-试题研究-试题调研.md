## 1. 页面几何与网格

### 1.1 试题研究：练习页双栏对位；答案页双栏齐头扫

**练习页（579 / 580 / 581）**

- **栏数**：稳定**双栏**，中缝一条细绿/灰竖线。579 不是「整页两篇独立文章」，而是 **左题右讲水平对位**：同一考点带横贯两栏，左边填空/选择，右边句型树或规则盒。580、581 改为 **左夯基、右提能** 的纵向分工，中缝仍在，但两栏任务不同，不再要求同一行对齐同一考点。
- **边距**：四周都窄。580 地脚被圆角营销条吃掉约页高 **12–15%**；真正的练习版心被压缩到上 85%。581 天头另加一条通栏「语法链接」浅框，约占页高 **10–12%**，下面才是绿药丸主标题。
- **页眉页脚**：课页几乎没有经典「书名+章节」页眉（被微信水印挡住一部分）。页脚：页码偏外下；580 整条 **万唯中考** 作业引流框（二维码 + 橙/绿胶囊文案 +「请完成分层作业本第 1–3 页」）。
- **模块纵比（目测）**

| 页 | 顶 | 中 | 底 |
|---|---|---|---|
| 579 | 被裁，残留重难考点/熟词生义绿签 | ~85% 左题右树 | 熟词生义虚线盒，约 12–18% |
| 580 | 绿药丸标题「核心词汇分层练」~8% | 左小题夯基 / 右教材语篇提能 ~75% | 营销条 ~15% |
| 581 | 语法链接框 ~12% + 绿药丸标题 ~8% | 双栏练习 ~70% | 作业提示框（比 580 瘦）~8% |

网格纪律：**栏少（2）、模块种类多。** 对齐靠中缝竖线 + 绿图标栏头，不靠严格基线网格。579 的思维导图是嵌进右栏的第三套局部网格，节点盒把栏宽切碎。

**答案页（scan 183 / 184）**

- **栏数**：严格**等宽双栏**，中缝 **浅青虚线**。不是杂志式模块拼贴，是报纸式正文流。
- **切口签**：183 为右页，**右切口**竖向青签白字「参考答案及解析」；184 为左页，**左切口**同款签。这是对页拇指索引，不是装饰边。
- **天头**：通栏浅青实条，条内黑字「精讲本参考答案及解析」；183 右上有一枚青勾标。天头条约页高 **5–6%**。
- **边距**：比练习页更贴。栏间沟约 4–6 mm 观感；外切口要给竖签让位。地脚页码：183 在右下，184 在左下（外口）。
- **模块**：几乎没有盒。换段靠 **居中主题名**、**【基础过关】** 黑括号标签、通栏青条上的「五、」「六、」题组号。184 中部「五、」是青底白字横条，把阅读解析从上一篇切开。

答案册网格纪律：**一栏流、标签当路标、色只出现在天头/切口/题组条。** 比练习页克制，也更像「附录」而不是「课」。

### 1.2 试题调研：对页单栏叙事 + 表/真题局部再分栏

四张都是**摊开对页**（横构图）。单页内部默认**单栏**，用色条和盒换段，不拿中缝竖线切课文。

- **574 目录（p.1–2）**：每页一条垂直目录流。层级靠缩进，不靠分栏。右缘挂元数据标签（「2026 高考高频失分点」「创新考法」「名师视频课」），等于给目录加了一条不画线的右栏。页码在地脚浅蓝圆。
- **575（约 p.012）**：主舞台是 **通栏大表**（左页名词后缀，右页形容词后缀）。表下「一词玄机」改 **双栏** 小词典。右页下半「参考答案与深度讲评」回到单栏编号流。
- **576（约 p.038–039）**：左页单栏（口诀 → 极简提分表 → 题 7–9 解析 → 答案速查一行）；右页单栏（梯形大标题「突破超重点」→ 三列表「核心考点 / 5 年高考创新解读 / 2027 命题预测」→ 类型小标题 → 带卷标的语法填空）。地脚左右外角各一条竖向「辨析」微栏，占版心之外的边角。
- **577（长难句）**：单栏，但分析区用缩进 + 蓝标注把一句英文拆成多层。右页「技法 4」是「例题 → Step 1 结构图 → Step 2 语境定形式」的纵栈。QR 贴在标题右侧，挤占栏宽。

边距：比试题研究答案页宽一点，比英系 ClearRevise 的 20 mm 仍窄。表和标题条经常顶到版心左右齐，地脚「一词玄机 / 逐句句解 / 辨析」贴切口。

调研网格纪律：**页是专题容器，不是题海容器。** 栏数随模块变（表双栏、解析单栏、边角微栏），变化服务于「这一页要讲透一个超重点」，不是为了塞更多题。

## 3. 字体层级与中英混排（重点）

项目硬约束是「讲解中文、语料英文」。两刊都在做这件事，成败不对称。

### 3.1 角色分工（两刊共通、执行不同）

| 角色 | 试题研究练习页 | 试题研究答案页 | 试题调研 |
|---|---|---|---|
| 栏头/标签 | 粗黑（绿） | 粗黑 /【】括号 | 粗黑 + 青底白字 |
| 中文讲解 | 宋/黑混用，讲解盒里偏黑 | **宋体**正文 | 标题黑、讲解宋或黑 |
| 英语题干/语篇 | Times 血统衬线 | Times 血统衬线 | Times 血统衬线 |
| 英语关键词 | 579 树节点里加粗；有时换色 | 解析里偶尔加粗 `Route 2` | 表内后缀青字；真题词干衬线 |

语料衬线、讲解无衬线/宋——这个分相对了。问题出在 **字号补偿、行距、断行、标签插入点**。

### 3.2 好的共处

**1. 空格后紧跟中文义项，不另起术语层。**  
580 / 581：`f_______（罚款）`、`l_______（可爱的）`、`g_______（绿色的）`。英文空与中文义项同一行、同一句位。学生不需要把「要考的词」和「要填的义」分两处找。义项用括号降一级，不和题干英文抢字重。这是中英混排里最干净的一招。

**2. 教材例句「英句 + 中译 + 教材坐标」三截，不混进题干。**  
579：`Ask the teacher for it. 向老师要它。(Unit 3 P17)`。英语句是语料相，中译是讲解相，括号页码是元数据——三相顺序固定。

**3. 答案解析先给中文句意，再嵌英语证据。**  
183 语法填空：`worried 【解析】句意：我……它会很无聊……分析句子结构可知，此处缺少谓语动词；根据 “At first, I felt unsure.” 及备选词汇可知……故填 worried。`  
中文承担推理，英语只作为引用证据，用引号隔开。学生扫【解析】就能进中文轨道，不必在英汉语序之间切换身份。

**4. 调研把卷标从句子里摘出来。**  
576 / 577：`[2026 全国二卷]`、`[2025 全国一卷]`、`[试题调研原创]` 是青底方括号，贴在题号后、英文句前。英文句得以整行排衬线，不被「2024 新课标 II 卷」这类长中文插入词打断。研究练习页 581 的 `（2022 安徽 23题）` 也能做到这一点，但括号是黑字，视觉上仍占题干行。

**5. 577 的句法标注：中文标签是「贴在英语上的透明层」。**  
主语 / 谓语 / 宾语用小一号青字挂在对应英语片段上/下，英语句本身不断开。这是混排的高级形态——讲解不插入语料，而覆盖语料。

### 3.3 差的共处（点名）

**1. 双栏答案把英语按中文两端对齐来断。**  
`scan_5179…jpg`（183）：引文在栏末被切成 `be-` / `fore`、`I slowly under-` / `stood`。中文宋体两端对齐，英语按音节乱断。行距按中文 1.2 左右锁死，英文升部降部贴邻行。这是「同一 leading 伺候两种文字」的典型失败。

**2. 579 右栏句型树：英语节点盒宽度不够。**  
`ask sb. to do sth.`、`Would you mind (not) doing sth.?` 在灰盒里折行，介词和 to 被甩到下一节点视觉层。中文标签「请求」「介意」挤在盒侧。树是图形，却按中文栏宽来切英语短语——短语被当成汉字块。

**3. 575 表内英语溢出。**  
名词后缀列 `appearance / preference / performance` 一串，单元格没有英语专用的词间距，OCR 已碎成 `prefer—>preference, perform—sperformance`。印刷上就是字号偏小、词间距被当成中文密排。青字后缀和黑字例词的对比，在浅青斑马纹上进一步掉。

**4. 577 标注层与正文抢行距。**  
技法分析把蓝标注、下划线、方括号从句、Step 标题叠在同一句上。英语行距没有为「上标中文」加一行 leading，于是标注贴到上一句英语。好方法，剂量过大。

**5. 581 中文义项与首字母提示叠床。**  
既给 `l_______` 又给 `（可爱的）` 又给题号前真题标，一行里三种辅助。功能上友好，视觉上中文括号比英文小一圈，造成行内「空洞」：拉丁字母 x-height 与汉字字面没有做补偿，括号中文像注脚掉在基线附近。

**6. 183/184 中英引号不统一。**  
中文用「」和 “” 混用，英语片段有时无衬线化（扫描后有的词看起来像 Arial）。不是刻意的「术语无衬线」，是混排时没锁英文字族。结果：同一条解析里，题干引用和选项词（interesting / difficult / boring / easy）字族跳动。

### 3.4 可执行的混排结论（给框架，不是审美感想）

- **语料整句必须能以英语规则断行**（按词、按意群），禁止按中文栏的两端对齐去切音节。
- **中文义项用括号挂在空格后**，字号 ≈ 英文 x-height，不要小于题干 2 pt 以上。
- **卷标/考频是元数据组件，禁止插入英语句子内部。**
- **句法标注需要额外 leading**（标注行 + 英语行），不能从正文行距里偷。
- 解析体例锁死：**句意（中）→ 结构/题型（中）→ 原文（英，整块引用）→ 故填/故选。** 183 的公式对；183 的断行不对。

## 4. 组件形态学

### 4.1 真题标签

| 形态 | 出处 | 构造 |
|---|---|---|
| `（2022 安徽 23题）` / `（2023 安徽 76题）` | 581 | 题号前，黑括号，年+省+题号。完整坐标。 |
| `（2023.51）` / `（2024.54, 2019.37）` | 579 | 压缩成「年.题号」，多卷用顿号并列。省去省份——默认本省卷时才成立。 |
| `（10年3涉及）` / `（2025.23、2022.37涉及）` | 579 | 考频标签，贴在句型规则旁，不是贴在题上。编码「这是常考点」而非「这是哪一题」。 |
| `[2026 全国二卷]` / `[2024 新课标 II 卷]` / `[2026 福建泉州 5 月]` | 576、577 | 青底方括号，年+卷别。调研把「全国卷 / 省级质检 / 本刊原创」收进同一组件。 |
| `[试题调研原创]` | 577 | 同一括号家族，来源不是真题时仍给标签，避免「无标 = 真题」的误读。 |

研究练习页的标签是**黑字内联**；调研的标签是**色块芯片**。信息字段相同（年、卷、题号），视觉职能不同：前者不打断黑题干，后者让学生先看见「这题的权威等级」。

### 4.2 解析框 / 解析流

两刊都很少用「大圆角解析卡」。解析主要是 **【解析】标签 + 正文流**。

- **183/184**：`题号 + 答案 + 【解析】` 同一行起头。阅读题在【解析】后立刻报题型（细节理解题 / 写作顺序题 / 数学计算题 / 文章出处题）。完形在【解析】后报「考查形容词词义辨析」，再列选项中英对照（`interesting 有趣的; difficult 困难的; …`）。
- **576 左**：题 7–9 没有【解析】二字，直接「前一分句……后一分句……故填 however。」——随文讲评，靠题号加粗锚定。
- **575 右**：「参考答案与深度讲评」下 `1. 2. 3.`，答案词（descriptive / functional）作条目头，再跟句法理由。
- **577**：解析升级成 **Step 1 / Step 2** 块。灰圆角小标签写「分析」。这是两刊里最接近「框」的解析。

### 4.3 答案区

| 形态 | 出处 | 构造 |
|---|---|---|
| 横排速查 | 183【基础过关】 | `1. C  2. B  3. A … 10. C` 一行或两行排完，**无解析**。客观题先给钥匙。 |
| 随题答案 | 183 语法填空 | `5. how 【解析】…故填 how`。答案出现两次：句首一次、句尾一次。 |
| 答案速查条 | 576 左下 | 细线隔开，`1. by  2. as  3. of … 9. Otherwise` 一行。与上方详解分离。 |
| 调研讲评头 | 575 | 「1–9 题考查形容词的构词变形」先定性再逐题。 |

研究答案册：**先压缩钥匙，再展开【解析】**。调研课页：**详解在题旁，钥匙再收成一行**——因为课页不是附录，学生边看技法边对答案。

### 4.4 方法 / 技法栏目

- **579 重难考点 n**：绿圆角条 + 序号。右栏句型树 +【拓展】。
- **579 熟词生义**：绿药丸标题；底盒对比「常见义 vs 考场生义」（book 名词/动词）。
- **579 教材例句**：绿书本图标领句。
- **581 语法链接**：顶栏浅框，5 条语法点 + `见本书 P134` 页码。练习页指向语法页，不做页内再讲。
- **580/581 小题夯基 / 教材语篇提能**：绿书本图标 + 绿字栏头。I / II / III 题型号。
- **574 超重点 n → 类型 n**：目录即方法树。
- **575 极简速记**：青圆角签 + 闪电图标，领整张词缀表。
- **576 极简提分**：圆角青框，灯泡图标，内嵌「类型 × 解题要点」小表；口诀「异式 + 口诀」。
- **576 突破超重点**：右页大梯形青座 + 钻石标。仪式感标题，下面立刻接预测表，不是空装饰。
- **577 技法 n**：青横条编号；下挂 QR「视频课精讲」（黄底 + 红框码）。
- **576/575 地脚微栏**：辨析 / 一词玄机 / 逐句句解——把边角收成固定栏目，而不是空白。

### 4.5 其他重复零件

- **选择题 2×2 选项栅**（581）：A–D 两行两列，省纵向空间。基线常与题干最后一行贴太近。
- **首字母填空**：`f_______` 下划线定宽，首字母已给。
- **语篇挖空**：580/581 右栏整篇，空号 12–22 连续，与左栏小题编号不重号——全书题号是页内连续，不是每栏从 1 起。
- **素材声明**：`素材改编自 Unit 1 & Unit 2 & Unit 4`（580）、`Unit 11 & Unit 12`（581）。灰小字，贴在语篇指令下。
- **斑马表**（575）：圆角外表框，表头青底白字，行浅青/白相间。
- **目录右缘红盒**（574）：把「高频失分点」从条目中抽到页边，条目本身保持黑字。

## 5. 考点组织与题量逻辑（核心）

这是中魂要偷的东西。视觉可以全部丢掉，下面这套编排不能丢。

### 5.1 试题研究：教材锚点 × 考点带 × 分层练 × 答案后置

**编排主轴是考点，不是年份，也不是「把真题按套卷重印」。**

579 的一页 = 一条考点带（ask 的句型网 + thank you for + book 的熟词生义）。带内顺序：

1. 左：单题（选择 / 填空 / 介词二选一）  
2. 右：规则可视化（树、清单、【拓展】）  
3. 教材例句回链到 Unit 页码  
4. 考频（10 年 3 涉及）证明「该讲」  
5. 底：熟词生义对比，把同一词的课标义与考场义撕开  

题不按 2023、2024 年表排。真题被拆成句子，塞进当前考点。年份只作标签，不作目录。

580 / 581 把「讲」抽走，改成 **分层练闭环**：

```
小题夯基（离散：选择 → 拼写）
        ↓ 同一批词
教材语篇提能（改编课文的语法填空）
```

左栏练原子（map / name / DeepSeek 语境里的 know），右栏立刻要求同一词汇在语篇里变形（photo → photos，one → first）。**题量逻辑是「先碎后整」**，不是「先套卷后讲评」。581 顶上再加语法链接：本页词练完，语法去 P134——考点有地址，不是孤页。

**真题怎么进练习：** 能标则标（安徽卷题号），标不上的就当新编。不追求「本页全是真题」，追求「本页只为一个考点服务」。580 第 3 题出现 DeepSeek，说明题库按当年语境翻新，年份标签不是唯一合法性来源。

**答案在哪：** 练习页 **无答案**。183–184 证明答案进 **精讲本分册**，按主题语境重排：

```
一、人与自我
  主题一 丰富、充实、积极向上的生活
    ——主题语篇分层练——
      【基础过关】 篇1【主旨大意】+ 横排 1–10 答案
                   篇2 同上
                   【一材多设问】 单题深挖
                   篇3 语法填空逐空【解析】
      【能力提升】 篇7 完形逐空【解析】
```

答案册的目录逻辑与练习页一致：仍是 **主题语境 → 分层（过关/提升）→ 篇 → 题**，不是按考试年份。学生查答案时走的是「我在练哪条主题」，不是「我在做哪一年的卷」。

**解析套路（研究，锁死）**

| 题型 | 公式 | 实证 |
|---|---|---|
| 语法填空 | 句意 → 缺什么成分 → 根据英文空前后/备选词 → 词形变化 → 故填 | 183：`how / build / ideas / clearly / about / magic` |
| 阅读选择 | 题型名 → 题干意为 → 引原文 → 可知 → 故选 | 184：细节理解 / 写作手法 / 文章出处 |
| 七选五 / 匹配 | 根据题干英文画像 → 需求是什么 → 扫选项 → 故选 | 184「六、」Audrey/Bill/Robert… |
| 完形 | 考查××辨析 → 句意 → 选项中英对照 → 根据下文 → 故选 | 184「七、」interesting/difficult/boring/easy |

没有单独的「干扰项逐项排除」栏目；干扰项只在完形以「四词 + 四义」出现。阅读解析几乎不写「A 错因为…」，只写正确项的证据链。这是速度取向：答案册当查阅，不当精读。

### 5.2 试题调研：考情树 × 超重点 × 少题精练 × 解析随文

**编排主轴是「超重点 → 类型 → 技法」，真题是验证，不是正文。**

574 目录把全书写成一棵树：

```
解码 6–8 月一手考情（创新风向 1–3：中国故事 / 语境即解题依据 / 梯度暗礁）
突破超重点
  词法盲点扫除
    超重点1 3类必考变形
      类型1 名词变形…    ← 右缘：2026 高考高频失分点
      类型2 形容词词形…
    超重点2 活用思维陷阱
    …
  句法…
    超重点6 非谓语
  技法卡点速通
    超重点8 一个等式判谓语/非谓语
```

年份出现在两个位置：① 目录右缘的 **考情元数据**（高频失分、创新考法、视频课）；② 课页题前的 **卷标芯片**。年份 **不是** 排序键。排序键是考点树。

575：一个超重点摊成 **规则总表**（名词后缀 | 形容词后缀），练习题在表外或已做完，页上主产品是「可背的表」+ 底部 3 条深度讲评。题量可以很少，表必须全。

576：标准课页节拍——

1. 口诀（冠词「异式 + 口诀」）  
2. 极简提分表（副词 3 类失分）  
3. 随文解析 3 题（把口诀用一遍）  
4. 答案速查一行  
5. 对页：预测表（已考创新 \| 2027 怎么出）  
6. 类型 1「时态：动作时间轴定位」下挂 **4–5 道** 带卷标的语法填空  

**单类型题量刻意少。** 576 右页可见题 1–3 量级，不是 15 题打底。情报刊的合同是「讲透」，不是「刷完」。

577：技法页节拍——

1. 为什么难（5 条：枝叶多、词类活用、结构相似…）  
2. 技法名（去枝剪叶 / 结构对比）  
3. QR 视频  
4. 2–3 道长句（全国一卷 + 原创/模拟）  
5. Step 1 画结构 → Step 2 结合语境定形式  
6. 地脚逐句句解  

**答案位置：** 随文。576 详解在左页中下部，速查在详解下；575 讲评在表右/表下；577 分析紧跟例句。没有「翻到书末 183 页」这一跳。因为调研的页就是讲义，不是试卷。

**解析套路（调研）**

- 词法：规则（加 -ance / 去 e）→ 例词 → 讲评里补一句句法（「修饰 names，用形容词 descriptive」）。  
- 语法填空：语义关系（转折 hence however）→ 插入语位置/大小写 → 故填。比研究多 **语篇逻辑** 一层，少 **备选词** 一层（高考语法填空常无备选箱）。  
- 长难句：先图形化结构，再定词形。干扰来自「相似结构」（mastered / served / conducting 看起来像并列）。这里出现了研究阅读解析所缺少的 **干扰路径点名**。

### 5.3 真题标签系统怎么服务组织（不是怎么画盒子）

- **研究**：标签证明「这题在真卷出现过」，服务 **中考题库可信度**。同一页可以无标新题 + 有标真题混排。考频标签（10 年 3 涉及）服务 **讲不讲**，不服务 **排第几**。  
- **调研**：标签证明「这是 2026 全国卷还是质检还是本刊」，服务 **考情等级**。目录右缘的失分点标签服务 **先读哪一节**。原创也打标，避免真假混读。

可蒸馏的不是括号圆角，是字段：

```
source: { year, region_or_paper, item_no?, freq?, origin: real | adapted | original }
```

每道练习题带 `source`；考点节点另带 `freq` 与 `risk`（失分点/创新考法）。排序键永远是考点树，`source.year` 只用于过滤和呈现。

### 5.4 题量与分层的合同

| | 试题研究 | 试题调研 |
|---|---|---|
| 一页主产品 | 10–20+ 题，或 1 条考点带的题+树 | 1 张规则表，或 1 个技法 + 3–5 题 |
| 分层 | 基础过关 / 能力提升；小题夯基 / 语篇提能 | 超重点下的类型；技法 1…n |
| 真题占比 | 混编，标得出就标 | 课页真题少而新（2025–2026 卷 + 质检） |
| 答案 | 分册集中，主题顺序与练习同构 | 随文 + 一行速查 |
| 与教材关系 | 强：Unit 页码、改编语篇 | 弱：教材不出场，高考卷出场 |
| 与来年关系 | 弱：考频回看 | 强：预测表第三列 |

中魂一句话：**研究用「教材锚 + 分层海量 + 答案后置」把课标词吃完；调研用「考情树 + 超重点 + 少题随文解」把当年写法讲透。** 自创语法填空专练更接近二者的杂交：组织取研究的分层闭环，情报取调研的超重点树，答案取「例题随文闭合、变式可后置」（与日骨课页闭合不冲突）。

## 6. 信息密度策略

两刊都密。乱或不乱，取决于 **路标是否垄断颜色、模块有没有换段信号**。

**试题研究练习页：密，且开始吵。**  
双栏 + 树 + 图标 + 绿虚线 + 考频小字 + 教材坐标，579 一页信息种类过多。密度服务于「一页结束一个动词」——合理。吵来自营销页脚（580）和树节点折行。580 去掉树之后，同样双栏密但不乱：左选择、右语篇，任务一目了然。

**试题研究答案页：密，但不吵。**  
183–184 几乎无盒无图标，密来自字号与行距。路标只有【】、题号、青条。查 C 答案很快；读完整解析会累。水印是额外的乱，设计本身其实干净。这是「附录密度」：承认没人把答案册当杂志读。

**试题调研：密，按模块分区后不乱。**  
575 表是高密度的合法形式（网格在替你对齐）。576 把口诀、表、解析、预测、真题叠进对页，但每块有青头或梯形座。乱的局部是：574 目录标签墙、576 题 7–9 解析墙、577 标注抢行。整体仍比 579 更可扫——因为同一时间只有一个超重点。

**为什么密：** 中系题源刊的产品承诺是「这本里有今年要的东西」。空白会被读成「没料」。研究用题量兑现承诺，调研用表+预测+视频码兑现承诺。自创若用英皮的留白，必须另用栏目名告诉学生「不是偷工」——例如一页只闭合一个考点，但答案当场给完。

## 7. 两刊对比

| 维度 | 试题研究（本批） | 试题调研（本批） |
|---|---|---|
| 学段/产品 | 万唯中考英语：课页 + 精讲本答案 | 高考英语考情刊：语法填空专项 |
| 一页到底在卖什么 | 题（外加紧贴的规则） | 方法（外加少量题） |
| 组织键 | 教材单元 / 主题语境 / 考点带 | 超重点 → 类型 → 技法 |
| 分层 | 夯基 vs 提能；过关 vs 提升 | 类型与技法编号 |
| 真题 | 拆句进考点；标签可缺省 | 整句进技法；标签必有（含原创） |
| 预测 | 无（考频是回顾） | 有（已考创新 \| 来年预测 并置） |
| 答案 | 后置分册，主题同构 | 随文 + 速查条 |
| 解析 | 句意—成分—证据—故填；阅读几乎不打干扰项 | 语篇逻辑 + 长难句分步；点名相似结构陷阱 |
| 教材 | 强锚（Unit、改编语篇） | 缺席 |
| 色 | 练习草绿 / 答案浅青，两套壳 | 全书青壳，红黄仅警报与视频 |
| 网格 | 双栏默认 | 单栏默认，表和边角再分 |
| 中英混排 | 空格+义项好；答案栏英语蛮断 | 卷标出句好；表与标注层易溢 |
| 要避开的性格 | 页脚招生；一页零件过多 | 目录徽章墙；预测表做成权威剧场 |

对自创配方的含义：

- **中魂的骨架用研究的分层闭环**（原子题 → 语篇题 → 同考点），因为验收样章是语法填空专练，不是考情月刊。  
- **中魂的目录用调研的超重点树**（考点 → 类型 → 技法），因为「机械填词 → 语境赋能」正是语法填空要讲的那句话（574 创新风向 2）。  
- **答案策略折中**：例题精讲随文闭合（调研 + 日骨）；大剂量变式的钥匙可横排后置（研究 183）。

## 9. 可蒸馏基因清单（内容组织，可执行规则）

只收组织手法。视觉令牌让英皮/日骨管。每条都能直接变成 schema 字段或生成顺序。

**1. 排序键是考点树，年份只是题的属性。**  
规则：目录与课页顺序 = `考点 →（类型）→ 技法/题型`。真题不得按年成章。每题必有 `source.year + source.paper`（缺省则标 `original` 或 `adapted`），可选 `source.item`、`source.freq`。呈现为题号后的元数据芯片，**插入点在中文讲解或题号侧，永不插入英语句子内部**。  
出处：`WechatIMG574.jpg`（超重点/类型树）；`WechatIMG581.jpg`（年+省+题号）；`WechatIMG576.jpg`、`WechatIMG577.jpg`（卷标芯片，原创也打标）；`WechatIMG579.jpg`（考频服务「讲不讲」）。

**2. 分层闭环：同一批词/点，先原子题后语篇题。**  
规则：一个练习节点必须能填两个槽——`drill`（选择/拼写/单句填空）→ `passage`（短语法填空或改编语篇）。两槽题号连续、考点集合相交。禁止只丢一套完整阅读却不在当页练原子，或只刷 15 道单句却不给语篇。  
出处：`WechatIMG580.jpg`、`WechatIMG581.jpg`（小题夯基 / 教材语篇提能）；答案侧同构见 `scan_5179…jpg` 的【基础过关】对 `scan_24ae…jpg` 的【能力提升】。

**3. 例题解析公式锁死，按题型换槽，不换顺序。**  
规则：

- 语法填空：`句意 → 缺的成分/词性 → 原文证据（整块英语）→ 词形变化 → 故填`  
- 选择/阅读：`题型 → 题干意为 → 原文证据 → 故选`（干扰项可选；完形才强制「选项中英对照」）  
- 长难句：`Step 1 结构 → Step 2 语境定形式`  

空槽可省，顺序不许乱。英语证据单独成 span，左齐、按词断行。  
出处：`scan_5179d3e39ae148cf1994a940234ec727.jpg`（句意—成分—故填）；`scan_24aeedd1a5254b6cd16d2b750e191afb.jpg`（题型—题干意为—引文—故选；完形四词对照）；`WechatIMG577.jpg`（两步结构）；`WechatIMG575.jpg`（讲评补句法角色）。

**4. 客观题钥匙与详解分离：先一行速查，再按需展开。**  
规则：凡 A/B/C/D 或短空答案，先输出 `answer-key` 横排（`1. C  2. B …`），再输出 `rationale`。例题精讲可以答案出现两次（句首+故填），变式练习只在栏末给钥匙。学生「对答案」与「读为什么」是两次任务，不要绑死在同一段。  
出处：`scan_5179…jpg`【基础过关】横排 1–10；`WechatIMG576.jpg`「答案速查」一行。

**5. 教材回链与考情回链分开存，不要混成一种徽章。**  
规则：课标练习写 `textbook: { unit, page, role: example | adapted_passage }`（579 的 Unit 3 P17；580 的「素材改编自 Unit 1 & 2 & 4」）。高考/中考情报写 `exam_insight: { risk: 失分点 | 创新考法, forecast?: 来年写法 }`。前者服务「从哪来」，后者服务「往哪去」。同一标题行禁止两枚一起闪。  
出处：`WechatIMG579.jpg`、`WechatIMG580.jpg`、`WechatIMG581.jpg`（教材）；`WechatIMG574.jpg`、`WechatIMG576.jpg` 三列表（核心考点 / 5 年创新 / 2027 预测）。

**6. 每篇语篇先给【主旨大意】，再逐题；一材可以多问。**  
规则：凡阅读/完形/语法填空语篇，解析以 2–4 句中文主旨起头（体裁 + 讲了什么 + 可选「旨在」一句封顶）。然后按题号展开。允许 `【一材多设问】` 槽：同一篇上额外打写作顺序/标题/出处题，不另开一篇。

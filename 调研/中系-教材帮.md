# 中系风格解剖：天星教育《教材帮》（讲解型同步教辅）

> **角色**：中魂——考点组织与题量逻辑，不是日骨（密度骨架）也不是英皮（克制美感）。  
> **原则**：结论以 5 张实拍样张为准。开本、系列口号、公开卖点不写入本报告。拍摄伪影与设计本意分开写。hex 为降采样 JPG 像素取样后的设计估计。  
> **项目对齐**：`规范/00-项目共识.md` 要求中系承担「考点怎么切、讲练怎么排、方法论怎么嵌」。本报告把视觉组件写全，但蒸馏清单的重心放在内容组织规则。

### 0.2 拍摄伪影（解剖时一律扣除）

1. **切口/装订阴影**：569 左缘取样约 `#A4C0CC`–`#B2BCC1`，是书口暗部，不是设计灰蓝边。
2. **色温**：纸白取样约 `#FCFCFC`–`#FEFEFE`，接近设计白。蓝色在照片里偏青（INDEX 底约 `#C6E9F9`，标签实地约 `#59BBEB` / `#4DA4D2`）。下文主色按「青天蓝」校正，不把照片里的粉青当印刷专色。
3. **梯形与页曲**：栏宽、圆角半径、竖线是否绝对垂直不可当毫米级几何。比例用相对关系。
4. **JPEG 压缩**：细线、浅网、发丝竖栏线会发糊。能确认「有细线分栏」，不能确认线宽是 0.25pt 还是 0.5pt。
5. **对页中缝**：暗带是装订，不是跨页色带。
6. **570–573 天头/切口取样发灰青**：桌面阴影 + 书口，不是设计把纸做成灰。课页纸白仍按近白。主色在讲解页比 INDEX 底更饱和（标签实地约 `#48A8E8` / `#58A0C0`），同一青天蓝，曝光不同。
7. **573 左页品牌是「练习帮」**：同一套天星产品里的测评分册/内文页型，不是另一家出版社。解剖时当「教材帮家族的纯练页」，色板和字母栏头与讲解页连续。

## 1. 页面几何与网格

### 1.1 `WechatIMG569.jpg` 左页：INDEX——浅蓝底 + 白卡片 + 三栏

- **页底**：满版浅青底（取样约 `#C6E9F9`，校正后约 `#D6F0FA`），带极浅水平细纹。职能是把整页索引「托」成一块产品界面，不是正文纸。
- **主容器**：白圆角大卡片浮在底上，顶圆角可见，带浅投影。卡片内边距明显大于卡片到裁切边的外距——外圈是装饰边，真正网格在卡片里。
- **栏数：三栏**。栏间发丝竖线（浅青）。上段按 UNIT 切列（每栏一个 UNIT + 知识点条目）；中段、下段换成「写作&解题方法」「英语听力」等**跨单元功能块**，仍走三栏，但条目改成「资源名 + 页码」。
- **水平切段**：栏头不是通栏色带，而是「细青横线中断、中间嵌胶囊标签」（如「10个写作&解题方法」「22 个英语听力」一类）。换段靠这条「线+胶囊」，不靠换页。
- **天头**：INDEX 白字蓝块 + 线稿人物/灯泡图标；其下一条图标+文字导航（视频微课、语法等）。
- **边距**：外页边被浅蓝底吃掉，视觉边距来自卡片内 padding。条目左齐、页码右齐，中间**没有点线引导**——短标题会留下大块空白。
- **模块纵比（目测，左页）**：天头图标条 ≈ 12%；UNIT 知识点三栏 ≈ 40%；方法块 ≈ 22%；听力块 ≈ 26%。下段明显更挤。

### 1.2 `WechatIMG569.jpg` 右页：单元开篇——通栏头 + 思维导图 + 下半双栏

- **天头**：浅灰通栏块（取样约 `#E8E8EA`），左圆角、其余方角。内含线稿插画（宇航员/UFO）、大写单元名 `UNIT 1 SCIENCE FICTION`、Asimov 引语、右侧二维码气泡（竖排「单词听写」）。
- **栏数随模块变**：上半「A 话题词汇」是**通栏树状图**（左根右枝，不是等宽栏）；下半「B 话题佳句」改**两栏编号句**；最下「练一练」重新趋近通栏段落，右侧贴「新考向」小块。
- **页边**：内边（靠近中缝）宽于外边；地脚外角蓝块白字页码 `001`。
- **换段锚**：青方标「A」「B」+ 栏名；「单元素材积累」是骑在细青横线上的小青标签。练习段用浅青底条把头和讲解区切开。
- **模块纵比（目测，右页）**：灰天头 ≈ 16%；导图词汇 ≈ 38%；佳句双栏 ≈ 28%；练一练+新考向 ≈ 18%。

**569 网格纪律一句话：** 检索页用固定三栏；课页按「输入宽、输出窄」换栏——导图要宽度，佳句要并排密度，练习要整段语境。

### 1.3 `WechatIMG570.jpg`：不对称双栏成为课页默认操作系统

**002（左，C 话题语篇）**

- **栏数：不对称两栏**，约 **60:40**。左=语篇（「自主阅读」），右=词语摘抄 + 底部练一练。不是等宽杂志栏，是「正文 | 脚手架」。
- **天头**：上一页练习的【答案】灰底条压在 C 栏头之上——跨页组件可以骑在新栏头上，网格为内容让路。
- **栏间**：极窄中缝，几乎无装饰竖线（或细到照片里看不清）。右栏自带图标栏头（书形标 +「词语摘抄」），靠栏头而不是靠竖线分区。
- **边距**：外页边目测比 569 开篇更窄，密度页把 padding 收掉。地脚外角蓝块页码 `002`。
- **模块纵比（002）**：答案残留 ≈ 8%；语篇+摘抄主体 ≈ 72%；右下练一练 ≈ 20%。左栏几乎通高一篇文章。

**003（右，预习课对译）**

- **上段**：浅青底或白卡片，把 002 的语境题/答案收尾——对页不是「左讲右练」对称，而是**上一模块的尾巴可以占下一页天头**。
- **下段改页型**：蓝切角条 `Section I` + 英文课型名 `Reading and Thinking` +「教材帮 课文对译解读 / 预习课」。其下重新两栏：左 **原文呈现**，右 **名师圈点**，栏间**浅灰点竖线**。
- **栏比**仍约 60:40。右栏内部再竖切：译文参考、人物小传、【答案】、词语编号、拓展。
- **地脚**：外角蓝块 `003` + 品牌字。
- **模块纵比（003）**：上段练习收尾 ≈ 22%；Section 栏头 ≈ 8%；对译双栏 ≈ 70%。

**570 网格纪律一句话：** 讲解课页默认「左源文、右教辅」；栏比随功能变（语篇宽、注释窄），换课型就换栏头组件，不换开本。

### 1.4 `WechatIMG571.jpg`：精读页加第三栏，练习页回到双栏字母链

**006（左，对译精读的后段）**

- **上半约 55%：三栏**，约 **45 : 35 : 20**。左英文源文（最宽）、中汉语译文、右词语摘抄窄栏（浅底）。这是 003「原文 | 圈点」的加密版：把「译」从右栏里拆出来，单独成栏。
- **中段约 20%：通栏「图解秒懂」**。复杂句不再挤进三栏，改用括号、箭头、功能标签把句子摊平。网格为句法图让路。
- **下段约 25%：通栏细研读容器**（双线青框 + 书形标 + 顶签「细研读 | 教材深挖」），内嵌 A 课文语篇赏析。赏析是段落，不再分栏。
- **天头**：品牌「教材帮」+ 选择性必修四一类书名细线。地脚左外角蓝页码 `006`。
- **边距**：比 002 略松（图解需要上下呼吸），仍谈不上英皮式留白。

**007（右，同一课的输出页）**

- **天头右齐**：浅青条 `Reading and Thinking Section I`——课型坐标，不是装饰。
- **切口**：外缘竖向胶囊 `UNIT 1`，白字青底。样张里第一次明确的**单元拇指索引**。
- **栏数随题型变，但字母块是通栏锚**：
  - B 课文语篇结构：通栏浅灰底思维导图（可含填空）
  - C 课文阅读理解：选择题改**等宽两栏**
  - D 课文语法填空：语篇改**等宽两栏**（左栏读完接到右栏顶，报纸栏）
  - E 课文佳句临摹：两栏或通栏，每题「教材原句 / 仿写」成对
- **栏头新零件**：字母方标 + 蓝栏名 + **细青线拉到版心右缘**。换段靠这条「字母+拉线」，比 569 的线+胶囊更硬。
- **模块纵比（007，目测）**：B 结构图 ≈ 28%；C 理解题 ≈ 32%；D 语法填空 ≈ 25%；E 临摹 ≈ 15%。

**571 网格纪律一句话：** 精读把「源 / 译 / 词」拆成三栏；练把同一篇文章切成 B–E 四块，题型要并排密度时才双栏。对页是「左榨课文、右考课文」，不是左右镜像。

### 1.5 `WechatIMG572.jpg`：Point 页 = 左 2/3 讲、右 1/3 练，横向对齐

- **栏数：不对称两栏**，约 **65–70 : 30–35**。左=考点讲解，右=即时练习。011 右栏整列浅青底，比 010 的发丝竖线分栏更「栏是一种模式」。
- **水平切块单位是 Point**，不是自然段。每个 Point 在左栏开一个头，右栏对应题组尽量与该 Point **同一视线高度**——讲哪条，旁边练哪条。
- **天头**：品牌条 + 书名（选择性必修第四册）；011 右上重复 `Reading and Thinking Section I`。切口 UNIT 1 竖签同 007。
- **边距**：外页边继续收。右栏练习贴外缘，装订侧反而更松。
- **模块纵比（010，目测）**：每 Point 约占页高 22–28%，一页塞 3–4 个词条（样张可见 Point 2 残余 + 3、4 及下一条开头）。右栏被这些 Point 的练习纵向切开，底可接「视频微课」二维码或「随手记」横线。

### 1.6 `WechatIMG573.jpg`：测评页双栏题、完形改通栏+四列选项；讲解页回到 2/3+1/3

**020（左，练习帮）**

- **天头重**：品牌「练习帮」出血圆角条 + 书名 +「学业质量测评」+「答案和解析详见第217页」。练习页把**找答案的坐标**写在做题之前。
- **A 基础练**：等宽两栏短句语法填空。栏头是浅青底横条：字母方标 + 栏名 + 右端「建议用时 5 分钟」。
- **B 综合练**：完形语篇改**通栏**（比 007 D 的报纸栏更尊重「一篇」）；选项区改**四列** A/B/C/D 对齐。右缘留一条窄边放「增值练习」二维码。
- **模块纵比**：天头 ≈ 15%；A ≈ 40%；B 语篇+选项 ≈ 45%。

**021（右）**

- 上段承接 020 的选择题 13–15（四列选项），然后「记一记 词汇积累」通栏浅底框，再切到 **Section III Using Language** 切角大条。
- 其下恢复 003 的对译网格：左原文呈现、右名师点睛，约 65:35。
- 换课型不换开本：测评页和讲解页可以在同一对页相遇（020 练完，021 上半收尾、下半开新 Section）。

**全书网格可压缩成三套：** 检索三栏（INDEX） / 精读三栏或 2/3+1/3（源+脚手架） / 练习等宽双栏或通栏+选项网格。栏数服务于题型，不服务于装饰。

## 2. 色彩系统

五张均为**单主色 + 灰阶**。下列 2.1 是取样底账，2.4 是合成令牌。

### 2.1 569 色板（拍摄取样 → 设计估计）

| 角色 | 取样（照片） | 设计估计 | 出现位置 |
|---|---|---|---|
| 纸白 | `#FCFCFC`–`#FEFEFE` | `#FFFFFF` | 课页正文、INDEX 卡片 |
| 主色实地 | `#59BBEB` / `#4DA4D2` / `#5BB0DC` | **`#2EA3D8` 青天蓝** | INDEX 标签、UNIT 切角标、A/B 方标、二维码框、页码块 |
| 主色浅底 | `#C6E9F9` / `#E4F0F0` | **`#E8F6FC`** | INDEX 页底、练一练条、新考向底 |
| 结构灰 | `#E8E8EA` | `#E8E8EA` | 单元天头 |
| 正文墨 | 近黑 | `#222`–`#333` | 中英正文 |
| 次级灰 | 中灰 | `#666` 量级 | 页码、部分中译 |

569 **没有红、没有黄、没有绿**（全页饱和色聚类：红=0，黄=0）。纪律是**单主色 + 灰阶**：蓝管结构，黑管内容，浅青管「这是练习/提示」。插画也是同一蓝的线稿，不引入第三色。

### 2.2 570 把同一条蓝分成「结构 / 注解 / 底」三层

| 角色 | 取样 | 设计估计 | 出现位置 |
|---|---|---|---|
| 主色实地 | `#48A8E8` / `#48A8E0` | `#2EA3D8` 同族，比 INDEX 底更饱和 | Section 切角条、练一练胶囊、栏头、页码 |
| 注解蓝字 | 同族更亮的青 | 主色的 80–90% 明度 | 语篇行间语法注、▶ 三角、圈号 |
| 浅青底 | `#D8F0F8` / `#C8E0E8` | `#E8F6FC` | 词语摘抄局部、拓展条、上段收尾容器 |
| 答案灰底 | 浅灰（照片偏脏） | `#F2F4F6` | 【答案】块，**故意不用蓝**，避免和「教」抢 |
| 「必会」星 | 照片里仍是蓝，全页黄/红像素≈0 | 主色，不是橙 | Compare and contrast 框角 |

570 的纪律比 569 更功能化：**黑 = 源文/要做的题；蓝 = 老师动手脚的层；灰底 = 不要先看的答案。** 绿聚类全是青的邻近色，不是第三色。视觉描述里若出现「橙必会」，按像素作废——本套样张没有引入警示橙。

### 2.3 571 仍然单主色；「链接高考」也不开第三色

571 饱和色聚类：红=0，黄=0，橙=0。所谓「金星 / 高考强调色」在像素上仍是蓝（`#58A0C0`–`#5098B8` 一类，照片偏暗）。「深挖教材 链接高考」用蓝星 + 蓝小字，**高考锚点不加红**。

新增只用灰：B 结构图浅灰底（约 `#F2F2F2`），把导图从练习题里托出来。灰=分组，蓝=导航，和 570 的答案灰同族。

### 2.4 572–573 仍是单主色；「基础练 / 综合练」是栏目名不是彩章

572、573 饱和红/黄/橙像素聚类均为 0。个别画面描述里的绿章、橙章、红点「附」标，**不能被像素坐实**，不进色板。`课标词` 星、`联想串记` 框、练习帮 A/B 条，全部走青天蓝 + 浅青底 + 灰标签。

**五张样张合成色板（设计估计）：**

| 令牌 | hex（估计） | 职能 |
|---|---|---|
| `brand-blue` | `#2EA3D8`（实地；照片 `#48A8E8`–`#59BBEB`） | 栏头、Point、字母方标、页码、二维码框 |
| `brand-blue-wash` | `#E8F6FC` | INDEX 底、练习栏底、积累框、练一练条 |
| `ink` | `#222`–`#333` | 源文、词目、题干 |
| `ink-dim` | `#666` | 中译、页码数字、常见搭配灰标 |
| `paper` | `#FFFFFF` | 正文 |
| `ash` | `#F2F4F6` | 【答案】、结构导图底、分组而不强调 |

**纪律：有。** 主色只做结构导航；灰做「次要/答案/分组」；禁止用红黄当易错或高考。第三色在本批不存在。这比项目共识里「局部允许第三色」更严——教材帮用**层级和栏**承担警示，不用色相。

用色数量：有效色相 **1**（青蓝）+ 灰阶 3–4 档。插画/二维码不引入新色相。

## 3. 字体层级与中英混排

中文：黑体管界面，宋体管要读的知识。英文：栏名/词目无衬线，语料衬线。中译在扫词页与英文等大，在用法页和精读页必须降对比、降字号。

### 3.1 中文层级（569）

| 角色 | 形态 | 例 |
|---|---|---|
| 产品栏名 | 粗黑体，白字坐蓝底或蓝字坐浅底 | INDEX 旁中文导航；「单元素材积累」 |
| 知识点题 | 黑、偏宋/书刊体，比栏名小一到两级 | 「动词不定式」「知识点 2」 |
| 导图中译 | 与英文词条同行、字号接近 | `space exploration 太空探索` |
| 佳句中译 | 英文句下一行，略小或略浅 | B 栏每句下的翻译 |
| 提示/考向 | 黑体小标 + 宋/黑混排说明 | 「新考向」 |

INDEX 把 **UI 用黑体、知识条目用偏宋**，课页栏头继续黑体。这是中文教辅的默认操作系统：黑体=界面，宋体=要读的知识。

### 3.2 英文怎么跟中文共处（569）

**做得好**

- **角色分工**：栏名/UNIT 用无衬线大写（`INDEX`、`UNIT 1`、`SCIENCE FICTION`）；引语和话题佳句改衬线（Times 血统），和中文讲解体形成「语料 / 讲解」两套声部。
- **导图同行对译**：英文词条 + 空格 + 中译，**不用冒号、不用括号**，同一基线。词表扫描效率高。
- **佳句上下叠**：英文一行、中译紧贴其下；条目与条目之间空隙大于英汉行距——先认「这是一句」，再读翻译。
- **练习句内支架**：完形段落在空白处用中文提示 `(太空探索)`，学生不用离开语境去翻词表。

**做得差**

- **INDEX 听力段中英竖混**：`Reading and Thinking` 这类英文课型名和「单词录音」挤在同一窄栏，英文偏长、中文偏方，**右缘锯齿**，页码仍右齐，眼跳对不齐。没有字号补偿到「英文视觉灰度 = 中文」。
- **导图末端过载**：`benefits` / `problems` 枝上词条一长，英汉同行 + 下划线列表把行距吃掉，中文降部会顶到上一行英文。树形救了分类，救不了枝端密度。
- **天头英文过大、引语过小**：`SCIENCE FICTION` 海报级无衬线 vs Asimov 衬线引语，层级对，但引语几乎成装饰，不像要记的输入。

### 3.3 570：行间注是混排的高光，也是翻车点

**中文层级补丁**

- 栏头/课型：粗黑或白字蓝底（`C 话题语篇`、`Section I`、`预习课`）。
- 列名胶囊：较小黑体（`自主阅读` / `自主学习` / `原文呈现` / `名师圈点`）。
- 行间语法：更小的黑体或细黑，**改蓝色**，前加 ▶。
- 词条释义、译文：偏宋，黑，词表里 IPA 夹在英文和中义之间。
- 标签四字：黑体缩进胶囊（`熟词生义`、`教材帮原创`、`拓展`）。

**英文**

- 语篇、教材原文、题干：衬线（Times 血统），书名斜体（*Frankenstein*）。
- 词条本身：加粗衬线或加粗无衬线，比释义大半级。
- 课型名 `Reading and Thinking`：蓝字衬线，挂在 Section 条下，像教材目录的回声。

**做得好**

- **行距为注解留槽**：源文行距拉到约 1.6–1.8，蓝色中文语法注嵌在行间，不另开脚注区。学生不用离开句子。
- **上标桥**：`fiction②` 这类上标把左栏源文钉到右栏词表，源文保持可朗读，重词不在句内展开。
- **词条五件套同一行**：词 + IPA + 词性 `[C, U]` + 中义 + 偶发标签。英文字号略大于中义，灰度接近。
- **对译页左源右译**：003 原文栏英文大、译文栏中文小且更挤——字号差在说「先读左」。人物小传等中文块只出现在右栏，不污染源文栏。

**做得差**

- **行间注连排三行**（002 语篇中段）：英语节奏被蓝注撕开，朗读线断掉。注解密度一旦超过「每两句一条」，混排从支架变成噪声。
- **▶ + 蓝字 + 上标 + 下划线同时上场**：同一句上四种指示符。中文注已经染色，上标还在抢。
- **译文栏过窄**（003 下）：中文被切成碎行，作为「对照」可用，作为「阅读」不可用。英汉行高没有锁齐，对译会错位。
- **词表非表**：词、音标、中义只是串在一起，没有悬挂缩进或音标固定栏，回看某一词要重新扫描整段。

### 3.4 571：三栏对译的字号补偿，以及「原句 / 仿写」的声部

**做得好**

- **三栏各司其职**：左衬线英文最大、行距最宽（给行间注）；中宋体译文明显更小、行距更紧；右词表更小一号。学生靠字号就知道「读哪一栏」。这是 569 导图「英汉同行等大」的反面——精读需要对译，所以故意让中文让路。
- **E 佳句临摹的括号注**：教材原句里划虚线的结构后面跟灰小字 `(it is/was + adj. + that 从句)`。英文保持衬线可朗读，方法论缩成四级灰注，不另开方法框。比 570 的行间 ▶ 注更克制。
- **仿写题中英分工**：原句英文、仿写题干中文 + 下划线作答区。语料和任务语言换栏/换行，不混在同一视觉层。
- **结构图里的英文句子**用衬线，框线当层级；中文只出现在 B 的栏名。主题结构用英语想，元说明用中文标。

**做得差**

- **三栏对译对不齐**：英汉长度差导致中栏换行和左栏行对不上，号称「对照」实际是「邻置」。没有锁行高。
- **图解句上下同时注**（006 中段句【2】）：箭头向上标从句类型、向下标句法功能，英文字号被撑开，中文标签在句周围飞。句法课可以，阅读课过载。
- **赏析段蓝下划线打在中文段落上**（006 底）：强调「明线 / 暗线」一类术语时，整段变网，宋体长文被划碎。
- **D 语法填空双栏断篇**：英文语篇从左栏底接到右栏顶，阅读节奏像报纸，不像完形。中文教辅常这么省版面，英语语篇吃亏。
- **C 与 D 视觉皮肤相同**：都是字母方标 + 双栏正文，阅读理解和语法填空只靠栏名字面区分，题型换了层级没换。

### 3.5 572：词条页把英文词目做成「字号最大的物体」

**层级**

- Point 词目（`guilty` / `dismiss` / `declare`）：粗无衬线，全页最大英文，**黑不是蓝**。蓝留给 `Point n` 块。词是内容，编号是界面。
- 教材语境句：衬线，常斜体，表示「这句来自课本」。
- 例句：衬线英文 + 下一行更小/更浅的中译；目标词加粗或下划线。
- 用法标签：`用法详解` 蓝黑体 + ▶；`常见搭配` 灰胶囊，降一级。
- 词性 `(1) adj.` `(2) vt.` 黑粗，领起义项。

**做得好**

- **中译降对比**：011 例句中文走 `ink-dim`，学生先读英语结构。569 导图「英汉等大」适合扫词，词条页适合学用法——混排策略按页型切换。
- **大括号收搭配**：`dismiss … as / from` 用花括号把共享动词的补足语收成一棵树，搭配是工具箱不是重复例句。
- **英汉句对内紧外松**：例与其译文行距 < 例与例的段距。

**做得差**

- **一词条五种英文姿态**：斜体语境 + 粗词目 + 蓝标签 + 下划线 + 括号公式，词目最大是对的，其余没有再分层。
- **英汉有时逗号硬接同行**：基线冲突，不如「英文一行、中文一行」。
- **右栏练习字号注释级**：「随手记」横线间距不够写汉字，点线空按印刷密度排、不按手写密度排。

### 3.6 573：纯练页混排最干净；元数据改浅蓝色

**做得好**

- 题干英文衬线、指令中文黑体/宋体。中文只当题型名和作答说明。
- **句末场景/来源**用浅蓝小字：`[应用文写作之学生课外生活]`、`(新高考 I 卷)`。元数据让路。
- **单元复现词用手写体**（练习帮天头说明）：用字形而不是第三色做「本单元要回收的词」。
- **完形选项四列对齐**：A/B/C/D 纵向成栏，涂卡预演清楚。

**做得差**

- **020 天头四层横条**：Logo、测评名、答案页码、手写体说明叠在 A 栏头之前，还没做到题已经过载。
- **021 点睛栏**再次把 IPA、粗词、中义、拓展塞进 35% 宽——003 的窄译栏问题复发。
- **本批未见独立「易错」红框。** 易错由 `熟词生义`、`课标词`、旁栏练承担，不要脑补警示色。

## 5. 考点组织逻辑

中魂核心。视觉皮可以全扔，下面这条流水线要留下。

### 5.1 569 已经给出的两套切块法

**左页 INDEX 不是按单元线性目录，是按职能横切：**

1. 各 UNIT 的语法/知识点（同步教材顺序）
2. 跨 UNIT 的「写作 & 解题方法」合集
3. 跨 UNIT 的听力/录音资源

学生可以「我要刷方法」而不必先知道它在第几单元。这是讲解型同步书把**教材单元序**和**题型/方法序**叠在同一张检索上。

**右页单元开篇走「输入脚手架 → 立刻输出」：**

1. 主题锚（单元名 + 一句名人语料 + 听写码）
2. **A 话题词汇**：按议论逻辑分枝（themes / types / benefits / problems），不是字母表
3. **B 话题佳句**：把词送进可背的整句
4. **练一练 语境应用**：同一批词立刻进语篇填空
5. **新考向**：用一句话把刚才的练接到考试要求

讲与练在开篇页的面积比大约 **8:2**（导图+佳句 vs 一道语境练习）。这里的「练」是巩固输入，不是大题量。题量逻辑要到后面的讲练页才展开。

方法论在 569 的位置：INDEX 把它提升为和知识点并列的检索层；课页里则缩成「新考向」旁注，还不占主栏。

### 5.2 570 的课页闭环：语篇页「读–摘–练」，教材页「原文–圈点」

**002 话题语篇（教辅自编阅读，标「教材帮原创」）**

1. 左栏整篇输入（科幻/Frankenstein 类主题语篇，接 001 的素材积累）
2. 句内蓝注 = 当场语法微课（不另开「语法角」）
3. 右栏词语摘抄 = 考点词表（熟词生义、词链是考点类型，不是字典）
4. 右下练一练 = 2 道理解题，当页输出
5. 【答案】可出现在本页顶或对页顶，讲练答案不集中到书末

讲与练面积比大约 **8.5 : 1.5**。题量故意小：这页的魂是「把一篇文章榨成考点」，不是刷题。

**003 预习课对译（对齐教材 Section I）**

1. 栏头声明课型 = 教材目录的镜像（Reading and Thinking）
2. 左原文 / 右名师圈点，上标或画线把两边钉住
3. 方法框（Compare and contrast）插在「题目要求你做这件事」的当下，而不是章末技巧汇总
4. 人物小传、译文参考、拓展、详见 Pxxx 都是右栏插件，左栏保持像教材

**字母链 A→B→C 现在可以读成组织规则：** 积累（词/句）→ 语篇应用 → 才进入教材课文精读。教辅先喂主题语言，再带学生回教材。这是同步讲解型相对纯练习册的核心差异。

### 5.3 571 把同一篇课文切成「榨干四刀」——中魂的完整题量逻辑

页码从 003 跳到 006：样张缺 004–005，但 006 仍是 Section I 原文后段（上标已到 ③③ / ③④），007 立刻进入输出。精读可持续多页，输出收在一页。

**006 仍是讲（把课文榨成可教的零件）**

1. 源文（左）  
2. 逐段译文（中）  
3. 随文词表（右，编号跟着课文走）  
4. 抽难句做图解（方法：看见从句）  
5. 语篇赏析（明线/暗线、叙事逻辑）+「链接高考」钩子  

讲的内部比例：对译三栏最大，图解次之，赏析最小。赏析不是文学课，是把篇章结构说成可考的话。

**007 是练（把零件还原成四种高考题型）**

| 块 | 课内名称 | 对应能力 | 题型 |
|---|---|---|---|
| B | 课文语篇结构 | 抓骨架 | 导图填空 |
| C | 课文阅读理解 | 抓意思 | 四选一 |
| D | 课文语法填空 | 抓形式 | 语境填空（给提示词） |
| E | 课文佳句临摹 | 抓产出 | 原句 → 公式 → 中文仿写 |

**讲与练的对页关系：** 左页几乎 100% 讲，右页几乎 100% 练。比 002「一篇文章旁边塞两道题」更干净。方法不再独占栏目，而是嵌进 B 的图式、E 的括号公式、006 的图解箭头。

**字母在本套书里会重置：** 001 的 A/B 是素材积累；006 底的 A 是赏析；007 的 B–E 是练习链。字母是**当前页型内部的序号**，不是全书唯一 ID。蒸馏时不要做成全局 A1、A2。

### 5.4 572：语言点的标准原子——中魂最可执行的一块

Reading 课型在课文四刀之后，进入 **Point 词条页**（010–011 仍挂 `Reading and Thinking Section I`）。每个词是一个封闭循环：

1. **Point n + 词目**（可标课标词）
2. **教材语境**（必须引用课本页码和原句）
3. **用法详解**（按词性义项）
4. **常见搭配**（括号树）
5. **双语例句**
6. 可选插件：联想/语境串记图、派生便利贴、视频微课码
7. **右栏同高练习**（语法填空 / 完成句子；可挂名校期中来源）

讲与练面积比约 **2:1 到 7:3**。题量小、对准刚讲的那一个词。这是「考点」的定义：**不是主题，是一个可考的词/结构，带课本出处，带当页题。**

方法论嵌入方式：词族流程图、串记语篇、括号公式，全部住在该 Point 内部。没有「本章语法技巧」总表。

### 5.5 573：讲完之后的题量爬坡，以及下一课型的接缝

**020 练习帮 = 纯练页，零讲解。**

- A 基础练：单句语法填空（知识巩固）+ 建议用时
- B 综合练：完形一篇（能力提升）
- 天头直接给答案页码（第 217 页）——测评和详解分离，和 570 的同页灰答案是两种答案策略：课内微练同页，单元测评翻到书末

难度逻辑是阶梯，不是换口味：旁栏 1–4 小题（572）→ 课文四种题型（571）→ 计时基础练 → 综合语篇。同一知识点会被考三次以上，这就是中系「题量」。

**021 接缝：** 测评余题收完 →「记一记」回收词 → Section III Using Language 重新开对译。单元内部课型按教材目录走（Reading and Thinking → Using Language），教辅只在每个课型里重复「对译 + 点睛 + 再 Point」的机器。

## 6. 信息密度策略

（569）INDEX 条目数高，但三栏 + 胶囊分段让密度落在「可检索」而不是「可阅读」。课页开篇上半疏（灰天头留白）、中段密（导图）、下段中密（双栏句）。乱的地方集中在导图枝端和 INDEX 听力墙——分类对、单元格过小。

（570）密度跳到全套最高：外页边收窄、行间注填满行距、右栏词表 10+ 条。**不乱的原因**是职能分栏（源文永不和词表抢同一栏）和单色染色（蓝=教、黑=读）。**乱的原因**是同一栏里指示符叠加（▶、上标、下划线、标签）和行间注过密。002 右栏词表是「工厂密度」——信息都在，扫描成本高。003 用点竖线和胶囊栏头把对译页从「墙」拉回「两列对照」，比 002 右栏更可读，仍无呼吸带。

（571）006 三栏是「对照密度」：每栏职能单一，所以密而不串。图解段局部变疏（句子周围要放箭头）。007 比 002 更可读，因为 B/C/D/E 有拉线栏头和段间空白；C 选项还有意拉开行距。乱点转移到图解嵌套和 D 栏的断篇。总体策略仍是：**宁可挤，不翻页**——同一课文的讲与四种考法尽量落在一对页附近。

（572）Point 页是「模块密度」：单点信息很多，但 Point 头把页切成可跳读的块。乱来自块内纹理（括号、图、标签、旁栏同时响）。右栏浅青底帮了一把——讲白、练青，比 002 词表墙更容易找输出区。

（573）020 基础练双栏仍然密但干净（一题一空、行距给手写）。完形选项四列是「表格密度」，有序、闷。021 上半测评+积累+Section 头三件事碰头，接缝处最挤。

**总策略：** 密度为「一课一站买完」服务，用分栏和单色保秩序。乱，是因为同一格里指示符太多，不是因为栏数错。自创框架若偷中魂的组织，密度应向日骨收、皮向英皮收，不要把 002 词表墙和 020 天头四条一起搬过来。

- **无引导线的三栏页码**（`WechatIMG569.jpg` 左）：短中文题与右齐页码之间空白过大，扫描会串行。

## 8. 可蒸馏基因清单

只收**内容组织**规则（中魂）。视觉皮（切角条、细纹底、吉祥物、彩虹章）不进。每条可直接写进 schema。

1. **单元流水线锁死为五段，不许打乱。** 主题积累（词表按议论枝分，不是字母表）→ 自编语篇微练 → 教材对译精读 → 语言点 Point 循环 → 基础练/综合练测评。先喂主题语言，再进教材，再把词做成考点，最后用阶梯题量回收。出处：`WechatIMG569.jpg` 右 + `WechatIMG570.jpg` + `WechatIMG572.jpg` + `WechatIMG573.jpg`。
2. **考点原子 = 一个 Point。** 顺序固定：课本原句（教材语境 + 页码）→ 用法义项 → 常见搭配树 → 双语例 → 旁栏同高 1–4 题。方法（词族图、串记、微课码）只许住在该原子里，不准另开「本章技巧」。出处：`WechatIMG572.jpg` 010–011。
3. **同一篇课文结束前必须切四刀。** 骨架（结构图/填空）→ 意思（阅读理解）→ 形式（语法填空）→ 产出（原句 + 公式 + 仿写）。讲在左页或前页榨零件，练在右页按高考题型还原。出处：`WechatIMG571.jpg` 006–007。
4. **源文和教辅分栏，用上标桥连接。** 左栏保持可朗读；释义、语法、译文进右栏或中栏。行间注可以有，但每页条数要有上限，禁止四种指示符叠在同一句上。出处：`WechatIMG570.jpg` 002–003、`WechatIMG571.jpg` 006、`WechatIMG573.jpg` 021。
5. **方法钉在「此刻要用」的位置。** Compare and contrast 跟题指令；图解秒懂跟难句；联想串记跟该词；括号公式跟仿写原句；新考向贴在当页练习旁。出处：`WechatIMG569.jpg` 右下、`WechatIMG570.jpg` 003、`WechatIMG571.jpg` 006 与 007 E、`WechatIMG572.jpg`。
6. **练分三级，答案策略随级变。** ① Point 旁栏即时练：同页、浅底。② 课文四种题型：对页输出。③ 计时测评：基础练→综合练，栏头写建议用时，题尾可挂场景或真题卷名，答案改指书末页码。出处：`WechatIMG572.jpg` 右栏、`WechatIMG571.jpg` 007、`WechatIMG573.jpg` 020。

# 柱式合成版：①填满 + ③按需通栏

2026-11-04。起因是所有者看主线稿时问：「为什么左边大部分全部空？」

实测结论：主线稿四页里，左柱面积只有 4–7% 有字，右边正文栏是 25–30%。柱只学到了 Evergreen 的位置，没学到它的内容。

## 过程

1. 在设计画布（`澄页 品牌色样张`，第四行）上用同一页内容排了三种柱的处理：
   - ① 填满：短句、旁注、小图都放进柱；
   - ② 变窄：柱缩到 4 字，只放标签；
   - ③ 按需：宽块排满通栏。
2. 所有者选 ①+③ 合成，短句由负责人先提炼。第五行排出合成版两页。
3. 负责人渲染自查后列出 7 处不好看。所有者让修第 2–6 处；第 1 处（页中间空白）按负责人建议放宽规则。第 7 处（整体偏素）等品牌色定了再处理。
4. 写回规范与 `主线.css`，用 Vivliostyle 出 PDF。

## 定下来的规则（已写入规范）

| 决定 | 规范位置 |
|---|---|
| 柱里放「名字」和「柱注 `gloss`」：9pt，最多两行，写成「关键词 → 结论」，只从本块内容提炼 | 02 `gloss`；03 §0、§2a |
| 注首选放进 `explain`，紧挨它解释的段落，住进柱 | 02 `note`；03 §2a |
| 辨析表、要点卡、练一练排满通栏；表格可带时间轴列（`point` / `span` / `two`） | 03 §0、§2a；02 `compare` |
| 主色只给编号（考点号、例题号、练习题号、语篇空号、页码）和图解图形；柱里文字标签一律墨色 | 01 §2 规则 3 |
| 例题可跨页：题干不断开、题干后不断页，解析至少前两行与题干同页（取代 08-27「例题整体不断页」） | 03 §1、§3 |

## 已知局限

- **续页没有「解析（续）」标记。** 画布样稿里有，CSS 做不到：Vivliostyle 无法判断一个块在新页上的续段。续页开头就是解析的后半段，靠柱的位置能认出来。要做的话，得在内容里显式拆块。
- **考点末页底部留白。** 1.1 第 2 页、1.2 第 4 页各空约三成。这是「考点从新页起」的结果，按书籍章末通例接受。如果要填满，就得放宽这一条，让下一个考点接在同页开头。
- 1.2 第 4 页开头只剩「故填」一行加旁注，就被翻到了次页。这符合「至少前两行同页」的规则，但看着有点碎。内容更长的考点里会更常见，规则是否收紧，等多排几个考点再定。
- 品牌色仍待定（画布三方向），合成版暂用现行沉靛青。

# 第一步：诊断

对象：`渲染/样章-谓语动词.html`（现行验收样章）。本步只测量，不改任何东西。

- 渲染：Vivliostyle CLI 11.2.0 / core 2.45.0，浏览器 Chrome for Testing 153（`--executable-browser`），产出 5 页 A4。
- 测量：`工具/measure.py`（PyMuPDF 抽取每行文字的字体、字号、颜色、坐标，以及矢量图形）；`工具/squint.py`（拼对页、灰度 + 高斯模糊 6px 的眯眼图）。
- 图：`01-诊断图/`（100 dpi）。对页按书页实际摊开拼：2|3、4|5。第 1 页为右页，单独出图。

复现：

```bash
渲染/node_modules/.bin/vivliostyle build 渲染/样章-谓语动词.html -o <out>/谓语动词.pdf --timeout 120
python3 -I 调研/视觉重做/工具/measure.py <out>/谓语动词.pdf <out>/rows.json
```

## A. 测量结果

### A1. 行长：英文严重超长

| 文字 | 实测每行 | 版心宽 | 备注 |
|---|---|---|---|
| 英文题干 / 语料（STIX 10.5pt） | **108–117 字符**（通栏行），练习行 90–94 | 169–179mm | 英文正文惯例区间 45–75 字符（Bringhurst）；超上限约 50% |
| 中文讲解（Noto Serif SC 10.5pt） | 42–56 字（英文按半字计） | 同上 | 合理区间待第二步用标杆实测定 |

单栏通栏 + 10.5pt 是根因：`01 §1` 规定课页单栏纵栈，却没有给行长设上限。版心宽度由页边距反推出来，不是从行长推出来的。

### A2. 字号：级数多、级差小，层级被噪声淹没

- 5 页 PDF 实际出现 **10 个字号**（6.5 / 7.5 / 8 / 8.5 / 9 / 9.5 / 10 / 10.5 / 12 / 14pt），字体 × 字号 × 颜色组合 **35 种**。
- CSS 里写了 **21 个不同的 `font-size`**，规范 `01 §3` 只定义了 9 级。CSS 用到而规范没有的：6.5、7、8.5、9、11、12、13、13.5、16、22pt。规范定的「专题大标题 20pt」在 CSS 里根本不存在。**规范与 CSS 已经脱节**（AGENTS.md：冲突时以规范为准、改 CSS）。
- 正文族在 9 / 9.5 / 10 / 10.5pt 之间以 0.5pt（约 5%）为一级。这个差别肉眼几乎分不出，形不成层级，只是让灰度不均。
- 内容页最大字号是节头 14pt，对正文 10.5pt 的比例为 **1.33**，只差一级。对比之下，最强的标记反而是 6.5–7.5pt 的白字色签（真题出处、栏签）。
- 白字坐色签用到 **6.5pt 粗体**（共 35 字符），已到印刷可读性的下限。

### A3. 层级倒置（眯眼测试）

见 `01-诊断图/眯眼-2-3.png`、`眯眼-4-5.png`。模糊后，整组对页最暗的点依次是：页眉坐标角标 → 真题出处芯片 `[2025·北京卷]` → 「解析」灰签 → 节号方块。节标题（「1.2 主语与动词定语态」）的分量和出处芯片相当。

结论：**元数据比内容标题更响**。读者的视线先落到「哪年哪卷」，然后才是「这一节讲什么」。整页其余部分是一片均匀的浅灰，没有入口。

### A4. 框套框

带描边、宽 >100pt 的框：第 1 页 **5 个**，第 2 页 3 个，第 3 页 3 个，第 4 页 5 个。

「例题框 + 解析框」上下两只等重的直角描边框紧贴，解析框再挂一个灰签。加上提示框、要点卡（圆角 + 投影 + 菱形图标）、表格横线，一页之内有四种容器语言并存。框线成了页面的主旋律，内容反而退后。

### A5. 左缘对齐轴不唯一

第 1 页左缘起点（mm，出现 ≥2 次）：16.0 / 18.2 / 19.3 / 19.4 / 21.2，5mm 之内有 5 条轴，另有 19.3 和 19.4 这样的 0.1mm 漂移。框外文字和框内文字相差 3.3mm 左右，视线每进出一次框就横跳一次。偶数页同样如此（14.0 / 15.0 / 17.4 / 17.5）。

规范 `01 §4` 要求「左缘纵轴 一条」，实测没有做到。

### A6. 没有基线网格

5 页内相邻两行（>5pt）的基线距出现 **70 种不同取值**。块间距由每个组件各自的 margin 加 padding 拼出来，不落在任何统一单位的倍数上。左右两页的行不对位（对页图上可直接看到）。

### A7. 断页与页面填充

版心底边约在 279mm（297 − 18）。各页正文最低基线：

| 页 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 最低基线 mm | 268.6 | **226.2** | 245.9 | 246.1 | 213.5（册末） |
| 底部空白 mm | 10 | **53** | 33 | 33 | — |

- 第 2 页底部空出 53mm（约版心高度的 20%），同一对页的第 3 页却排得很满，左右轻重失衡。
- 第 3 页（右页）底部开始讲 1.3 节：节头 + 讲解 + 句型 + 表格都在这一页，它的例题却在翻页之后的第 4 页。**一个考点被翻页切开**，而且切在右页，读者必须翻页才能接上。

### A8. 中西混排：没有做字号补偿

fontTools 实测（单位 = 1em）：

| 字体 | x 字高 | 大写字高 | 表意字面框（「中」） |
|---|---|---|---|
| STIX Two Text | 0.473 | 0.657 | — |
| Noto Serif SC 自带拉丁 | 0.514 | 0.729 | −0.078 ~ 0.838（0.916） |
| Noto Sans SC 自带拉丁 | 0.543 | 0.733 | −0.079 ~ 0.840 |

讲解句里夹的英文，STIX 和中文一样都是 10.5pt，没有做补偿。按 x 字高算，它比思源宋体自带的拉丁字母小约 8%（0.514 / 0.473 = 1.087）。所以句中英文看起来「缩了一号」。`00-项目共识` 把中西字体配对列为核心资产，`01 §3` 却只写了断行、括号等 5 条，没有补偿值。

### A9. 规范明令禁止、样章里仍然存在的网页惯用语

按 `01 §6` 的判据「印刷品里见过吗」：

- 提示框左上角的圆形「i」信息图标，是 UI 图标语言。
- 要点卡：圆角 + 投影 + 左侧菱形图标 + 竖分隔线，是网页卡片（card）的造型。
- 节头从标题一直拉到右端考频芯片的细线：功能上是网页的 `<hr>` 和徽章（badge）组合。

以上是负责人的判断，不是测量值，留到第四步的盲测去检验。

### A10. 已达标项

- `pdffonts`：6 款字体全部为 CID TrueType，嵌入、子集化，**零 Type 3**。
- 色彩纪律基本守住：只用了一个路标色 `#1E6F8C`，没有引入第三个色相。

## B. 规范里「凑出来的数值」

`01 §4`「生产间距（2026-08-25，冠词配平定版）」逐个 class 给值，彼此之间没有推导关系：

| 位置 | 值 |
|---|---|
| `.toc li` 行距 | 0.2em |
| `.tip` 内边 / 行高 | 2.5/2.2mm、1.5 |
| `.explain` 行高 / 段距 | 1.62、0.28em |
| `.subhead` | 0.1/0.35em |
| `.compare td` | 0.22em |
| `.stem` 与解析间距 | 1.6mm |
| `.solution` 行高 / 底边 / 段距 / 顶 pad | 1.58、2.2mm、0.26em、4mm |
| `.evidence` | 0.15/0.2em |
| `.solution aside p` | 0.4em |
| `.keypoint` 行高 | 1.55 |
| `.drill` 线内顶距 / 栏头下 / 原子题行距 | 1.5mm、1.8mm、0.42em |

同一份规范里，正文行高出现了 1.5 / 1.55 / 1.58 / 1.62 / 1.7 / 1.75 六种，单位混用 em、mm、无单位倍数。CSS 中共有 **152 个不同的尺寸值**（pt/mm/em/px），**269 条 class 规则**。

这是「哪里挤了就改哪里」的结果：每次配平都给单个 class 加一个小数，系统在不断变复杂，但没有变得更一致。

## C. 规范缺失的正面主张

| 缺什么 | 后果 |
|---|---|
| 基线单位（所有纵向间距的公约数） | A6：70 种基线距，对页不对位 |
| 版心按「每行字数 × 每页行数」定义 | A1：行长是被动结果 |
| 英文行长上限 | A1：108–117 字符 |
| 字号比例（模数）与最少级差 | A2：0.5pt 一级、节头只比正文大一级 |
| 视线顺序：每个页型先看什么、再看什么 | A3：元数据压过标题 |
| 容器预算：一页最多几只描边框、几种容器语言 | A4：一页 5 只框、4 种容器语言 |
| 断页规则：考点不跨右页翻页、对页左右填充差的上限 | A7：53mm 空白、考点被翻页切开 |
| 中西混排的补偿值与基线偏移 | A8：句中英文小约 8% |
| 参照图：每条规则配一张「对 / 错」样图 | 全部规则只能靠读文字理解，Agent 和人都会读偏 |

规范目前是「禁令 + 补丁」结构：`01 §6` 有 8 条禁止，却没有一句话描述这本书正面应该长什么样。

## D. 待第二步解决的问题

1. 英文行长上限定多少：按标杆实测（《English Grammar in Use》《Evergreen》）确定。改法有三种可能：缩窄英文块、改双栏、或放大字号，第三步出方向时比较。
2. 中文行长区间、基线单位：按标杆和 GB 40070-2021 的条款确定。
3. 中西字号补偿值：用 fontTools 的度量数据算出，再按 100% 原大打样，用眼睛校验。
4. 「元数据过响」的修法：降芯片的对比度，还是提标题，或者两者都做。第三步的 3 个方向分别给出不同答案。

## 本步局限

- 诊断图是 100 dpi 的屏幕图，还**没有按 100% 原大打印到纸上**校验。A3、A9 两项的视觉判断要以实物打样为准。
- 只诊断了一份样章（谓语动词）。语篇精讲和册级件页型没有测，但 A2、A6、B、C 属于全局问题，那两个页型也会有。

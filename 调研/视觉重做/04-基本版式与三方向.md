## 一、基本版式（三方向共用）

依据 clreq 7.1.1.4，版心由字号、字数、行数、行距决定，不再从页边距反推。

| 项 | 值 | 依据 |
|---|---|---|
| 正文字号 | 12pt（小 4 号），思源宋体 | GB 40070 高中正文 ≥ 小 4 号，以宋体为主 |
| 行距 = 基线单位 u | **21pt**（7.408mm），行空 9pt = **3.175mm** | GB 40070 行空 ≥ 3.0mm |
| 半格 | 10.5pt：块与块的间距、块内边距都取半格的整数倍；块内行距恒为 u | clreq 7.1.1.3 标题地位取行数整数倍 |
| 版心 | **42 字 × 35 行** = 504 × 735pt = 177.8 × 259.3mm | clreq 7.1.1.4 |
| 页边 | 天 16mm，地 21.7mm，订口 18mm，切口 14.2mm；左右页镜像 | — |
| 辅文最小字号 | 9pt（栏签、出处、页脚） | GB 40070 辅文 ≥ 小 5 号 |
| 中文段落 | 两端对齐；行尾全角标点压半宽，相邻标点挤压（`text-spacing-trim: trim-both`） | GB/T 15834 5.1.10；clreq 6.2.3、6.3.2 |
| 讲解句内的拉丁 | STIX × **1.12**（`@font-face size-adjust`，只作用于拉丁字符；中文引号、破折号、省略号仍走思源宋体全角） | 03 §二，候选中值 |
| 独立英文语料块 | STIX 12pt，左对齐，不补偿 | 01 §3 |
| 强调原子 `em-atom` | 加粗，不换色 | 02-标杆对照 §4.1 |
| 引号 | “ ” ‘ ’ | GB/T 15834 4.8.2 |

**技术验证（本步实测，不是推测）**

1. **行尾标点压半宽可行。** Vivliostyle 2.45 + Chromium 153 下，`text-spacing-trim: trim-both` 生效：行尾逗号的空白半边伸出版心，墨迹落在版心内。写法 `text-spacing: trim-start allow-end …` 不生效。
2. **`size-adjust` 可行。** 拉丁实测 13.44pt（= 12 × 1.12），汉字仍为 12pt。
3. **基线网格的关键是统一度量覆盖。** 一开始只修行距，对齐率只有 7%。原因是同一行里混了思源宋体、思源黑体、STIX，各自的 ascent/descent 不同，行盒被撑高 0.5–2pt；表格单元格的默认内边距也在破坏网格。修法：给所有字体统一 `ascent-override: 88%; descent-override: 12%`；en-mix 因为放大了，改用 83.9% / 16.1%，使基线位置与 12pt 汉字一致；单元格纵向内边距清零。修完后对齐率 **90–100%**（半格网格，容差 0.6pt）。剩下的偏差来自 10.5pt 的「注」和列表编号，单处漂移 ≤ 0.4pt。
4. **Vivliostyle 不读入口文件目录之外的文件。** `../fonts` 会静默回退到系统字体（文泉驿、Liberation），而且不报错。所以 `方向稿/` 里放了指向 `../fonts` 的符号链接 `fonts`。
5. **STIX 没有 → (U+2192) 和 ▸ (U+25B8)。** → 由字体栈回退到思源宋体，没有问题。▸ 会回退到 DejaVu，已换成 › 和 ▶。今后选用符号前要先查字体覆盖。

## 二、三个方向

三个方向的内容完全相同，都是谓语动词 1.1 + 1.2，并按规范 02 改写：例题编号由 CSS 计数生成，练习全单元连续编号，引号改为“”。

### A · 柱式 — 「左柱放骨架，右栏放内容：扫一眼左柱就知道这一页讲什么。」

- **网格**：柱 8 字 + 栏距 1 字 + 正文栏 33 字（英文约 79 字符）。
- **柱里放什么**：小标题、「句型」「例 1 [出处]」「解析」「要点」「注」「练一练」。正文栏里只有内容。
- **容器**：只有要点卡一种（浅青底，记忆层），全稿零描边框。
- **参照**：Evergreen 的柱、Genius 的「强调换字族」（解析标签用黑体加主色）。
- **眯眼图**：最暗处依次是考点标题、柱标签、要点卡。诊断 A3 的层级倒置已纠正。
- **代价**：柱占掉版心 21% 的宽度，页数会增加。柱里的标签都很短，左柱下半部常常是空的。

### B · 对页单元 — 「一个考点一组对页：左页讲清，右页练完，翻页即换考点。」

- **网格**：签栏 4 字 + 栏距 1 字 + 底块 37 字（块内左右各 1 字，文字宽 35 字，英文约 84–87 字符）。
- **断页纪律**：考点从左页起，第二道例题强制起右页。1.1、1.2 都正好排满一组对页（1|2、3|4）。
- **容器**：结构层浅灰底块，包括「讲」和「例 n」，例题题干是灰底里的白色内框；记忆层浅青底（要点）。签栏里是白字坐色签。零描边框。
- **参照**：English Grammar in Use。
- **代价**：
  - 断页规则要求内容服从版面：一个考点的「讲 + 例 1」必须放得下一页，「例 2 + 要点 + 练」必须放得下另一页。内容放不下时只能拆考点（02 schema 要加这条约束），CSS 救不了。
  - 灰底面积最大，自印时墨量最高。
  - 英文行长 84–87 字符，三个方向里最长。

### C · 书页 — 「像一本好书那样排：不用框、不用柱，层级只靠字号、字重和留白。」

- **网格**：正文栏 31 字（英文约 74 字符，三个方向里唯一落在 45–75 区间内的），左侧 7 字悬挂区放编号和出处，右侧留 4 字空白。
- **层级**：考点标题用宋体粗 20pt，编号用 STIX；段首缩进两字，段间不空（clreq）；要点卡是上下两条主色发丝线夹一段粗体。
- **用色**：主色只给编号与答案。零底色、零描边框，墨量最低。
- **参照**：Bringhurst、Genius。
- **代价**：没有签、没有块，学生翻找「例 2 在哪」时只能靠悬挂编号，导航最弱。练习少、讲解多的页面会显得像普通读物，离「教辅」的身份最远。

| 正文字号 | 10.5pt ✗ | 12pt ✓ | 12pt ✓ | 12pt ✓ |
| 正文行空 | 2.78mm ✗ | 3.17mm ✓ | 3.17mm ✓ | 3.17mm ✓ |
| 字号种数 | 10 | 8 | 7 | 6 |

## 三、负责人推荐

**推荐 A（柱式）作为主线，同时从 B、C 各借一条：**

1. **从 B 借断页纪律，但放宽**：考点从新页起，不强制左页、也不强制对页。这样消除了诊断 A7 的「考点被翻页切开」，同时不要求内容服从对页。
2. **从 C 借要点卡和段落规则**：中文段首缩进两字、段间不空。要点卡保留 A 的浅青底，因为它是全书唯一的「请记住」，需要比 C 的发丝线更强的识别度。

理由：

- A 同时守住了「日骨」（柱 = 信息编排骨架）和「英皮」（零框、克制用色）。
- 柱给学生提供了 C 所缺的导航，又没有 B 那种让内容服从版面的硬约束。
- 指标上，A 的基线对齐率最高、标题与正文的反差最大，英文行长也在可接受范围内。

但这只是负责人的判断，按任务书，「好看」由第四步的外部验证决定。建议把 A / B / C 三份都打印出来，做学生两两比较的盲测，再定方向。

## 四、方向稿的已知问题

- B 的页码从左页的 1 起（首元素 `break-before: left` 使第 1 页成为左页）。正式书里左页应为偶数页码，到册级拼版时再处理。
- A 的第 4 页只有一个练习的尾巴，C 的第 3 页底部空出约 65mm。这些是断页规则还没细调的结果，属于定稿阶段的工作。
- 「注」用 10.5pt，没有落在 12pt 网格上，单处漂移 ≤ 0.4pt。定稿时要么改成 12pt，要么把注改成柱里的辅文。
- 练习的空格仍是 `______` 下划线字符，不是真正的书写空间。改成书写线需要在 schema 里增加一个 `blank` 元素，留到回写规范时（第五步）一并处理。
- 讲解中的英文放大系数只试了 1.12，1.08 和 1.16 两档还没有打样比较。

## 五、对规范的影响（第五步回写时处理）

1. `01` 字号阶梯改为以 12pt / 21pt 为基础，「生产间距」整节用半格规则替代。
2. `02` schema 需要补的：
   - 例题编号改由 CSS 生成，内容里不再写「例 1」和题目要求。
   - 引号统一为“”。
   - 汉字与西文之间统一加半角空格。
   - 增加 `blank` 书写空元素。
   - 如果选 B，还要加「考点放得下一组对页」的约束。
3. `03` 版式映射按选定的方向重写。

## 中西补偿：定 1.12

三档的同位截图见 `中西补偿-三档对比.png`，取 1.1 讲解段，200dpi。

- **1.08**：句中的 last year、now 比汉字略单薄。
- **1.16**：time、now 这类短词开始比周围汉字更抢眼。
- **1.12**：两者最平衡。

**所以定 1.12。** 这是负责人在屏幕图上的判断，最终以 100% 原大打印为准。独立的英文语料块（如句型行）不受这项影响。

切换补偿系数时，en-mix 的度量覆盖要同步改：

- 公式：(ascent − descent) × k = 0.76，ascent + descent = 1
- k = 1.08 → 85.2% / 14.8%
- k = 1.12 → 83.9% / 16.1%
- k = 1.16 → 82.8% / 17.2%

# 视觉重做任务书

2026-11-04 立。起因：所有者判断现行样章与视觉规范「不好看、不专业」。

本轮**做深，不做大**：只针对「专项讲练」页型的一组对页（`样章-谓语动词` 第 1–2 页内容），不新增组件、不扩展页型。

## 第一步：诊断（不改任何东西）

1. 用 Vivliostyle 把当前样章渲染成 PDF，按 100% 原大出对页图。每个问题给**测量值**，不给形容词：英文 / 中文每行字符数、各级字号比例与字重差、块间距实际分布、左缘对齐轴数量、眯眼（模糊）测试与灰度测试截图。
2. 列出 `规范/01` 中非由统一单位推出的「凑出来的数值」，以及规范缺失的正面主张（网格、行长、基本版式）。

## 第二步：回到原始材料（不以 `调研/*.md` 为准，它是二手材料）

**标杆清单**——按维度各取最强者，不找单一范本。区分「风格参考」（像什么）与「品质标杆」（做得多精）：

| 维度 | 看齐对象 | 学什么 |
|---|---|---|
| 讲练对页结构 | Raymond Murphy《English Grammar in Use》（Cambridge University Press） | 一单元 = 一对页：左讲右练 |
| 母语讲解 + 英文语料的高中语法书（最近同类） | 日本高中「総合英語」：《Evergreen》（いいずな書店，桐原《Forest》后继）、《Vision Quest 総合英語》（啓林館） | 同学段、同双色、同「母语讲 + 英文例」的出版级完成度 |
| 词汇书（848 核心词汇、识记机） | 《鉄緑会 東大英単語熟語 鉄壁》（KADOKAWA）、《システム英単語》（駿台文庫）、《英単語ターゲット1900》（旺文社） | 词条层级、高密度下的清楚 |
| 中西混排最难场景 | 《牛津高阶英汉双解词典》（商务印书馆）、《ジーニアス英和辞典》（大修館書店） | 6–7pt 小字下英 / 中 / 音标 / 标签四声部的字号补偿、基线、标点 |
| 双语读本（语篇精讲） | 外研社「书虫」牛津英汉双语读物 | 英文与中译的对照排法、「先读英文」的主次 |
| 旁注与推演并排 | Edward Tufte《The Visual Display of Quantitative Information》等 | 正文与旁注同行对齐 |
| 正文阅读质量（底线） | 中华书局 / 商务印书馆 / 三联书店的精良版本、历届「中国最美的书」；Bringhurst《The Elements of Typographic Style》 | 均匀的正文灰度、行距、标点、行长 |

现有七套参考的定位调整：中系三套只作考点组织与题量逻辑参考，不作视觉参考；ClearRevise / Oxford Revise 只取浅底克制的气质。主标杆三本：《English Grammar in Use》（结构）、《Evergreen》或《Vision Quest》（最近同类，两本都翻过再定）、《牛津高阶英汉双解》（混排）。书名、版次、可得性下单前须核实。

1. 用 PyMuPDF / pdfplumber 从标杆的矢量 PDF（或实体书原大实测）提取正文、标题、注释的字号、行距、行长、版心、色值，入同一张对照表；每本取 1–2 组对页。无矢量 PDF 的注明精度。
2. 用 fontTools 读 STIX Two Text 与 Noto Serif / Sans SC 的度量（unitsPerEm、x 字高、大写字高、表意字面框），算中西混排的字号补偿与基线偏移。
3. 查原文，列出 W3C clreq、GB/T 15834、GB 40070-2021 中适用本项目的条款，每条附出处。

## 第三步：先定基本版式，再定方向

1. 定基线单位、版心（每行字数 × 每页行数）、英文行长区间；所有间距取基线单位的倍数，替换规范里凑出来的数值。
2. 用同一份内容做 **3 个明显不同的方向**，每个方向一句话主张，附与标杆同比例的对页对照图。由所有者选，或交第四步测试决定。

## 第四步：外部验证（负责人与所有者说「好看」不算数）

- 自动检查全部通过：行长区间、基线对齐率、对比度、禁则零违例、`pdffonts` 零 Type 3、GB 40070 条款。
- 学生盲测材料：两两比较的打印页 + 「找到某考点答案」计时任务。
- 我们的一页去标识，与标杆书页混排，交第三方盲选。

## 第五步：回写规范

选定方向回写 `规范/01`、`03`，写法为「原则 + 由原则推出的数值 + 参照图」，删掉被取代的补丁条款。

**每一步结束都停下来交所有者过目**：测量表、对照图、未解决问题清单。没有证据不宣布「已经好看了」。

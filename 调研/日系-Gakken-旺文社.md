# 日系风格解剖：学研 Gakken × 旺文社 Obunsha

> **角色**：日骨——信息编排密度是整个自创风格的骨架。本报告是七套参考里分量最重的一份。  
> **原则**：结论以样张实证为主；开本、印刷规格、系列传统用公开书目作辅证。拍摄伪影与设计本意分开写。  
> **项目对齐**：`规范/00-项目共识.md` 要求色彩纪律接近日系双色（主色 + 强调色 + 灰阶，局部第三色）。旺文社样张几乎就是这条纪律的实物；学研样张证明「双色纪律」之上还可以加一层扫描色，但不能把彩虹章色整套搬进生产框架。

学研系列公开卖点：「左页讲解、右页练习」「一次只讲一件」。**本批三张都是卷首**（卖点页、目录、应试指南），**没有课页对页**。密度结论必须把「页型」说清楚：学研的骨架不在这三张的填满率，而在它如何用扫描层把目录和指南页组织成可跳读的结构；真正的高密度课页骨架在旺文社。

旺文社系列公开结构：每个主题固定走 **基礎問 → 精講 → 解答 → ポイント → 演習問題**，原则 1 页或对页闭合。本批 566 是目录，567 / 568 正好是这套页型的实物——这才是「日骨」的主样本。

### 0.2 拍摄伪影（解剖时一律扣除）

六张都是微信实拍/扫描 JPG，有梯形畸变和室内暖光。以下**不当成设计**：

1. **色温偏暖**：纸白取样约 `#F0F0F0`–`#F3F3F2`，印刷纸应接近纯白。学研 563 右页粉地取样 `#E8B3AF`，比设计本意更「肉粉」；旺文社青取样会略偏灰青。下文 hex 是「拍摄取样 → 校正后的设计估计」。
2. **梯形与页曲**：栏宽、圆角、章圆的正圆度不可当精确几何。比例用相对关系（「外页边 ≈ 正文栏宽的 1/8」），不写毫米级假精度。
3. **电子试读 UI（学研）**：563 底栏社交图标 / 购物车、画面中的「2 / 5」胶囊；565 底部灰条同样控件、右下深灰圆角「5」。**这些不是印刷页眉页脚。** 563 左缘蓝色细条也无法坐实是切口染色还是电子章节色带——不纳入基因。
4. **JPEG 网点**：旺文社浅青底的真实印刷是特色平网；照片里网点和压缩颗粒会混在一起。能确认的是「浅青平涂分层」，不能确认网线角度和目数。
5. **阴影**：旺文社章条、ポイント卡上的浅灰投影在 567 左右页反复出现，判为**印刷设计**（墨网），不是桌面灯光。学研页基本是平涂，没有这套投影语言。

### 0.3 关于「赤シート」传统（背景，不是本批的物理事实）

日本参考书暗记文化的标准工艺是：**墨 + 橙色（特色）2 色刷**，红透明片盖下去橙色字消失。组版上，色字若叠在墨网上必须ノセ，否则红片盖住后会露出白挖空（文京组版公开说明）。学研自己的《寝る前5分暗記ブック》、旺文社《出る順パス単》都走这条线。

**本批六张都不是赤シート本。** 学研 2024 改订版公开写成オールカラー，粉字是品牌强调色，不是可隐字。旺文社精讲是墨 + **青**，青字盖红片盖不掉——青色的职能是结构导航，不是暗记隐藏。

可蒸馏的不是「必须做橙字 + 配红片」，而是：**第二色只承担一种认知职能**。项目是 RGB 自印/电子本，记忆层用强调色编码即可，不要做成依赖红片的工艺。

## 1. 页面几何与网格

### 1.1 学研（B5）：宽页边 + 单栏叙事 + 目录才双栏

**563 对页（书名 / 卖点）**

- 左页：单栏，主体是一张竖向圆角大框，约占版心宽 85%、版心高 75%，框内再单栏。框外四周留白很大——这是「系列性格页」，不是课页网格。
- 右页：粉地接近满版（照片上仍可见一圈纸边，印刷上应视为满版色块 + 常规页边）。文字和笑脸图标沉在下 1/3，上 2/3 只放底纹。这是封面式构图，不是信息网格。
- 依据：对页左右信息量极度不对称；右页上半几乎无字。

**564 对页（目录 004–005）**

- **每页两栏**。章是通栏模块（章头横跨该页两栏或至少以章为分组），课目在栏内做「号 + 题 + 虚线 + 页码」。
- 页边相对宽松：天头要放下「もくじ」云形标和「英検®3級」；地脚放下页码 `004` / `005`（居中、细ゴシック）。外页边目测约正文栏宽的 1/6–1/5，比旺文社更「透气」。
- 005 下半改单栏：「この本の使い方」胶囊头 + 条目，再下是带框的「音声の聞き方」+ 二维码。目录网格到这里让位给说明网格。
- 依据：004 可见 ①–⑥ 章分列两栏；课目页码右齐、虚线拉齐，是标准目录栏。

**565（006，单页）**

- **单栏**。水平切段：天头系列名 → 大标题「受験パーフェクトガイド」→ 右对齐的粉色导语 → 点线 → 胶囊栏头 + 荧光笔小标题 + 正文。插画贴在中下右，打断栏的矩形，但不另开栏。
- 页边仍宽。页码 `006` 居中（印刷）；右下深灰「5」按 0.2 处理为电子控件。
- 模块纵比（目测，006 一页）：天头+标题+导语 ≈ 22%；第一胶囊段 ≈ 28%；第二胶囊段 + 插画 ≈ 40%；地脚 ≈ 10%。

学研网格纪律可以概括成：**叙事页单栏、检索页双栏、模块与模块之间用「一整条水平色带」换栏，而不是用细线把页切碎。**

### 1.2 旺文社（A5）：窄版心、单栏课页、目录才双栏——更小的纸、更硬的模块

A5 面积约为 B5 的 2/3。同样字数在精讲里会显得更「骨」。这是密度对比必须先扣除的格式差。

**566 对页（目录 4–5）**

- **每页两栏**，对页等于四条检索列。
- 章头是「黑方（白字『第n章』）+ 浅灰横条（章名）」组成的通栏（相对于该页两栏之宽）分隔带。带与带之间留出约 1.5–2 行的章间空白。
- 栏内：青号 + 黑题名 + 细虚线 + 页码。条目行距紧，但列对齐极严。
- 天头：左页「もくじ」+ 页码 `4`，右页页码 `5` 在外上角。地脚干净。
- 5 页最底「演習問題の解答 …… 260」**拉通两栏**，用加长虚线宣布目录结束。
- 页边：外页边目测约栏宽的 1/8–1/10，比学研目录更贴。依据：四列数字能在 A5 对页里排下 52–154 号（约 103 条）还不撞边。

**567 对页（课页 6–7）与 568（课页单页）**

- **单栏纵栈**，不是杂志式多栏。信息密度不靠加栏，靠「一种信息一种容器」在纵向上卡死。
- 天头约 8–10% 页高：页码、章名「第1章 数と式」、568 还有左上青底白字「基礎問」签。
- 7 页切口有**竖向章标**「第1章」（青底白字），拇指索引。
- 版心内固定纵序（567 左页 基础问 1、右页 基础问 2，各走完一套）：

  | 模块 | 约占比（单页内，目测） | 依据 |
  |---|---|---|
  | 节头（青方号 + ゴシック节名） | 6–8% | 顶部分量小但字号最大 |
  | 基础问框（青细线 + 折角） | 12–18% | 小题 2 栏排，框本身不高 |
  | 精講 | 12–20% | 一段到数段，568 更长 |
  | 解答框 | 35–50% | 永远是页上最大块 |
  | ポイント浅青卡 | 8–12% | 567 两页都贴在解答下 |
  | 参考 / 注 | 0–8% | 7 页有「参考」；6 页把法则嵌进解答 |
  | 演習問題（斜缎带） | 8–12% | 贴地脚，蓝细线与上文隔开 |

- 568 解答内部还有**隐式双栏**：左约 65–70% 推演，右约 30–35% 旁注。这是课页里唯一稳定的「栏」，而且只出现在演算层。

旺文社网格纪律：**栏数极少（课页 1 栏），模块种类极多；对齐靠左缘一条纵轴（节号、精講图标、解答框左线、ポイント左缘共线）。**

## 2. 色彩系统

拍摄取样（作物高彩像素）与校正估计如下。校正原则：把纸白拉回 `#FFFFFF`，把暖偏扣掉。

### 2.1 学研：全彩，但「用起来像有节制的三色 + 章色」

**核心色板（563 / 564 / 565 共用）**

| 角色 | 取样 | 校正估计 | 用在哪 |
|---|---|---|---|
| 纸白 | `#F0F0F0` | `#FFFFFF` | 底 |
| 正文墨 | 近黑 | `#222222` | ゴシック正文 |
| 品牌珊瑚粉 | 栏头 `#D9727D` / `#DA727C` | **`#D46C76`** | 胶囊栏头、导语、句内关键数据、框线、笑脸 |
| 书名页粉地 | `#E8B3AF` | **`#E8A8A0`**（实地，比栏头浅） | 563 右页满版 |
| 结构青 | 框边 `#79C0E2` | **`#6EBBE0`** | 563 左框、卖点小标题、句内关键词 |
| 荧光笔黄 | `#F1EF60` | **`#F3EE5A`**（半透明感，盖在字脚） | 小标题衬底 |
| 目录深灰 | 云形「もくじ」 | **`#3A3A3A`** | 检索页主标 |
| 预测标签褐 | `#C0A98C` | **`#C4A484`** | 「予想テスト」「模擬試験」胶囊 |

**目录彩虹章色（564，每章一色，只染章圆、课标题、装饰星）**

目测八色：①粉、②绿、③琥珀、④紫、⑤青、⑥珊瑚红、⑦绿、⑧橙褐。这是**导航色，不是印刷第四色习惯上的「再加一只专色」**——书是全彩，章色可以任意。对自创框架：这种彩虹**与「克制全彩」冲突**，只偷「一章一色」的检索逻辑，不偷八色本身。

**底纹与网点**

- 563 右页：粉地上有 **45° 细白点/虚线菱格**。这是印刷地纹，不是污渍。作用：大面积实地不发闷、不廉价。浓度很低，远看仍是平色。
- 564「使い方」：胶囊下的说明区是 **粉的 5–8% 浅网**（照片上几乎只剩纸色偏暖，但与纯白正文区仍可分开）。
- 565：几乎无网，分层全靠实地色带和荧光笔。
- 学研**不用**旺文社那种「整块浅青网当记忆层」。它的分层工具是实心胶囊和黄标记，更「贴纸」，更少「印刷网」。

**印刷判断**：全彩 CMYK。565 插画有校服蓝、校舍褐、肤色，不可能是双色。563 左页看起来像青 + 黑 + 黄点缀，那是这一页没用上全套色，不是全书双色。

### 2.2 旺文社：标准 2 色刷 + 墨网 / 色网分层（本报告最重要的色彩结论）

| 角色 | 取样 | 校正估计 | 用在哪 |
|---|---|---|---|
| 纸白 | `#F3F3F2` | `#FFFFFF` | 底 |
| 墨 | 近黑 | `#1A1A1A` | 正文、章方、题名、页码 |
| 特色青（实地） | 基础问签 `#499FDD`；567 全局高彩 `#489CD8` | **`#4A9CD8`** | 基础问号、节号方、框线、精講书标、演習缎带、旁注三角、切口章标 |
| 青的平网 | ポイント底 `#DCE6F2` / `#D4E4F5` | **约 10–18% 青网**，看起来像 `#D8E8F4` | ポイント卡、部分精講/提示底 |
| 墨网浅灰 | 章条、解答签 | **8–20% 墨网** `#E6E6E8`（条）/ `#6E6E72`（解答签） | 章头条、解答标题条、细框、投影 |
| 虚线 | 浅灰 / 浅青 | 墨 30–40% 或青 40% | 目录引导线；解答内嵌法则框；ポイント内竖虚线 |

**网点用法（日骨的物理层）**

1. **色网 = 记忆层**：ポイント整卡铺浅青网，不加粗框。学生用「色块」而不是「线框」识别「这一块要背」。
2. **墨网 = 结构层**：章头灰条、解答顶签、细阴影。灰色从不承担「强调」，只承担「这是容器」。
3. **实地青 = 路标**：面积很小（方、签、三角、1pt 线）。青一旦铺大，就变成ポイント——职能升级。
4. **白底 = 演算层**：解答主区保持白，公式对比最高。法则如果必须进解答，用虚线白框嵌进去，不加网，避免和ポイント抢层。
5. **投影**：ポイント卡右下浅墨网，约 0.4–0.8mm 偏移。让记忆卡「浮」在演算层之上。这是用印刷网做的 z-index。

**印刷判断**：2 色（墨 + 青）。566–568 所有彩色都在同一青相里，没有粉、没有黄。灰一定是墨网。与公开规格「2色刷 / A5」一致。

**和赤シート传统的关系**：同一家出版社会做橙字红片（パス単），也会做青字结构书（精讲）。本套选的是后者。对项目：学**青字这套「职能色」**，不要学橙字红片，除非将来真做可隐暗记本。

## 3. 字体层级

### 3.1 学研：几乎全程丸ゴシック，用字重和颜色当层级

英检入门向。所见页面**几乎不见明朝**。标题、栏头、目录、指南正文都是带圆角末梢的ゴシック（丸ゴシック气质），亲和、低压迫。

| 级 | 所见 | 大约相对关系（以正文字号 = 1） |
|---|---|---|
| 书名 | 563 右：白、特粗，「英検®3級を」> 系列名 > `[改訂版]` | 2.4 / 1.6 / 0.85 |
| 目录主标 | 「もくじ」白字塞进深灰云形 | ~2.0 |
| 章名 | 粗ゴシック黑 + 色圈号 | ~1.45 |
| 课号 `01` | 特粗黑 | ~1.25 |
| 课标题 | 章色、粗 | ~1.1 |
| 课副题 | 灰、细，嵌在标题下一行 | ~0.85 |
| 胶囊栏头 | 白字、中粗 | ~1.2 |
| 荧光笔小标题 | 黑、粗 | ~1.15 |
| 正文 | 黑、常规 | 1（行距约 1.55–1.75 倍字高） |
| 句内强调 | 同字号，改珊瑚粉或青 | 1 |
| ※ / 资费说明 | 更小、灰或粉 | 0.7–0.8 |

**假名与汉字节奏**：丸ゴシック让平假名偏圆、汉字偏软，适合「不要吓到考生」。行距宁可松，也不把 1 行塞成 1.2 倍——学研的密度不靠压行距。

**符号系统**

- 章号：双线圈 + 色 + 小「星光」三撇（564）。
- 步骤：①②（使い方、音声）。
- 「もっと！」：浅色方块标签，表示附录式加料，不是正课号。
- 注册标记 `®` 紧贴「英検」。
- 方括号 `[改訂版]`、`[音声の聞き方]`：元数据、框题，刻意比主信息低一级。

### 3.2 旺文社：ゴシック管结构，明朝管讲解，数学衬线管式子

这是日系数学参考书的经典三角，也是项目「字体角色制」最值得对齐的实物（把明朝换成 `serif-cjk`，ゴシック换成 `sans-ui`）。

| 级 | 字体角色 | 所见 |
|---|---|---|
| 章名 / 节名 | 粗ゴシック | 「第1章 数と式」「3 式の展開」 |
| 容器标签 | 粗ゴシック白字 | 精講、解答、ポイント、基礎問、演習問題 |
| 目录章名 | 粗ゴシック | 灰条上 |
| 目录条目 | 常规ゴシック | 黑题名；青号略大于题名、更粗 |
| 精講正文 | **偏明朝的阅读体**（567 长段尤其明显） | 行距约 1.55–1.7；可含句内公式 |
| 解答旁注 | 更小的ゴシック | 约为精講的 0.8–0.85 |
| 公式 / 变量 | 数学衬线 + 斜体变量 | `x, y, a^n`；等号纵向对齐 |
| 最终答案 | 同式，**加粗** | 567 ポイント上方的 `-108x^7y^8` |

**假名与汉字**：明朝精講里，汉字是「骨」、平假名是「气口」，长解释读起来像老师讲话，不像 UI。ゴシック标签则完全是界面。两种节奏在同一页上切换 = 学生知道现在是「在读」还是「在扫」。

**符号系统（精讲的操作系统）**

- 主题号：青实地方、白数字（节 `1` `2` `3`）。
- 基础问小题：`(1) (2) (3)` 圆括号——轻，不和 ① 抢。
- 精講策略：①②③④ 圈数字——这是「思维步骤」，比小题更「教」。
- 法则编号：罗马数字 Ⅰ Ⅱ Ⅲ（指数法则 inset）。
- 角括号〈指数法則〉：给一块知识命名。
- 注：青小方「注」。
- 目录号：52、53… 全程阿拉伯，青色，全书基础问唯一 ID。

学研用圈号做「友好步骤」；旺文社把圈号、括号号、罗马号、全书序号**分给不同语义**。后者更值得偷：符号即 schema。

## 4. 组件形态学

只列样张里能指认的。每个组件写构造，不写「感觉」。

### 4.1 学研

**A. 双线圆角信息框**（563 左）

- 外：约 2–2.5pt 结构青、大圆角（目测半径 8–12mm 量级，B5 上很软）。
- 内：细黑发丝线，与外框平行，间距约 1.5–2.5mm。
- 顶外：白底青线笑脸徽章，骑在框线上。
- 内部分段：细黑横线，端点小菱形或圆点；段首再放笑脸 + 青小标题。
- 框内留白大于框外装饰——框是「房间」，不是「铁笼」。

**B. 书名页（563 右）**

- 满版浅粉实地 + 菱格白点地纹。
- 下 1/3：白线稿笑脸（带三撇高光）+ 白丸ゴシック书名叠句。
- 无框、无页码入镜（电子 UI 另计）。职能：用空的上半页兑现书名里的「わかりやすく」。

**C. 「もくじ」云形标**（564）

- 深灰有机圆角块（云/胶囊变体），白字「もくじ」。
- 旁注「英検®3級」黑ゴシック。检索页的唯一重色块，当锚。

**D. 章头（目录）**

- 双线圈 + 章色数字 + 顶部星光三撇 + 「章」+ 粗黑章名。
- 章与章之间空白 ≈ 课目两行，用空白分组，不用横线。

**E. 课目行**

- `01` 粗黑｜章色粗标题｜其下灰细副题｜浅灰点线｜页码。
- 副题嵌在标题下，**一行课目占两行高、但不占两行宽**——这是学研目录能密而不乱的核心构件。

**F. 状态胶囊**

- 「予想テスト」「模擬試験」：褐/驼实地、白字、全圆角、高度约 1 行。插在课列里当元数据，不另起段落。

**G. 胶囊栏头**（564 使い方、565 两处）

- 珊瑚粉实地条，**两端全圆**（药丸）。
- 左：白线稿笑脸。中：白ゴシック栏名。
- 这是学研换段的主工具。粗细约 7–9mm 高，比旺文社任何签都更「海报」。

**H. 荧光笔小标题**（564 音声框内、565 各段）

- 黑粗ゴシック。
- 衬底黄条高度只有字高的 50–60%，偏下，模拟手涂荧光笔，**不是**整行色带、也不是下划线。

**I. 句内色字**（565）

- 正文黑，把「65分」「6月 / 10月 / 1月」改成珊瑚粉。字号字重不变。扫描层叠在句子里。

**J. 粉线框 + 框题**（564 底部音声）

- 约 0.6–0.8pt 粉线圆角框。
- 框顶线中断，嵌入 `[音声の聞き方]`。二维码落在框内一角。
- 星标粉段：★ 领起的整段改粉色，当「规则/例外」，不是正文。

**K. 粉圆点列表**（使い方）

- 实心粉圆 ≈ 字号 0.45。悬挂缩进，二级用更小的点或短横。

**L. 插画**（565）

- 细线平涂，校服/校舍，不出血。贴在文右，给指南页一个「休息面」。全彩才养得起；双色框架里不要学题材，只学「说明页允许一张减压图」。

**M. 黄小胶囊 CTA**（563 左下「さらに学習をサポート！」）

- 取样区偏白（框太小），目视为浅黄胶囊。点缀第三色，全书不超过这种剂量。

### 4.2 旺文社

**N. 章头条（目录）**（566）

- 左：黑圆角方，白字「第n章」。
- 右：8–12% 墨网横条，粗ゴシック章名。
- 条下极浅墨网投影。圆角只出现在这条上，正文行全是直角节奏。

**O. 目录条目**

- 青粗号（基础问 ID）+ 黑题 + 细点线（墨 30–40%）+ 黑页码。
- 青**只给号**，不给题——和学研「整行课标题上色」相反。号是手指的落点。

**P. 基础问签**（567 / 568）

- 天头外上或框角：青实地、白字「基礎問」，可带问次。568 更像贴在左上的矩形签。

**Q. 基础问题干框**

- 0.5–0.75pt 青线矩形。
- 一角 45° 折角/狗耳（567 右下折、568 左上切角 + 右下重叠角），浅墨网投影。隐喻「一张练习纸」，不是 UI 卡片。
- 内部小题 2 栏；过长的 (5) 再单独通栏。题干句「次の式を展開せよ。」在框内顶上一行。

**R. 精講**

- 青开书小标（白字「精講」），可带浅影。
- 后接阅读体正文，相对节头左缘缩进约 1 个汉字。
- 568 用 ①②③④ 拆策略，句内粗ゴシック打「式の特徴を見ぬく」这类动作词。
- 无大底网（或极浅），避免和ポイント撞层。精講是「听老师说话」，ポイント才是「抄进脑子」。

**S. 解答容器**

- 顶：灰签白字「解　答」，两侧短粗横杠或细线拉到框边，签骑在框顶线上。
- 框：浅墨细线；567 特写可见**内凹方角（notch）**，图纸感。
- 内部白底。6 页把〈指数法則〉虚线框嵌在解答右上——「即时备忘」，不是记忆卡。
- 568：框内再分推演 | 旁注。旁注无自己的框，靠一条浅竖线和青三角定义。

**T. ポイント卡**（567，本套记忆层标准件）

- 浅青平网底。
- 左圆右较方（或全圆角，照片畸变下以「比解答框更软」为准）。
- 右下浅墨投影。
- 左：圆标（目视钟/笔尖类）+ ゴシック「ポイント」。
- 竖向青虚线把标签列和公式列切开。
- 公式可带青小方子弹。这是全书唯一「请记住」的底。

**U. 演習問題缎带**（567 两页地脚）

- 青实地斜裁条（约 10–15°），白字「演習問題」，可带回形针/铅笔小标。
- 上方一条通栏青细线与ポイント隔开。
- 斜，是整页唯一破坏水平网格的元素——所以一眼能找到「该动手了」。

**V. 参考**

- 与精講同族的开书标，文案「参考」。7 页出现在ポイント附近，补元认知（「也可以竖式算」），不是新题。

**W. 注**

- 青小方「注」+ 手绘感细曲线箭头，指到竖式某一行。把老师的口吻钉在演算上，而不进精講正文。

**X. 切口章标**（567 右页）

- 青竖条、白竖排「第1章」，贴外切口。检索用，课页内容不依赖它。

**Y. 解答旁注**（568）

- 青实心三角（▶ 或 ◀，照片方向因裁切有出入）+ 小ゴシック。
- 与该步等号行对齐。内容是操作口令（「2つのかっこの中で」「ひとまとめにしておく」），不是再讲一遍概念。

**Z. 节头**

- 青方白号 + 大号粗ゴシック节名。567 / 568 都从这条开始一个主题。号的方，和目录章的黑方，同一家族、不同色。

## 5. 信息密度策略（核心）

先把「密」定义成可数的东西：**一页有多少独立信息单元**（一个可被学生单独指认的块：一条课目、一道小题、一块精講、一条旁注、一张记忆卡……）。再问它靠什么不塌。

### 5.1 一页塞了多少

**学研 563 对页**：约 **5** 个单元（3 条卖点 + 1 个 CTA + 1 个书名块）。这是广告页。密度接近零，职能是降血压。

**学研 564 对页**：8 个章头 + 约 26 个课目（各带副题）+ 若干「もっと」+ 若干测试胶囊 + 使い方约 6 条 + 音声框 + QR ≈ **55–65** 个检索/说明单元。数字高，但每个单元结构相同，字号不小。这是**检索密度**，不是**讲解密度**。

**学研 565 单页**：2 个胶囊段 + 约 4 个荧光笔小标题 + 若干句内色数据 + 1 张插画 ≈ **8–12** 个单元。讲解密度低，扫描层厚。

**旺文社 566 对页**：章头 6 个（④–⑨）+ 基础问 **52–154**（约 103 条）+ 通栏「演習解答」≈ **110** 个检索单元。A5 上完成这件事，检索密度高于学研目录，手段却更少（只有青号 + 灰条）。

**旺文社 567 左页（基础问 1）**：1 节头 + 1 题干框（5 小题）+ 1 精講 + 1 解答（内含 5 解 + 1 个法则 inset）+ 1 ポイント + 1 演习 ≈ **10+ 个模块，模块里还有子单元**。主题从「是什么」到「你会不会」在 **A5 一页内闭合**。

**旺文社 567 右页**：同样完整循环，另加参考 / 注 / 竖式对照。对页 = **两个闭合主题**。

**旺文社 568**：1 个主题的「题 + 讲 + 带旁注的解答」。小题 5 道、策略 4 条、旁注若干。讲解密度是学研 006 的数倍，纸却更小。

**结论**：日骨的「密」主要体现在旺文社课页——**不是字号小到读不动，而是一页走完一个完整学习闭环**。学研卷首的密只出现在目录，而且用双行嵌套和章色把闭环拆成「以后再学」。

### 5.2 高密度不乱，靠什么

**旺文社：组件词典 + 网点分层 + 左缘共线 + 符号分义**

1. **组件词典**。精講 / 解答 / ポイント / 演習 的外形固定。学生用 200ms 认容器，不靠读标签。新主题不发明新容器。
2. **网点当 z-index**。白（做题/演算）→ 浅青网（记忆）→ 实地青（路标）→ 墨网灰（结构）。四层不会用同一手段表达。
3. **左缘一条纵轴**。节号、书标、框线、卡边共线。乱来自横向漂移；他们把漂移禁掉。
4. **符号分义**。`(1)` 小题、① 策略、Ⅰ 法则、全书 52… 基础问 ID。同一页上四个计数器互不抢。
5. **解答内再压缩**：法则 inset、双栏小题、旁注上右栏——省的是**模块个数**，不是行距。
6. **开本诚实**：A5 强迫「少装饰、多职能」。折角、斜缎带只在题干和演习各出现一次，装饰预算花在换模式上。

**学研：扫描层 + 嵌套行 + 禁止压正文行距 + 换段用色带**

1. **扫描层厚、正文层松**。目录能密，是因为课标题有颜色、副题缩在下一行，眼睛可以只看色标题。565 能扫，是因为黄标记 + 粉数据。
2. **正文行距不压**。指南页 1.55–1.75 倍。密的是「块的个数」，不是「行的间距」。
3. **换段用胶囊，不用细线网格**。水平色带比九宫格更不容易碎。
4. **一章一色**（仅目录）。色是手指的落点，功能等于旺文社的青号，只是学研肯花全彩。
5. **系列性格页故意留空**（563）。告诉读者后面也不会是墙。这是密度策略的一部分：用空页给密页签发通行证。

### 5.3 留白在哪里省、在哪里绝不省

| | 学研 | 旺文社 |
|---|---|---|
| **省** | 目录课目行距；副题不另占通栏；胶囊内边距中等 | 模块**内部**行距；小题改双栏；法则改 inset；旁注缩字号 |
| **不省** | 页边；章与章之间；框内边距；插画周围；563 上半页 | 模块**之间**（约 1 行）；ポイント内边距；精講相对节头的缩进；解答与旁注的水平缝；外页边（给切口标） |

共同法则：**留白属于「块的边界」，不属于「块的内部」。** 块内可以紧；块与块之间必须能用拇指分开。项目若把块间距和行距一起压，会同时失去两家的优点。

### 5.4 信息的「层」怎么用视觉编码

**学研四层（卷首所见）**

| 层 | 编码 | 例子 |
|---|---|---|
| 导航 | 实地色块、大号、笑脸 | 胶囊栏头、もくじ云、章圈 |
| 扫描 | 章色标题、荧光笔、句内粉数据 | 课名、小标题、「6月」 |
| 正文 | 黑ゴシック、正常行距 | 指南段落、卖点说明 |
| 补充 / 规则 | 更小、粉整段、★、※、框 | 音声规则、资费、QR |

没有单独的「记忆层」——卷首不要求背公式。粉字在 565 上接近记忆层，但职能是「应试事实」，不是赤シート暗记。

**旺文社六层（课页所见）**

| 层 | 编码 | 学生动作 |
|---|---|---|
| 结构 | 黑方、灰网条、天头、切口青条 | 我在哪一章 |
| 任务 | 青线折角框、白底、括号小题 | 先看题 |
| 讲解 | 开书标 + 阅读体 + 圈号策略 | 听完再算 |
| 演算 | 灰签解答框、白底、等号对齐 | 写步骤 |
| 旁注 | 小字 + 青三角，无底网 | 卡住再看 |
| 记忆 | 浅青网ポイント卡 + 投影 | 合上书还记得 |
| 操练 | 斜缎带演習 | 立刻默写 |

**警示层**：本批旺文社几乎没有红/橙警示。风险提示如果出现，会走「注」——青方、小、贴在式子上。学研的警示是粉整段。项目若要做易错，不要新发明第七色；挂在「注」或「粉/强调色整段」其中一轨即可。

### 5.5 对「日骨」的直接推论

骨架不是「把字排满」，是：

1. **主题闭合**（旺文社）：一个考点在一页或一对页内走完「题—讲—解—记—练」。
2. **层的互斥编码**（两家都有，旺文社更严）：颜色、网、线、符号、字族，每项只服务一层。
3. **检索件与课页件分开设计**（两家目录都双栏，课页都单栏）。

学研卷首证明：骨架允许封面式留白。那是节奏，不是课页规范。生产框架的默认页型应对齐旺文社闭环；学研的扫描层（荧光笔、句内色、胶囊）作为闭环内部的可读性皮肤——再交给英皮去做克制美感，而不是把学研目录彩虹当皮肤。

## 6. 图形语言

### 6.1 图标

- **学研**：笑脸是品牌 OS。线稿、圆、三撇高光。出现在框顶、胶囊左、书名页。降低威胁，不承载学科语义。
- **旺文社**：开书 = 精講/参考（进入讲解模式）；钟/笔尖圆标 = ポイント；回形针/铅笔 = 演習。图标 = 模式开关，几乎没有吉祥物。

### 6.2 线

| | 学研 | 旺文社 |
|---|---|---|
| 分段 | 点线（灰或粉），轻 | 模块靠容器，少用通栏线 |
| 框 | 双线圆角（卖点框）；粉细线框（音声） | 青 0.5–0.75pt 折角框；解答浅墨线 + 内凹角 |
| 目录 | 浅灰点线引导 | 更细的墨网点线 |
| 强调线 | 几乎没有下划线，用荧光笔代替 | 解答顶粗短杠；ポイント内竖虚线 |

### 6.3 箭头与手势

- 学研：几乎不见箭头。流程靠①②和列表。
- 旺文社：青三角是旁注子弹；「注」带手绘细曲线箭头指到式子。参考里用 `⇒` 做页内/书内跳转。手绘感只允许出现在「老师指给你看」这一类元层。

### 6.4 强调装饰

- **学研**：荧光笔（黄、半高、偏下）；句内改色；★；极少着重号。565 没有波浪下划线。
- **旺文社**：加粗最终答案；精講里动作词加粗；没有荧光笔（2 色刷也做不出学研那种黄）。记忆不靠涂黄，靠整卡铺网。

### 6.5 故意打破网格的装饰（各只用一次职能）

- 学研：云形もくじ、笑脸骑线。
- 旺文社：折角题框、斜演习缎带、ポイント投影。

规则：**一页最多一个「斜的」或「浮的」。** 567 斜缎带在底、ポイント浮在中下，已经是预算上限。

## 7. 两家对比：密度哲学

两家都是日本教辅工业，但密度的**目的**相反。

| | 学研『ひとつひとつわかりやすく』 | 旺文社『基礎問題精講』 |
|---|---|---|
| 开本 | B5，面积大约 1.5 个 A5 | A5，逼你做职能压缩 |
| 印刷 | 全彩 | 2 色 + 平网 |

| 密在何处 | 目录（检索）；课页（本批未见，公开结构是左讲右练、一次一件） | 每一课页都是闭环 |
| 乱如何被挡住 | 扫描色 + 松行距 + 胶囊换段 | 容器词典 + 网点分层 + 左缘共线 |
| 第二色的工作 | 品牌（珊瑚粉）+ 章彩虹（目录） | 全部路标共用一只青 |
| 字族 | 丸ゴシック一统 | ゴシック结构 / 明朝讲解 / 数学衬线 |
| 记忆怎么做 | 本批未见赤シート；粉数据近似「看一眼记住」 | ポイント浅网卡；不依赖红片 |
| 空页的意义 | 563 证明「空」是产品承诺 | 空只出现在块边界，块内不空 |
| 和项目配方的关系 | 扫描层、胶囊、荧光笔 → 可给英皮克制后使用 | **主题闭环 + 双色职能 + 网点分层 = 日骨本体** |

一句话：**学研用「一次少给一点」降低焦虑；旺文社用「一次给完一个主题」降低来回翻。** 自创英语讲义的课页更接近后者（考点讲解 → 例题精讲 → 变式 → 答案，和精讲的题—讲—解—记—练同构）。学研卷首的松，是封面和指南的节奏，不应变成课页的默认填满率。

学研课页（左讲右练）本批没有实证。公开描述与 564 目录的「01, 02…」一致，但**不要把未见的课页画成高密度墙**——系列名称已经反对这件事。日骨要从旺文社课页取闭环，从学研取「闭环里仍然要可扫」。

## 8. 可蒸馏基因清单（可执行排版规则）

每条写到能进 CSS 令牌的粒度。出处是本批文件名。与 `00-项目共识.md` 冲突的（八色彩虹、丸ゴシック吉祥物、A5 死磕）已剔除或改写成纪律兼容版。

### 8.1 一只强调色做全部路标，灰网做容器，浅网做记忆

- **规则**：正文与结构线用墨/黑；**所有**标签、题号、框线、图标、旁注子弹共用一只强调色（建议青系 `#4A9CD8` 或项目主色，但全书锁死一只）。强调色实地只用于 ≤ 1 行高的签/方/三角，或 ≤ 0.75pt 的线。记忆块用同一色的 **10–18% 底**（`background: color-mix(in srgb, var(--accent) 14%, white)`），不要改用第二种彩。结构条用 **8–15% 墨灰**，不要用彩。
- **禁止**：目录彩虹八色进课页；记忆块再描 1.5pt 彩框（会和题干框抢）。
- **出处**：`WechatIMG567.jpg`、`WechatIMG568.jpg`、`WechatIMG566.jpg`（青号）。学研 563 的青框是同一逻辑的全彩版，但 564 章彩虹不要偷。

### 8.2 课页默认「主题闭合」：题 → 讲 → 解 → 记 → 练，一页或一对页

- **规则**：一个考点节点必须按固定顺序输出五个槽位（空槽可省略，**不可换序**）：题干框 → 精講/讲解 → 解答 → 要点卡 → 练习。解答不得翻到章末才出现（变式练习的答案可另栏，但例题精讲必须当面闭合）。
- **纵比建议**（A4 可按旺文社 A5 比例放大，不要均分）：题干 12–18%；讲解 12–22%；解答 35–50%；要点 8–12%；练习 8–12%。解答必须是最大块。
- **出处**：`WechatIMG567.jpg` 左右页各走完一套；公开文案与实物一致。`WechatIMG568.jpg` 是「题+讲+解」的加长版。

### 8.3 解答 = 左推演 + 右旁注，旁注无框

- **规则**：解答框内部分成 **62–70% / 30–38%**。左：公式，等号列对齐，最终行加粗。右：小一号 UI 黑体，每条以强调色实心三角（约 0.55em）开头，垂直对齐到该步。左右之间 0.4–0.6pt、40% 灰竖线，**旁注不加底、不加框**。
- **出处**：`WechatIMG568.jpg`。`WechatIMG567.jpg` 6 页用虚线 inset 代替右栏，是同一层（补充）的变体——当补充是公式表时用 inset，当补充是口语口令时用右栏。

### 8.4 要点卡：浅网、软角、浅影、内竖虚线——记忆层唯一底色

- **规则**：背景 = 强调色 12–16% 网；边框无或 0.3pt 同色 30%。左圆角 ≥ 6px，右可稍方。投影：`0 1px 2px`、墨 12–18%（印刷感，不要 Material 大影）。左列宽 4–5em 放图标+「要点」四字；右列公式。两列之间 0.6pt、强调色 40% **虚线**。卡片与解答间距 ≥ 0.8em，卡片内边距 ≥ 0.6em——这块不省留白。
- **出处**：`WechatIMG567.jpg`（两页各一张，形态锁定）。

### 8.5 题干框：细强调色线 + 单折角 + 小题双栏

- **规则**：框线 0.6–0.8pt 强调色，白底。**只折一角**（建议右下 4–6px 三角实地，或左上 45° 切角），不要四角都倒。可选 8–12% 墨、1px 偏移投影。框内小题两栏，栏间距 1–1.2em；最后一题过长则通栏。题干指令句单独占框顶一行，不加粗到节头级别。
- **出处**：`WechatIMG567.jpg`、`WechatIMG568.jpg`。

### 8.6 荧光笔小标题（第三色的合法剂量）

- **规则**：小标题用 `sans-ui` 粗、黑色。衬底黄 `#F3EE5A`（或项目第三色），高度 = 字高 × 0.55，垂直对齐偏下（顶在字的 45% 处），宽度随标题字面，**左右各伸出 0.15em，不拉满栏宽**。同一栏头下的小标题才用；栏头自己用胶囊/签，不用荧光笔。
- **出处**：`WechatIMG565.jpg`、`WechatIMG564.jpg`（音声框内）。这是学研对「扫描层」的贡献；黄是局部第三色，符合共识。

### 8.7 句内强调只改色、不改号：只涂可背的原子

- **规则**：正文黑。允许把**日期、时长、次数、公式名、考点词**改成强调色，字号字重不变。禁止整句上色。一行里强调色原子不超过 3 个。补充规则段（★ / ※）才允许整段改强调色，并降 0.5–1pt。
- **出处**：`WechatIMG565.jpg`（「6月」「65分」）；`WechatIMG564.jpg`（★ 粉段）；`WechatIMG563.jpg`（卖点框内青关键词）。职能对齐赤シート「色 = 可抽检」，但不做橙字工艺。

### 8.8 栏头：药丸胶囊（说明页）vs 小签（课页）——按页型换，不混用

- **规则**：指南/用法/卷首用 **全圆角胶囊**，高 1.6–1.8em，强调色实地，白字，左置 1em 线稿图标。课页用 **小签**：精講 = 开书标；解答 = 灰签骑框顶、白字「解答」、两侧 2–3pt 粗短线；练习 = 斜 8–12° 的强调色条，白字，每页最多一条斜的。目录章头用 **黑方白字 + 灰网横条**（`WechatIMG566.jpg`），不要用胶囊。
- **出处**：胶囊 `WechatIMG564.jpg` `WechatIMG565.jpg`；课页签 `WechatIMG567.jpg` `WechatIMG568.jpg`。混用会把指南页做成习题页，或把习题页做成儿童读物。

### 附：明确不偷

- 笑脸作为系统图标（英皮要克制；笑脸是学研品牌，不是密度骨架）。
- 563 式满版实地书名页当课页模板。

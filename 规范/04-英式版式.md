# 04 英式版式（ClearRevise 为主，Oxford Revise 为辅）

2026-11-05 所有者定：否决「柱 + 正文栏」的左右排版（主线稿，日系味重），改为英系单栏。参考以 ClearRevise 为主，Oxford Revise 只取「讲 → 例 → 练」的固定骨架。两家合不到一起的地方，一律听 ClearRevise。
依据：`调研/英系-ClearRevise-OxfordRevise.md`（§8 可蒸馏基因 1、2、4、5、8）。

**适用范围**：本地化讲义（段考专题、同步讲义）。先做段考样章，所有者验收后再推到三册。旧主线稿（`渲染/方向稿/主线.css`）在本地化讲义中停用。

## 0. 不变的硬约束（沿用 01 §0、§1、§2）

- 正文 12pt，辅文 ≥ 9pt，行距 u = 21pt，块间距与块内边距取半格 10.5pt 的整数倍；半格基线对齐率 100%（`指标.py`）。
- 中文正文用宋体（serif-cjk）；英文题干、例句用 STIX（serif-en）。黑体（sans-ui）只用于标题、标签、出处、辅文。
- 灰度先行：文字一律实地；一页只用一种浅底（`--accent-wash`）；层级在黑白打印下必须成立。
- 字体只用 `渲染/fonts/` 内的 OFL 字体；`pdffonts` 不得出现系统回退字体。
- 英文最长行 ≤ 80 字符。

## 1. 版心：单栏

| 令牌 | 值 | 说明 |
|---|---|---|
| 版心宽 | **39 字 = 468pt（165.1mm）** | 左右页边距相等，各 22.45mm（2026-11-05 所有者定：初版 36 字 / 28.8mm 嫌宽 → 方案 A 38 字 / 24.57mm → 再放宽一档）。英文题干仍按 34 字（段考）/ 390pt（同步）折行，保证 ≤ 80 字符 |
| 版心高 | 35 行 = 735pt | 天 16mm，地 21.7mm，与 01 相同 |
| 编号悬挂 | 2 字 | 例题、练习的题号悬挂在 2 字里；英文题干最大宽 34 字（408pt），同步 33 字（396pt） |
| 左缘纵轴 | **一条** | 标题、色块左缘、题干左缘都在版心左缘；只有题号向左悬挂 |

没有左柱。原来住在柱里的小标题、柱注、「例 n」「解析」全部改为行内标签（§3）。

## 2. 颜色与形状

| 令牌 | 值 | 职能 |
|---|---|---|
| `--accent` | `#1A5E77` | 专题号块、药丸标签底、题号、要点星圈、答案条 |
| `--accent-wash` | `#D6E5EA` | 知识块底色（全书唯一浅底） |
| `--ink` | `#000000` | 文字、发丝线 |
| 圆角 | 4pt（色块）、全圆（药丸、星圈） | 取 ClearRevise 的圆角语言；01 §5「不用胶囊」在本版式中作废 |
| 描边框 | 只允许「要点」一种：0.75pt `--accent` | 01 §7「描边框 0」在本版式中改为「描边框只限要点」 |
| 投影 | 无 | ClearRevise 的语料盒软影不取（A4 黑白打印无意义） |

## 3. 组件

### 3.1 册头（`.stage-head`）
- 上：9pt 黑体 kicker「段考专题　高一上」。
- 中：册名 24pt 黑体粗（如「期中」），左侧不再放大号编号；编号「02」改为右上角的**角标**：12pt 黑体粗白字，`--accent` 实地，4pt 圆角，内边距 0 半字（ClearRevise 试卷坐标角标）。
- 下：统计行 9pt 黑体，数字 12pt 粗。
- 无下划线；与下文空 1u。

### 3.2 考情总览（`.overview` + `.focus`）
- 结构不变，表格通栏 36 字。
- 标题「考情总览」16pt 黑体粗，无编号。
- 表头 9pt 黑体，下线 0.75pt 墨色；行线 0.3pt。覆盖格不变。

### 3.3 专题头（`.topic-head`）
- 专题号：`--accent` 实地圆角方块（1u × 1u 的整数倍，建议 2u 高），白字 18pt 黑体粗，居中。
- 专题名：紧跟方块右侧，20pt 黑体粗，与方块垂直居中。
- 考频 chip（「覆盖 20/20 卷 · 82 道」）：9pt 黑体，右对齐，与专题名同基线。
- **不画下线**（ClearRevise 页标题靠字号与留白成立）。与下文空 1u。

### 3.4 知识块（`.explain` 内每个小标题一组 → `.group`）
ClearRevise「浅底圆角容器 + 药丸标题」。
- 每个小标题和它下面的要点包成一个 `.group`：`--accent-wash` 底，4pt 圆角，内边距上下半格、左右 1 字。组与组之间空半格。
- 小标题 → **药丸**：行内块，`--accent` 底，白字 10.5pt 黑体粗，全圆角，左右内边距半字，`line-height: 1`，坐在组的第一行行首。
- 柱注（`.gloss`）→ 药丸右侧同一行的 9pt 黑体说明，如「15 题 · 已有谓语，句中无连词」（两行柱注用「 · 」接成一行）。
- 要点段：不缩进，悬挂主色小方块（沿用 2026-11-05 的讲解段方块，挂在色块内边距里）。
- 句型（`.pattern`）：组内最后一行；「句型」9pt 黑体标签 + 12pt STIX 粗。
- 讲解里的「注」（`.note`）：组内一行，「注」9pt 黑体粗 + 正文。

### 3.5 例题（`.example`）
Oxford 的固定骨架（题 → 析），ClearRevise 的轻量外观。
- 首行：**「例 1」**12pt 黑体粗主色 + 空 1 字 + **出处** 9pt 黑体（「2023 · 东莞市 · 高一上期中」）+ 「 · 」+ 柱注提示 9pt 黑体（如「作状语，过去分词」）。**出处在题前**（所有者定：年份放最先）。
- 题干：下一行起，12pt STIX，左缘与版心左缘齐。
- 解析：与题干之间空半格；**不加底色、不加框**（同页已有知识块浅底，01 §2 一页一种底色）。整块左缩 2 字；首行行首放「解析」9pt 黑体粗白字的主色药丸，后接「句意：……」。「判断 / 成分」「故填」各起一行，标签 12pt 宋体粗（沿用）。
- 例题之间空 1u。

### 3.6 要点（`.keypoint`）
ClearRevise 星标提示框。
- 白底，0.75pt `--accent` 描边，4pt 圆角，内边距上下半格、左 2 字、右 1 字。
- 左上角骑一个星圈：直径 1u 的 `--accent` 实心圆，白色五角星（CSS 或内联 SVG 背景，不用字形），圆心落在框的左上角点向内 1 字处、上沿线上。
- 框内首行行首「要点」12pt 黑体粗，后接正文。
- 上方空 1u。

### 3.7 练一练（`.drill`）
- 标题「练一练」：药丸，但为**描边药丸**（0.75pt `--accent` 边、主色字、白底），与知识块的实心药丸区分。上方空 1u，无发丝线。
- 每题：题号 12pt 黑体粗主色，悬挂 2 字；**出处在题前**：题干段行首放 9pt 黑体「2022 · 东莞实验 · 高一上期中」，后空 1 字接题干；改写指令（`.cue`）仍在句末。
- 题与题之间空半格。

### 3.8 答案（`.answers`）
ClearRevise 答案条。
- 每个专题一条：`--accent` 实地 4pt 圆角条，白字 10.5pt 黑体粗「专题 1　非谓语」，条高 1u，宽通栏。
- 条下答案两栏流排（沿用 `.key`），题号主色。

### 3.9 页脚
沿用 01：外下角页码 + 面包屑，9pt 黑体。页码改为 12pt 黑体粗。

## 4. 密度预算（每页）
浅底 1 种；描边框只限要点；药丸两种（实心 = 知识小标题 / 解析，描边 = 练一练）；组件种类 ≤ 7。

## 5. 不取的
ClearRevise 每页换网格、每页换粉彩、扁平人物插画、品红品牌色、黄黑斜纹；Oxford 海军蓝大页眉、二维码、斑马纹检索表（以后做「自测」页型时再议）。

## 6. 段考整册的落地补充（2026-11-05 负责人审校后）
- 专题不再每个起新页，专题之间空 2u；考情总览后的第一个专题起新页。答案接在最后一个专题后。
- 例题题干左缩 2 字，与练一练题干、解析同轴（英文行 ≤ 80 字符）。
- 考情总览：表格行高 2u，专题名 14pt 黑体粗，覆盖格 7 × 10.5pt，百分比与题数 12pt 粗；册名 36pt。
- 知识块左右内边距 2 字；药丸与小方块对齐在 1 字处；块内齐左。
- 行内件挪基线一律用内边距差，不用 `position: relative`（表格单元格会连行线一起挪）。

## 7. 同步讲义（讲义一）的组件映射
沿用 §1–§4 与 §6，组件按下面映射到 `同步排版.py` 现有结构：

| 现有结构 | 英式做法 |
|---|---|
| 单元头 `.unit-head`（unit-book / h2 英文标题 + small 中文 / unit-stats，data-no=W/U1/U2） | 同册头 §3.1：kicker 9pt；英文单元名 30pt STIX 粗（3u 行盒），中文名 14pt 黑体跟在其后；统计行同册头；单元号「U1」做右上角角标。每单元起新页 |
| 各节 `.part > .topic-head`（data-no 1–4 + h3 + chip） | 同专题头 §3.3：主色圆角方块（节号）+ 20pt 节名 + 9pt chip；节与节之间空 2u，不起新页 |
| ① 考情表 `.freq` | 样式同 §3.2 的表，但行高保持 1u（行多）；词头 12pt STIX 粗；形式列 STIX；频次条主色；表头、行线同 §3.2 |
| ② 词族 `.family`（fam-head 词头 / gloss / fam-chain 词族链 / atoms 原题） | 首行：词头 14pt STIX 粗主色 + 空 1 字 + gloss 9pt 黑体（多行用「 · 」接成一行）。第二行：词族链放进 `--accent-wash` 圆角条（内边距上下 0、左右 1 字，高 1u 的整数倍），考过的形式前主色圆点。其下原题，题号悬挂 2 字、出处在题干行首（同 §3.7）。词族之间空 1u |
| ③ 短语 `.phrase`（gloss / ph 短语 + 中文释义 / atoms） | 首行：短语 12pt STIX 粗 + 中文释义 12pt 宋体 + gloss 9pt 黑体；其下原题同上 |
| ③ 「句式转换」分隔 `.lead` | 描边药丸（同练一练 §3.7） |
| ③ 句式块 `.phrase.trick`（fam-head 句式名 / gloss / ph 公式 / atoms） | 首行：句式名做实心药丸（同知识块小标题）+ gloss 9pt；第二行：公式放进 `--accent-wash` 圆角条；其下原题同上 |
| ④ 单元小测 `.atoms` | 原题列表，题号悬挂、出处在前 |
| 答案 `.answers`（topic-head + ol.key） | 同 §3.8：标题 20pt 无方块；不再分专题条，直接两栏 key；接在小测之后，不另起页 |

## 8. 答题横线（2026-11-05 所有者定）
- 只用于练习题（练一练、讲义一原题与小测），例题不加。
- **整句作答**（题干无空，或以「→ ___」收尾：同义句转换、句型改写、整句翻译、合并句子）：去掉句末的「→ ___」，题下空半格，**统一两条**书写横线（`.answer-lines`，各占 1u，线在行底，0.6pt 实地墨色，宽同英文题干）。
- **只填句中一截**（有「→」且空在句中，框架已给）：保留句中空，空位加长到 12em（`.blank.long`）。
- 单句改错不加横线。
- 出处字号定为 10.5pt（原 9pt）；出处校名用学校本名（去地名前缀），见 `本地化/脚本/题库.py` 的 SCHOOL_CANON。

## 9. 2026-11-05 晚补充（所有者定）
- 出处外加半角方括号 `[2023 · 东莞外国语学校 · 高一上月考]`，不用圆括号（与题内词形提示、改写要求区分）。
- 题内提示 / 做题要求（`.cue`，如「（用 recommend 翻译句子）」）与题干同字号：12pt 宋体，不拆行。
- 答案区改单栏：题号悬挂 2 字，答案加粗后接说明，整句答案独占一行；条间不空行；行宽同英文题干（408pt）。
- 节标题不落单在页末：标题下不足 6 行即换页（`本地化/脚本/孤标题检查.py` 自查）。

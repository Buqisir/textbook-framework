# 01 设计令牌

风格代号 **澄页**。目标一句话：学生拿到手的第一感觉是「信息好清楚，而且好看」。
配方：日骨（柱 = 信息编排骨架，见 03 §0）、英皮（零框、克制色量、语料衬线）、中魂（考点树 + 分层闭环 + 解析公式，见 02/03）。

本文件是视觉层唯一权威。CSS 与本文件冲突时改 CSS。改令牌须项目负责人确认。

**2026-11-04 视觉重做定版。** 推导过程、测量与对照见 `调研/视觉重做/00–05`。参考实现：`渲染/方向稿/基础.css` + `主线.css`。迁移状态见 §8。

## 0. 硬约束（不可协商）

| 约束 | 值 | 依据 |
|---|---|---|
| 正文最小字号 | **12pt（小 4 号）**；讲解、解析、题干、语料都是正文 | GB 40070—2021，高中教科书 / 教辅（所有者 2026-11-04 定：一律执行） |
| 辅文最小字号 | **9pt（小 5 号）**：栏签、出处、考频、表头、页脚、语篇说明 | 同上 |
| 行空 | **≥ 3.0mm**（行空 = 行距 − 字号） | 同上 |
| 正文字体 | 以宋体为主（serif-cjk） | 同上 |
| 标点 | 横排引号用“ ” ‘ ’；行首行尾禁则；行尾全角标点占半字 | GB/T 15834—2011 4.8.2、5.1、5.1.10 |
| 字体嵌入 | `pdffonts` 全部 CID TrueType，零 Type 3 | §3 嵌入工程约束 |

GB 40070 的数值出自官方新闻稿与政务解读，条款编号待核原文（`调研/视觉重做/03` §一.1）。

## 1. 基本版式

版心由字号 × 字数 × 行数 × 行距定义（clreq 7.1.1.4），页边距由版心反推，不反过来。

| 令牌 | 值 | 说明 |
|---|---|---|
| `page-size` | A4 210×297mm | 单一输出，纸屏两用，RGB |
| `--zi` 一字 | 12pt | 横向单位：栏宽、栏距、缩进都取一字的整数倍 |
| `--u` 基线单位 | **21pt**（7.408mm） | 正文行距；行空 9pt = 3.175mm |
| `--h` 半格 | 10.5pt | 纵向单位：块间距、块内边距取半格的整数倍 |
| 版心 | **42 字 × 35 行** = 504 × 735pt = 177.8 × 259.3mm | — |
| 天 / 地 | 16mm / 21.7mm | 地含页脚 |
| 订口 / 切口 | 18mm / 14.2mm | 左右页镜像 |
| 课页栏制 | **柱 8 字 + 栏距 1 字 + 正文栏 33 字**；宽块通栏 42 字 | 柱放骨架（小标题、栏签、题号）和柱注，正文栏放内容；辨析表、要点卡、练一练通栏（03 §0）。英文 12pt 约 79 字符/行 |

**网格规则**
1. 块内行距恒为 `--u`。
2. 块与块之间、块内边距只取半格（10.5pt）的整数倍；一个块（含边距）的总高度应为整格。
3. 所有字体统一度量覆盖：`ascent-override: 88%; descent-override: 12%; line-gap-override: 0%`，使不同字体在同一 21pt 行盒里基线同高、不撑高行盒。不做这一步，混排行会被撑高 0.5–2pt（实测：对齐率从 7% 升到 98%）。
4. 非 12pt 的正文级文字（如 10.5pt 的注）用 `position: relative; top` 下移，与 12pt 同基线：偏移 = (12 − 字号) × 0.76 / 2。
5. 表格单元格纵向内边距为 0；表格线用背景渐变画，不占行高。
6. 验收：半格基线对齐率 ≥ 95%（容差 0.6pt），由 `调研/视觉重做/工具/指标.py` 测。

页脚：外下角页码 + 面包屑「单元 › 考点」，9pt sans-ui 墨色；考点名取当页第一次出现的考点（`string(topic, first)`）。课页不设页眉。

## 2. 色彩：灰度先行

讲义的真实输出通道有三条：屏幕、彩色打印、**黑白激光 / 速印**。最后一条最常见，也最苛刻，所以规则按它来定：**层级必须在黑白打印下成立，色彩只是彩色输出的加分项。**

实测依据（`调研/视觉重做/工具/色值.py`、`网点模拟.py`）：
- 旧墨色 `#232629` 的灰度等效墨量为 85%，黑白打印会挂网，字的边缘发毛。
- 旧主色 `#1E6F8C` 与旧墨灰 `#63676D` 明度相同（L* 43.6 / 43.4）。黑白下「路标」和「降级的元数据」变成同一种灰。
- 9pt 灰字在 100 线网点下碎成虚线字。
- 四种浅底的灰度等效都在 2–7%，两两 ΔL* < 5，黑白下互相分不开；奶油底 2% 会整块丢失。

| 令牌 | 值 | 灰度等效 | 职能 |
|---|---|---|---|
| `--paper` | `#FFFFFF` | 0 | 纸 |
| `--ink` | **`#000000`** | 100% | **所有文字**：正文、辅文、英文、表头、页脚。纯黑在黑白输出下不挂网 |
| `--accent` | **`#1A5E77`**（沉靛青，L* 37） | 63% | **唯一路标色，只给编号**：考点号、例题号、练习题号、语篇空号、页码；外加考点头下线和时间轴等图解图形。明度与 EGIU 标题蓝 `#305C92`（L* 38.5）同档；与墨 ΔL* 37，黑白下仍可分。品牌色相待定（`调研/视觉重做/` 画布三方向），明度规则不变 |
| `--accent-wash` | **`#D6E5EA`** | 10% | **记忆层唯一底色**（要点卡）。低于 8% 速印易丢，高于 15% 压字 |
| `--ash` | `#F0F2F4` | 5% | 结构层底（答案组头等）。灰度下与 `--accent-wash` 不可分：**同页不得并用** |
| `--cream` | `#FDF9EC` | 2% | 语料盒底。**黑白下会消失**：语料盒必须靠结构识别（衬线英文 + 行号 + 边线），底色只是加分 |
| `--sample` | `#FAEFC0` | 6% | 示范答案底，同上 |
| `--ink-dim` | **已退役** | — | 灰字在黑白下碎成网点。降级靠字号（9pt）和字族（sans-ui），不靠灰 |
| `--hl` | 已退役（2026-08） | — | 不得新用 |

**用色规则**
1. 文字一律实地：墨色或主色，不得用半透明、不得用灰。
2. **主色文字只限 ≥12pt 粗体，或 ≥18pt 常规。** 主色在黑白下是 63% 网点，小字和细笔画会碎。
3. **主色只给编号**（2026-11-04 合成版定），不进句子、不给文字标签：柱里的小标题、「解析」「注」「要点」「练一练」一律墨色；解析标签（句意 / 成分 / 词形 / 故填）用墨色 sans-ui 500，靠换字族区分（Genius 做法）；`em-atom` 半粗不换色。规则一句话说得清，读者就不会觉得用色随意。
4. 一页最多一种底色；底色区块内的文字用墨色。
5. 线：发丝线用实地墨色 0.3pt；强调线用实地主色 0.75pt。**禁止半透明灰线**（黑白下网点化成虚线）。
6. 黄族（`--cream` / `--sample`）只当容器色，不当笔迹色。
7. 任意两种语义角色不得只靠色相区分：去色后仍须靠位置、字号、字族、字重之一可辨。
8. 全书只有一个色相（`--accent` 及其浅底）+ 黄族容器。出现第三色相即违规。

警示 / 易错不开新色，走「注」组件。禁止红章、橙章、徽章墙。

## 3. 字体角色

角色制，不写死字体名。默认绑定全部 SIL OFL、可嵌入售卖。

| 角色 | 默认绑定 | 用途 |
|---|---|---|
| `serif-cjk` | 思源宋体（Noto Serif SC TTF） | 中文讲解、解析正文。**要读的知识** |
| `serif-en` | STIX Two Text（static TTF） | 独立的英文语料块、题干、证据行。**被分析物** |
| `en-mix` | STIX Two Text × **1.12** | 中文正文里夹排的拉丁字母（`size-adjust: 112%`，度量覆盖 83.9% / 16.1%）。`unicode-range` 排除中文引号、破折号、省略号、间隔号，让它们落到思源宋体（全角） |
| `sans-ui` | 思源黑体（Noto Sans SC TTF） | 柱标签、柱注、考点头、解析标签、题号、表头、页脚。**界面** |
| `arrow` | 思源黑体，`unicode-range: U+2190-21FF` | 所有箭头。放在每个字体栈最前：STIX 缺 →，思源宋体的 → 又小又偏下 |
| `hand`（预留） | 待定 | 手写 / 临摹页型引入时再绑 |

黑体 = 界面，宋体 = 知识，衬线英 = 语料。三种字体在同一页共存，本身就构成层级。

**中西补偿系数 1.12 的来源**：拉丁 x 字高 / 汉字墨迹高，Genius 实测 0.60、Evergreen 0.64、思源宋体自带拉丁 0.56；STIX 同字号时只有 0.52。在 1.08 / 1.12 / 1.16 三档原大对比中取 1.12（`调研/视觉重做/05`）。改系数时，en-mix 的度量覆盖要同步改：(A − D) × k = 0.76，A + D = 1。

**嵌入工程约束**：绑定的字体文件必须是 TrueType 轮廓（glyf）。Chromium 打印管线会把 CFF/OTF 轮廓退化为 Type 3 嵌入。验收：`pdffonts` 全部为 CID TrueType、零 Type 3。字体文件须在 Vivliostyle 入口 HTML 所在目录之内（或以符号链接引入），否则会静默回退到系统字体。用符号前先查字体覆盖：STIX 缺 → (U+2192) 与 ▸ (U+25B8)。

### 字号阶梯

| 级 | 字号 / 行高 | 角色 |
|---|---|---|
| 考点号 | 24pt / 42pt（2 格） | sans-ui 700，主色，居柱 |
| 考点标题 | 18pt / 42pt | sans-ui 700，墨 |
| 柱标签 / 小标题 / 解析 / 要点 / 练一练 | 12pt / 21pt | sans-ui 700 墨 |
| 例 n | 12pt / 21pt | sans-ui 700 主色（编号） |
| 柱注 `gloss`、柱内注 | 9pt / 13.5pt | sans-ui 墨，最多两行（注最多三行） |
| 中文正文 | 12pt / 21pt | serif-cjk，两端对齐，段首缩进 2 字，段间不空 |
| 英文语料 / 证据 | 12pt / 21pt | serif-en，左对齐，不两端对齐；证据行斜体、缩进 2em |
| 例题题干 | 12.75pt / 21pt | serif-en，比讲解大一档，让例题当主角 |
| 解析标签（句意 / 成分 / 词形 / 故填） | 12pt | sans-ui 500，墨 |
| 注 | 10.5pt / 21pt | serif-cjk，下移 0.57pt 对齐基线 |
| 辅文 | **9pt** | sans-ui：出处 `[2025·北京卷]`、考频、句型签、表头、页脚、语篇说明 |

标题 / 正文 = 1.5–2.0。相邻两级字号相差不足 1.5pt 的，视为同一级，不得并存（实测：0.5pt 一档形不成层级，只会让灰度不匀）。

### 中西混排硬规则

1. 英文语料块**按英语规则断行**（按词、按意群），永远左对齐，禁止两端对齐和音节断行（`hyphens: none`）。
2. 中文段落两端对齐；含西文的行只调整汉字和中西间距，西文词间距不参与（clreq 6.2.3）。
3. 行尾全角标点压半宽、相邻标点挤压：`text-spacing-trim: trim-both`（实测 Vivliostyle 2.45 下生效；`text-spacing: trim-start allow-end …` 不生效）。
4. 汉字与西文、数字之间**一律加半角空格**（约 0.24em，合 clreq 6.3.3「不多于四分之一字宽」）；不得一处有空格、一处没有。紧挨中文标点一侧不加。
5. 卷标、考频等元数据是辅文，**永不插入英文句子内部**。
6. 同一份文档内英文字族锁死：句外语料用 `serif-en`，句内夹排用 `en-mix`；禁止无衬线英文混入语料（UI 短码除外）。

## 4. 间距

| 令牌 | 值 | 规则 |
|---|---|---|
| `--h` | 10.5pt | 最小块间距：句型行上下、解析与题干之间、注与上块之间 |
| `--u` | 21pt | 大块间距：例题之间、要点卡上方、练一练上方、考点头下方 |
| 块内边距 | `--h` 上下 + `--zi` 左右 | 要点卡等底色块 |
| 段落 | 段间 0，段首缩进 2 字 | clreq：段间空行表示一节结束，段落之间不用空隙 |
| 左缘纵轴 | 两条：柱左缘、正文栏左缘 | 所有元素只落在这两条轴上 |

旧版「生产间距」逐 class 列的 0.28em、1.6mm 等数值全部废止，由半格规则取代。

**密度预算**（每 A4 页）：描边框 0（课页）；底色块 ≤ 1 种；斜的或浮起的元素 0；同一句上的指示符 ≤ 2；一页组件种类 ≤ 7。

## 6. 明确禁止

- 一页一个新主色（分隔页除外）。
- 目录彩虹章色、红黄徽章墙、梯形钻石仪式标题、营销条 / 二维码广告牌。
- 吉祥物、半透明水印、细纹装饰底、渐变色带。
- **网页惯用语**：左缘裸竖条（blockquote 边条）、卡片投影、胶囊按钮态、整行拉满的荧光底。判据是「印刷品里见过吗」，不是「网页里好看吗」。
- 大面积主色实地（A4 自印墨量）。
- 灰色文字、半透明线、低于 9pt 的文字。
- Agent 写内联样式、发明 class（施工纪律，见 03）。

## 7. 验收指标（渲染后自动检查）

`python3 -I 调研/视觉重做/工具/指标.py <pdf>` 输出以下各项，须全部满足：

| 指标 | 要求 |
|---|---|
| 正文字号 / 行空 | 12pt / ≥ 3.0mm |
| 最小文字字号 | ≥ 9pt（▶ 等记号除外） |
| 英文最长行 | ≤ 80 字符 |
| 描边框（课页） | 0 |
| 半格基线对齐率 | ≥ 95% |
| `pdffonts` | 全 CID TrueType，零 Type 3，无系统回退字体（DejaVu / WenQuanYi / Liberation） |
| 行首行尾禁则 | 违例 0 |

黑白可读性用 `网点模拟.py` 抽查：文字须为实地、不挂网。

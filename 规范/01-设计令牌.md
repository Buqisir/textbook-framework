# 01 设计令牌

风格代号 **澄页**。目标一句话：学生拿到手的第一感觉是「信息好清楚，而且好看」。
配方：日骨（旺文社的主题闭环 + 双色职能 + 网点分层）、英皮（ClearRevise/Oxford 的浅底圆角、语料衬线、克制色量）、中魂（考点树 + 分层闭环 + 解析公式，见 02/03）。

本文件是视觉层唯一权威。CSS 与本文件冲突时改 CSS。改令牌须项目负责人确认。

## 1. 页面几何

| 令牌 | 值 | 说明 |
|---|---|---|
| `page-size` | A4 210×297mm | 单一输出，纸屏两用，RGB |
| `margin-top` | 16mm | 页眉带在版心内，不另占 |
| `margin-bottom` | 18mm | 页脚页码 |
| `margin-inner` | 16mm | 装订侧 |
| `margin-outer` | 14mm | 切口侧留给专题竖签 |
| 栏制 | 课页**单栏纵栈** | 密度靠模块纵序，不靠加栏（旺文社纪律）。仅三处例外：练习小题可双栏、解析内「推演\|旁注」62–70/30–38、目录双栏 |

页眉：外上角**坐标角标**（主色小方块白字，如 `语法填空 · 03`）+ 右侧浅主色条写专题名。页脚：外下角页码 + 册名小字。左右页镜像。

## 2. 色彩

有效色相两个：**青（结构）+ 黄族（物件）**，加灰阶。这是全部预算。

| 令牌 | 值 | 职能 |
|---|---|---|
| `--paper` | `#FFFFFF` | 纸 |
| `--ink` | `#232629` | 正文墨。中文讲解、英文语料、题干全用它 |
| `--ink-dim` | `#63676D` | 中译降对比、元数据、页脚 |
| `--accent` | `#1E6F8C`（沉靛青） | **唯一路标色**：所有标签、题号、框线、图标、芯片、旁注三角共用。实地只用于 ≤1 行高的签/方/芯片或 ≤0.75pt 线 |
| `--accent-wash` | `accent 12% + 白` ≈ `#E3EDF1` | **记忆层唯一底色**（要点卡）。铺大即升级为记忆，禁止随意当装饰底 |
| `--ash` | `#F0F2F4`（墨 8–12% 感） | **结构层**：章条、答案分组底、导图底。灰永不承担强调 |
| `--cream` | `#FDF9EC` | **语料盒专用底**（英文被分析物） |
| `--hl` | `#F5EE58` | **已退役**（2026-08 裁决：日系荧光笔手势与本书冷调不合）。黄族只当容器色（`--cream`/`--sample`），不当笔迹色。令牌保留备查，禁止新用途 |
| `--sample` | `#FAEFC0` | 示范答案底（黄族，与语料同族不同浓度） |

层的互斥编码（网点当 z-index，旺文社纪律）：
**白底 = 做题/阅读层；`--accent-wash` = 记忆层；实地青 = 路标；`--ash` = 容器结构；`--cream` = 语料物件。** 每层一种手段，禁止一层两种编码或两层共用一种。

警示/易错不开新色：走「注」组件（青小方 + 小字 + 细箭头，见 03）。禁止红章、橙章、徽章墙。

## 3. 字体角色

角色制，不写死字体名。默认绑定全部 SIL OFL、可嵌入售卖。

| 角色 | 默认绑定 | 用途 |
|---|---|---|
| `serif-cjk` | 思源宋体（VF） | 中文讲解正文、解析正文。**要读的知识** |
| `serif-en` | STIX Two Text | 英文语料、例句、题干英文。**被分析物**。讲解句内的英文单词/短语也用它 |
| `sans-ui` | 思源黑体（VF） | 栏头、标签、芯片、页眉页脚、题号、表头。**界面** |
| `hand`（预留） | 待定 | 手写/临摹页型引入时再绑 |

黑体=界面、宋体=知识、衬线英=语料，三声部在同一页共存即层级（教材帮 + 旺文社共同纪律）。

**嵌入工程约束**：绑定的字体文件必须是 **TrueType 轮廓**（glyf）。Chromium 打印管线会把 CFF/OTF 轮廓退化为 Type 3 嵌入（无 hinting、子集碎片化、印刷 RIP 风险），验收标准：`pdffonts` 输出全部为 CID TrueType、零 Type 3。因此 serif-cjk / sans-ui 用 Noto Serif SC / Noto Sans SC 的 TTF 构建（与思源同源同形），serif-en 用 STIX Two Text 官方 static TTF。

### 字号阶梯（print pt）

| 级 | 字号/行距 | 角色 |
|---|---|---|
| 专题大标题 | 20pt / 紧 | sans-ui 粗 |
| 节头（考点标题） | 14pt / 1.3 | sans-ui 粗 + 主色方块号 |
| 栏头/容器签 | 9.5pt | sans-ui 粗，白字坐色签 |
| 中文讲解正文 | 10.5pt / **1.75** | serif-cjk。行距宁松勿压（学研纪律：密的是块数，不是行距） |
| 英文语料块 | 10.5pt / **1.55** | serif-en。有句上标注时行距增至 2.1（标注占位另算，禁止从正文行距里偷） |
| 中译（对照时） | 9.5pt / 1.6 | serif-cjk + `--ink-dim`。字号降、灰度降，宣告「先读英文」 |
| 解析正文 | 10pt / 1.7 | serif-cjk |
| 旁注/元数据 | 8pt | sans-ui，`--ink-dim` 或主色 |
| 页脚/行号 | 7.5pt | sans-ui |

### 中西混排硬规则

1. 英文语料块**按英语规则断行**（按词、按意群），永远左对齐，禁止两端对齐切音节（`be-fore` 是事故）。
2. 中文义项括号挂在空格/词后同行，字号 ≈ 英文 x-height，与题干差距 ≤2pt。
3. 卷标、考频等元数据是芯片组件，**永不插入英文句子内部**。
4. 句法标注层必须自带行高（标注行 + 英文行），见 03。
5. 同一份文档内英文字族锁死 `serif-en`，禁止无衬线英文混入语料（UI 短码除外）。

## 4. 间距与密度

| 令牌 | 值 | 规则 |
|---|---|---|
| `gap-block` | ≥ 3.2mm（0.8em@10.5pt 以上） | **块与块之间必须能用拇指分开**。这是不可侵犯的留白 |
| `pad-card` | ≥ 2.5mm | 要点卡、语料盒内边距，不省 |
| 块内 | 可紧 | 留白属于块的边界，不属于块的内部 |
| 左缘纵轴 | 一条 | 节号、容器签、框线、卡边共线对齐。乱来自横向漂移 |

**生产间距（2026-08-25，冠词配平定版）**：`gap-block` 下限 3.2mm 不动；块与块不得再贴。全书共用一套块内值（禁止单元专属小灶）：`.toc li` 行距 0.2em；`.tip` 外距收到 `gap-block`、内边 2.5/2.2mm、行高 1.5；`.explain` 行高 1.62、直系 `p` 段距 0.28em；`.subhead` 0.1/0.35em；`.pattern` / `.compare` 块内边距收半；`.compare td` 0.22em；`.stem` 内边 ≥`pad-card`、与解析间距 1.6mm；`.solution` 行高 1.58、底边 2.2mm、直系 `p` 0.26em（顶 pad 4mm 留给解析签骑线，不收）；`.evidence` 0.15/0.2em；`.solution aside p` 0.4em；`.keypoint` 行高 1.55（外距仍 ≥`gap-block`、内距仍 ≥`pad-card`）；`.drill` 线内顶距 1.5mm、栏头下 1.8mm、`.drill-atoms li` 0.42em。禁止 `example + example` 的 `break-before: avoid`（引擎会把整组例题推到下一页）。

密度预算（每 A4 页）：斜的或浮的元素 **≤1**（斜缎带、带投影的卡二选一都算）；同一句上的指示符（色字/下划线/上标/标注）**≤2**；行间注 **≤每两句一条**；一页组件种类 ≤7。

## 5. 线、角、影

| 项 | 值 |
|---|---|
| 强调框线 | 0.6–0.75pt `--accent`（题干框） |
| 结构线 | 0.5pt 墨 30–40%（表行、分隔） |
| 虚线 | 主色 40%（要点卡内竖分隔、对折自测中缝） |
| 圆角 | 卡片 6–8px；签/芯片 3–4px；题干框直角 + **单折角**（右下三角实地 4–6px） |
| 折角记号 | **品牌记号**（「澄页」= 翻起的页角），每页限两处：题干框右下（4–6px）、页眉坐标线订口端（微型约 1.2mm）。其他位置禁用 |
| 对纸记号 | 对折线两端各一条约 4.2mm × 0.75pt 主色实心短竖，骑在虚线上。禁止三角（与折角同构） |
| 投影 | 仅要点卡与语料盒：`0 1px 2px` 墨 12–18%。印刷感薄影，禁止 Material 大影 |

## 6. 明确禁止

- 一页一个新主色（ClearRevise 的换页换粉彩不进课页；分隔页除外）。
- 目录彩虹章色、红黄徽章墙、梯形钻石仪式标题、营销条/二维码广告牌。
- 吉祥物、半透明水印、细纹装饰底。
- **网页惯用语**：左缘裸竖条（blockquote 边条）、整行拉满的荧光底、卡片大投影、胶囊按钮态。参考教辅零出处的处理一律不进——判据是「印刷品里见过吗」，不是「网页里好看吗」。
- 大面积主色实地（页眉满版海军条不进：A4 自印墨量）。
- Agent 写内联样式、发明 class（施工纪律，见 03）。

# 项目共识

2026-08-24 与项目所有者拷问式对齐后的结论。改动任何一条须所有者确认。

## 目标与用途

- 蒸馏自有特色的教辅风格与 UI 语义，产出 **Agent 可执行的生产框架**：Agent 拿框架 + 原始文字素材，即可产出成品教辅 PDF。
- 用途：先给所有者自己的学生做自印成册讲义；将来可能直接售卖电子本（不走出版社）。
- 学科锚点：高中英语。风格语义层设计为学科无关（栏目体系、层级、网格不绑定英语），日后可迁移。

## 风格配方：日骨・英皮・中魂

- **日骨**（Gakken、旺文社）：信息编排密度为骨架。
- **英皮**（ClearRevise、Oxford Revise）：克制美感为皮肤。
- **中魂**（教材帮、试题研究、试题调研）：考点组织与题量逻辑为内容结构。
- 学生第一感觉押「信息好清楚，而且好看」。

## 视觉硬约束

- **色彩**：克制全彩——纪律上接近日系双色（一个主色 + 一个强调色 + 灰阶），局部允许第三色。打印机墨量友好。
- **语言**：讲解中文、语料英文。中西字体配对（字族、字号补偿、基线对齐）是核心资产。
- **字体角色制**：令牌层定义角色，不写死字体名。默认绑定（全部 SIL OFL 可商用、可嵌入售卖）：
  - `serif-en` → STIX Two Text（Times 血统开源后裔）
  - `serif-cjk` → 思源宋体（7 字重）
  - `sans-ui`（标签/栏目头） → 思源黑体
  - 本地自印版若更喜欢系统 Times New Roman + 宋体 SC 的味道，改令牌绑定即可；售卖版永远用开源轨。
- **输出**：单一 A4 PDF，纸屏两用。RGB，无 CMYK/出血（「印刷级别」= 质量过关，非印厂标准）。

## 交付物（三层）

1. **内容语义 schema**：教辅内容类型的结构化定义（考点讲解、例题精讲、词汇框、易错警示、练习、答案详解等）。Agent 把原始文字装进 schema。
2. **版式语义规范**：内容类型 → 版式组件映射、网格、密度规则、设计令牌。
3. **Vivliostyle 主题模板**：确定性渲染。Agent 不碰像素层。

## 验收标准

一份「语法填空专练」样章 PDF，页型为专项讲练（考点讲解 → 例题精讲 → 变式练习 → 答案详解），素材取 student system 现有语法填空真题单句数据。样章印出来像不像样，是整个框架的验收标准。

## 工程决策

- 本项目独立于 `student system`：自装 Vivliostyle，方法论借鉴其设计约束文档 + 密度 QA 模式，不复用其基础设施。
- 不考虑与 student system 现有六套主题的反向兼容。
- 参考样张每套 3–5 页，蒸馏对象是版式语言（网格、色板、组件、密度）；整本结构（目录、章节节奏、页型家族）自创，不从参考里抄。
- **练习册与答案册分订**（2026-08-25）：练习册拼各专题讲练（讲 + 例 + 练，练里无钥匙、无详解）；答案册另订一份，拼各专题练习的钥匙与详解。检测件答案不进练习册。
- **冠词切法**（2026-08-25）：废「特指与标记 / 泛指 / 搭配」和拥有测试主轴。考点树、八句判断、真题随点 / 模拟检测见 `02`「专题切法：冠词」。

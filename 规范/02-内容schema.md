# 02 内容语义 schema

Agent 的工作面。Agent 拿到原始文字素材后，把内容装进本文件定义的结构，产出语义 HTML；版式由 03 + CSS 主题确定性渲染，Agent 不碰像素层。

**词汇表是封闭的**：只允许使用本文件列出的内容类型与字段。素材装不进现有类型时，停下来向负责人报告，不许发明新类型。

## 1. 文档结构树

```
练习册 booklet
└── unit 专题 ×n（如「语法填空 · 冠词」）
    └── topic 考点节点 ×n     ← 最小闭环单位
        ├── topic-head   考点头（必有）
        ├── explain      考点讲解
        ├── example      例题精讲 ×n
        ├── keypoint     要点卡
        ├── note         易错警示/注
        └── drill        变式练习（只留题：subhead 分组 → drill-atoms → drill-passage）

答案册 booklet                         ← 另订一份，不接在任一专题正文后
└── 区头 + [单元组头 → answer-key → rationale] ×n
```

**排序键永远是考点树**（超重点 → 类型 → 技法），年份只是题的属性，真题不得按年成章（中魂第一定律）。

**槽位规则**：topic 内六个槽位空槽可省略，**顺序不可换**。例题精讲必须当面闭合（题干 + 解析同处；2026-11-04 起解析可续到次页，但至少前两行与题干同页，见 03 §3）。检测件答案不进练习册，一律进答案册。

**例外：小条贴身例题**（2026-08-25）。知识点由若干互不相干的小条拼成时（如冠词固定搭配），允许 `explain` 与 `example` 交替：每条 = 一个 `subhead` 起头的 `explain` + 紧跟一道 `example`，讲完一条立刻演示一遍，不攒到节末。此时 `keypoint` / `note` / `drill` 仍在全部小条之后，顺序不变。适用条件：小条之间没有共同的判断动作可讲，笼统罗列会让讲解空转。

## 2. 内容类型定义

### topic-head 考点头
字段：`no`（树内编号）、`title`、可选 `freq`（考频，如「5 年 4 考」）、`risk`（失分点/创新考法，最多一枚）。

### explain 考点讲解
中文讲解正文（serif-cjk 声部）。内部允许的子元素：
- `subhead` 小标题——讲解内「这一条的名字」；也用于 `drill` 内给真题 / 模拟分组（见下）
- `em-atom` 句内强调原子——只涂**可背的原子**（时态名、连接词、日期、公式名），一行 ≤3 个，禁止整句
- `pattern` 句型/公式行（英文用 serif-en）
- `compare` 辨析对（两栏小表：常见义 vs 考场义、A 结构 vs B 结构）。时态类辨析可加首列时间轴：`<th class="axis">`、`<td class="axis" data-axis="point|span|two">`（03 §2a），单元格内不写字
- 英文例句行：英句 + 中译 + 可选教材坐标，三相顺序固定，中译降级
- 段落：一个意思一段；段间不空行、不用空 `p` 调距（段首缩进由 CSS 给）

### example 例题精讲
- `stem` 题干：`source` 芯片（第一个子元素）+ 英文语料（serif-en 整块，按词断行）+ 空位 `blank` + 可选提示词 `(word)`
  - 可选 `gloss`（题眼），紧跟 `source` 之后
  - **题号由 CSS 计数生成**（2026-11-04）：内容里不写「例 1」，也不写题型说明（「写出括号内动词的正确形式」）。同一单元题型统一时，题型说明只在练习的 `drill-passage` 说明行或单元首交代一次
- `source` 芯片（必填）：`{ year, paper, item?, origin: real | adapted | original }`——原创也打标，避免「无标 = 真题」误读。芯片挂在题号侧，永不插入英文句内
- `solution` 解析，**公式锁死、空槽可省、顺序不许乱**：
  - 语法填空：`句意（中）→ 缺什么成分/词性 → 原文证据（英文整块引用）→ 词形变化 → 故填 ___`
  - 选择/阅读：`题型 → 题干意为 → 原文证据 → 故选 ___`（完形加「选项中英对照」）
  - 长难句：`Step 1 结构 → Step 2 语境定形式`
  - 英文证据单独成 span，左齐；答案词在句首与句尾各出现一次
- 可选 `aside` 旁注列：教师口令式短句（「先找谓语」），不是概念重讲

### blank 书写空（2026-11-04 新增）
题干、练习、证据行里的空位。取代旧的 `______` 下划线字符——字符画的线不能定宽、不能定位，也不是真正的书写空间。
- 单句题：`<span class="blank"></span>`
- 语篇内带号：`<span class="blank" data-no="5"></span>`（号码由 CSS 悬在线左，内容里不写「5.」）
- 证据行引用原句时同样用 `blank`

### gloss 柱注（2026-11-04 新增）
住在左柱里的一句结论，让学生只扫左柱也能复习。`<aside class="gloss">`，紧跟在它所属的标签之后：
- `explain` 内：跟在 `subhead` 后（如「时间信号 → 时态」）
- `stem` 内：跟在 `source` 芯片后，写**题眼**（如「题眼 By the time」）
- `solution` 内：跟在 `<h4>解析</h4>` 后，写**口令**（如「锚点 brushed<br>→ 过去的过去」）
- `drill` 内：跟在 `<h4>练一练</h4>` 后，写一句动作提示（如「先画轴，再动笔」）

写法：**最多两行、每行不超过 10 字**，写成「关键词 → 结论」；换行处可用 `<br>`。只能从本块已有内容里提炼，不得引入新知识点。由干活 Agent 提炼，负责人或所有者审定；审不过宁可留空。

### keypoint 要点卡
可背的规则/句型公式。一张卡一条主张；`label`（默认「要点」）+ 内容列。这是全书唯一「请记住」的容器，别的内容不许借用。

### note 注 / 易错
一句话贴在具体的式子/句子上（「同类项竖着对齐更好算」）。字段：`target`（指向哪一行）。警示不开新色、不做红框。
- **首选位置**（2026-11-04）：放进 `explain`，紧挨在它解释的段落**之前**，版面上住进左柱。此时压成最多三行短句（「by the time 从句<br>→ 用一般过去」）；原句里正文已讲过的部分不重复。
- 不贴具体段落的注，仍放在 topic 级 `keypoint` 之后。

### drill 变式练习
分层闭环（中魂第二定律）：同一批考点，**先原子后语篇**。练习册的 drill **只留题**。
- `subhead`（drill 内）：真题一组、模拟一组，各一条。无则省。
- **真题随点**：各考点 topic 的 drill 只收本点真题（无则整段省略）。
- **模拟检测**：同单元模拟集中到单元末一个 topic，标题固定为「模拟检测」；drill 只有「模拟」一条 subhead，内部混合，不按本单元考点再切。**不写方法提示**（2026-08-27）：检测节前放一句「先认说法，认不出再往上一句找指的是哪一个」这类提示等于把全章方法再摘一遍，而学生翻到此处是来做题的，方法已在前面各节讲完；节头之后直接进题。仅模拟才有的考点（如冠词「修饰补充的不定冠词」）可在本点用模拟当 `example`，检测件仍进「模拟检测」。
- `drill-atoms`：单句题组（选择/拼写/单句填空），**全单元连续编号**（各点真题小练接着编，模拟检测续编）。**每题必有** `source` 芯片，挂题号侧，永不插入英文句内。高考真题芯片写卷别（`2026·浙江一卷`）；模拟写卷名（`2026·嘉兴二模`）；原创写「澄页原句」。句子必须完整。**返指**（同名、换名、关联）必须带上先行词所在的完整句（或紧邻上句），学生要看得见指的是哪一个；只留空所在句算出题失败。
- `drill-passage`：短语篇语法填空（可标「素材改编自 …」）；有则放在原子题组后。
- `answer-key` 与 `rationale`：**不进练习册，进独立答案册**（2026-08-25：检测件答案不与题同册）。
  - `answer-key`：横排钥匙 `1. C  2. B …`，放在答案册该单元组头下
  - `rationale`：逐题详解**条**，接在钥匙后。不复用 solution 全公式（全公式只住在 example 里）。每条 = 题号 + source 芯片 + 原句（含空格与提示词）+「故填」答案 + 一行中文理由（合并成分判断与词形推导，≤22 字）
- **教学件豁免**：example 的 solution、语篇精讲页的逐空解析是教学内容，当面闭合，不进答案册

### 答案册
独立 booklet（另文件、另 PDF）。页眉坐标 `data-no="A"`、`data-unit="答案与详解"`。结构：区头 → 按单元分组（组头 = 单元号 + 单元名，同目录分组语法）→ 该单元 answer-key → 该单元 rationale 条目流。各专题答案在此拼接，不接在练习专题正文后。

### 页型：语篇精讲（组装方式，见 03 §1b）
零新类型：`topic-head`（篇目头，卷别 chip）→ `corpus`（整篇含空）→ `rationale`（逐空解析，语篇页每条可带 `evidence` 摘录行）→ `keypoint`（本篇考点归纳）。

### 独立页型组件（不住在 topic 内）
- `corpus` 语料盒：被完整分析的源文本（衬线 + 奶油底 + 行号）
- `sample-answer` 示范答案（黄底，答句斜体，赋分标记）
- `tip` 提示框：应试元评论（「这题通常 4 分钟内完成」）
- `retrieval` 对折自测表：左问右答 + 中缝「把纸放在这里」（预留，样章不用）
- `toc` 目录：双栏，青号 + 黑题 + 点线 + 页码，色只给号

### 页型：日卡（识记机，2026-09-08）

一天一页的对折自测，**不是**专项讲练。题与钥匙同页——对折本身就是产品，不走练习册 / 答案册分订。

```
booklet
├── opener     周扉（周号 + 本周日录；不另出独立 toc）
└── unit.day ×n
    ├── topic-head   完整日期 + 周几（不挂科目 chip）
    ├── face         上半页题区
    │   ├── stem     早读：文1–3（古诗）+ 理1–2（数/物/化方程式混排）；只留题
    │   └── drill    抽测 5 条（数物化语各 1 + 道法/历史隔日 1；drill-atoms + write）
    ├── fold         对折线，文案锁死「对折朝下，写完再看」
    └── answer-key   下半页钥匙（文1–3、理1–2、抽测 1–5；不印卡号）
```

- 早读每天固定 **古诗 3 + 公式 2**，不再「一天只背诗」或先走完一科公式。stem 首行写「早读 · 古诗 3 + 公式 2」。
- 公式 / 化学方程式用 HTML 上下标（`<sup>` / `<sub>`），不写 `am·aⁿ`、`2H2O2`、`I2R`、`Mg2+` 这种纯文本伪指数。平方（`I²R`、`(a+b)²`、`sin²A`）走上标；电路下标（`I₁`）与化学计量（`H₂O`）走下标；离子电荷（`Mg²⁺`、`SO₄²⁻`）走上标，禁止收成 `Mg₂⁺` / `SO₄₂⁻`。反应条件 `--MnO2、Δ-->` 收成 `rxn-arrow`（Δ/点燃/通电/高温在上，催化剂在下），禁止收成 `—MnO2、Δ→`。
- `write`：空块，CSS 画横线。抽测每条一条（题号与题干同行）。早读十条装一页，只给句内 `<u>` 空，不另起整行写线。
- 钥匙里源面「填；填　整式」只印整式；`=；=` 这种两空提示不进印刷面。抽测答案可带大纲 `备注`：源面写成「答案。注：…」，印刷面挂复用 `note`，不上题面。
- 科目签复用 `chip-freq`，不另开 class。
- 卡号（`math-001`）是源数据坐标，**不进印刷面**。
- 页眉坐标：`data-code` 写周码（如 `识记 · 01`）；每个 `unit.day` 的 `data-no` 写当天序号，`data-unit` 写 `MM-DD 周X · 诗+数物`（当天文+理，只在骑线出现一次）。日头只写完整日期 + 周几。
- 页脚刊名：`东莞2027中考`（不印「瞳瞳识记机」）。
- 单日周周扉落款只写一天，不写 `2027-06-30 至 2027-06-30`。`opener` 加 `data-days="1"`，目录改走日牌（标「本周 1 天」+ 当天序号），落款收到日牌下，不按七日清单排。
- 第01周周扉可挂裸 `aside`（无 class）写用法，三短段，其他周不挂。

## 3. 元数据字段（全局）

```
source:   { year, paper, item?, origin: real | adapted | original }
freq:     "10年3考" 类考频字符串
risk:     失分点 | 创新考法（二选一，最多一枚）
textbook: { unit, page, role: example | adapted_passage }   ← 教材回链
```

教材回链（从哪来）与考情回链（往哪去）分开存，**同一标题行禁止两枚一起闪**。

## 4. HTML 产出约定

- 语义 HTML + 本 schema 的 class 名（closed set，见 03 映射表）。
- 结构示意：

```html
<section class="topic" data-no="1.2">
  <header class="topic-head">
    <h3>动作时间轴定谓语时态</h3>
    <span class="chip chip-freq">5年4考</span>
  </header>
  <div class="explain">
    <p class="subhead">先找时间坐标</p>
    <p>句子里出现 <span class="em-atom">last year</span> 时……</p>
  </div>
  <article class="example">
    <div class="stem">
      <span class="chip chip-source">2026·全国一卷</span>
      <p lang="en">By the time he arrived, the train <span class="blank"></span> (leave).</p>
    </div>
    <div class="solution">
      <p><b>句意</b>：他到达时火车已经开走。</p>
      <p><b>成分</b>：by the time 引导时间状语从句，主句需先于过去的动作。</p>
      <p lang="en" class="evidence">By the time he arrived</p>
      <p><b>故填</b> <b class="ans">had left</b>。</p>
    </div>
  </article>
  <aside class="keypoint">…</aside>
  <div class="drill">
    <h4>练一练</h4>
    <div class="drill-atoms">
      <p class="subhead">真题</p>
      <ol>
        <li>
          <span class="chip chip-source">2026·全国一卷</span>
          <p lang="en">… dates back to <span class="blank"></span> Han Dynasty.</p>
        </li>
      </ol>
    </div>
  </div>
</section>
```

- 中文内容不加 `lang`，英文语料块/证据加 `lang="en"`（触发 serif-en 与英语断行规则）。**中文句子里夹的英文不加 `lang`**，由 CSS 的 en-mix 自动放大 1.12（01 §3）。
- **引号**一律“ ” ‘ ’（GB/T 15834 4.8.2），不用「」『』。
- **汉字与英文、数字之间一律加一个半角空格**；紧挨中文标点一侧不加（`在 now 上，` / `last year、since 2019`）。不得一处有空格、一处没有。
- 练习题号：一个单元内连续编号，跨 topic 接续时用 `<ol start="8">`；不在 `li` 里手写号码。
- **禁止**：内联 style、schema 外的 class、用空 div 调间距、在英文句内塞中文元数据。

## 5. Agent 工作流

1. 读素材，按考点树切分出 unit / topic。
2. 逐 topic 填槽：能填的槽填满，填不进的内容报告负责人，不硬塞。
3. 每题补 `source`（例题与 drill 原子题都要）；讲解里挑出 em-atom（宁少勿多）。
4. 产出两份 HTML（均引主题 CSS）：练习册专题文件（无 answer-key / rationale）；答案册文件（按单元拼接钥匙 + 详解）。分别交渲染管线出 PDF。
5. 渲染后自查：断页有没有把要点卡/题干框切开、英文有没有被音节断行、密度预算（03 §4）有没有超。超了回到结构层调整（拆 topic、移 drill），**不改 CSS**。

## 6. 专题切法：冠词

废「特指与标记 / 泛指 / 搭配」和拥有测试主轴。一个知识点一个 `topic`，扫描序如下（讲解口吻仍是澄页冷调，不搬原书术语腔）。

**单元内按冠词分两组**（2026-08-25 二改）：定冠词四节 → 不定冠词三节 → 模拟检测。组头复用 `toc-group`，`data-no` 写 `the` / `a/an` / `测`，不新增 class。类指整节撤销（见下）。

**每组内先讲会推理的，固定搭配压到组末**：前面几节教的是「往哪儿看」，末节收一份「只需认说法」的清单，学完方法再背清单。

| 号 | 组 | topic | 装什么 | 判断 |
|---|---|---|---|---|
| 1.1 | the | 返指 | 同名、换名、关联 | 前文已经在谈这个东西，或谈过和它绑死的事物 → **the** |
| 1.2 | the | 共同语境 | 周围情景、大情景、独一无二 | 这个名词前文没当谈论对象出现过，当场 / 本地 / 世上能定 → **the** |
| 1.3 | the | 限定词（包括 of） | 后置修饰限定、of 限定（事件 / 部分特征） | 后置短语、从句或 of 把「哪一个」定死 → **the**；of 只标明种类，不走这格 |
| 1.4 | the | 固定搭配 | 六小条，见下 | 空落在这些说法上 → **the**，停 |
| 1.5 | a/an | 第一次用的不定冠词 | 首次引出 + 类型里的任一 | 单数可数，读者定不到哪一个 → **a/an** |
| 1.6 | a/an | 修饰补充的不定冠词 | 只进模拟 | 给已经在场的人 / 物补身份（系动词后、同位）→ **a/an** |
| 1.7 | a/an | 固定搭配 | 两条：①纯搭配 *a touch/range/amount of*、*quite a*、*for a while*、*as a result*；② *a* + 抽象名词指具体一件事 *a success / a pleasure / a great help / a must / a must-read* | 空落在这些说法上 → **a/an**，停 |
| 1.8 | — | 模拟检测 | 本单元全部模拟，内部混合；修饰补充至少 4 题 | 无说明句，节头直接接「模拟」subhead |

节名 1.4 与 1.7 同叫「固定搭配」（2026-08-27 由「固定搭配的特指」改）：二者分挂在「用定冠词」「用不定冠词」两组之下，组头已给出冠词，节名再带「的特指」是重复；同名反而让两组对称，学生一眼看出两种冠词各有一份清单。

**1.4 拆小条，一条一例**（2026-08-25）：定冠词的固定搭配不是一堆无关的死记项，各条各有道理，笼统罗列等于没讲。拆成六条，每条 = `subhead` 一条 + 两三行讲解 + **紧跟一道带解析的 `example`**，学完一条立刻见一个完整演示：

| 条 | 装什么 |
|---|---|
| 1 | 形容词最高级、序数词 |
| 2 | *one … the other*、*the same* |
| 3 | 专名带 the：朝代 / 大洋 / 姓氏指一家人 |
| 4 | 量化说法：*the number of*、*most / three-quarters of the time* |
| 5 | *the* + 形容词表一类人 |
| 6 | 短语里固定带 the：*all the way*、*take the lead* 等 |

第 5 条吃掉原「类指」整节，「说一整类」组随之撤销。**2026-08-27 再收窄**：原第 5 条兼收的「*the* + 单数表一整类」删去，只留 *the* + 形容词。理由是全库只有两道题归得进类指，其中一道回原卷后判定实属返指（*the tea ceremony* 的上一句正在讲洗杯、弃第一泡这套茶事仪轨，此处是用一个笼统的词回指前文，与「用单数代表全类」无关），剩一道即 *the blind*；且同一意思用 *a* + 单数或复数都通，填 the 还是 a 取决于句子本来用哪种说法，不构成可判断的依据。零冠词那种答案是「不填」，高考冠词空不这么设。

**1.7 拆两条**（2026-08-27）。原先一段话把 *a touch of* 与 *a must* 混在一处，但两者性质不同：前者的 a 是短语的固定成分，学生只需认说法；后者是 *success / pleasure / help / must* 这类抽象名词转指具体一件事而变可数，有道理可讲，也能迁移到没背过的词上。故分两条，各配一例（①*a touch of*，2023 新课标一卷；②*a must*，2021 新课标一卷），②另配深圳一模 *a must-read* 一道贴身模拟。**只有纯搭配才配笼统写法**——凡有可讲的道理，就不许塞进清单。

**题干必须自足**（2026-08-27 立）：单句题的题干要让学生只凭纸面就能定出答案，凡有下列情形，一律回**源卷或真题库**（不是选题池——池里的「先行句」列多为空）抠够上下文再入册：① 空前的名词是回指前文的（*the festival*、*the shift*、*the tea ceremony*）；② 空所在句里有 *them*、*this*、*among them* 一类指代成分悬着（*this world cultural heritage*、*among them*）；③ 判断依据是「给已出现的人或物补身份」，而题干里那个人或物尚未出现（*Thangka is a unique form…*，需前一句的 *Thangka paintings*）；④ 出现无来由的人名地名（*Watching Liu work*，需交代 Liu 是谁）。反之，凡固定搭配、最高级序数词、读音定 a/an、句内同位这几类，句内即可判定，不必补。此条为**每章交稿前的自检项**，逐题过一遍。

### 讲解口径：指的能不能确定，不是只有几个

冠词的判据是**读的人能否确定指的是哪一个**，不是「世上/屋里/当地只有那一个」。后者一举反例就塌：门可以有两扇，医院可以有两家，车上可以有两个司机，`the door`、`the hospital`、`the driver` 照样成立——成立的原因是指的那个东西在当前语境里能确定，不是物理上唯一。

固定用词：动词用**确定**，名词位置用白话的**指的**（「指的都在上文」「指的就是那一回」），小标题写「已经能确定，用 the」「还不能确定，用 a / an」。「定下来」一类说法不用，口语味重。三个词不用：「认得出／认不出」是说话腔，落纸太轻；「识别」是术语腔，与教辅口吻隔一层；「所指」把「所指代的那个人或事物」压成两字，中心语被砍掉，读者要自己补，且「所+动词」本身是文言结构。补全成「所指代的名词」也不对——冠词定的是那个词说的东西，不是那个词。禁用「只有那一个」「不止一个」「别无可指」式的数数说法（真正唯一的事物如太阳、一座山的顶，可照实说，但不得当作规则）。由此派生的三条硬约束：

- **规则不写成形式规则。**「最高级前面用 the」「be 后面用 a/an」「同位语用 a/an」都有反例（`his latest work`、`He is the leader.`、`She is the teacher I mentioned.`）。凡形式规则必须带上语义条件与限定词条件：前面没有别的限定词、且没有被说到读者认得出。
- **修饰语不决定冠词。**of 短语、定语从句本身都不决定填什么，两类高频模式（动作事件名词加 of、部位属性名词加 of）只是模式，反例必须同列：`a discussion of the problem`、`a height of two metres`。
- **同一条目下的对立情形排成条目对照**（`.item`），不塞进一段散文。如 of 后接所属物用 the／接数值用 a、the other／the others／another 三分。

# 03 版式映射

schema 内容类型 → 版式组件的确定性映射。CSS 主题按本文件施工；冲突处以本文件为准。

**2026-11-04 视觉重做**：课页改为柱式（§0），组件词典 §2 分成「主线」与「待迁移」两张表。推导见 `调研/视觉重做/`，参考实现 `渲染/方向稿/主线.css`。

## 0. 课页通则：柱式

主张：**左柱放骨架，右栏放内容——扫一眼左柱就知道这一页讲什么。**（日骨：Evergreen 的「柱」；英皮：零框、克制色量）

```
|<— 柱 8 字 —>|1字|<———————— 正文栏 33 字 ————————>|
 1.1             动作时间轴定时态                10年主考
 ═══════════════════════════════════════════════════  ← 0.75pt 主色
 先圈时间坐标      真题里时态几乎不靠语感。先把 last year …
 句型             By the time sb. did sth., sb. had …
 例 1             Making choices is part of life. …
 [2025·北京卷]
 解析             句意：…  成分：…  词形：…  故填 had made。
 要点             ▒▒ 浅青底：可背的规则 ▒▒
 注               by the time 从句本身几乎不用完成时 …
 ───────────────────────────────────────────────────  ← 0.3pt 墨
 练一练           1. Henry ________ (fix) …
```

1. **柱里只放「名字」**：小标题、栏签、例题号与出处、「要点」「注」「练一练」。柱里不放句子，最长 8 字。
2. **正文栏里只放内容**：讲解、题干、解析、练习。所有元素只落在两条左缘轴上（柱左缘、正文栏左缘）。
3. **柱元素与它所标的块首行顶端对齐**（实现：柱元素 `float: left; clear: left; margin-left: −(柱 + 栏距)`）。
4. **容器只有一种**：要点卡（记忆层浅青底）。课页零描边框、零投影、零斜元素。
5. 主色只给导航：考点号、考点头下线、柱内导航标签、练习题号。其余一律墨色（01 §2）。

## 1. 页型：专项讲练（锚定页型）

一个 topic 走完五槽：

```
topic-head  →  explain  →  example(题+解当面闭合) ×n  →  keypoint  →  note  →  drill(只留题)
```

- **考点从新页起**（`.topic + .topic { break-before: page }`），不强制左页、不强制对页。一个考点通常 1–2 页。
- drill 的答案钥匙与详解一律进独立**答案册**（§1d）；练习册正文不出现检测件答案。
- 纵比指导（非硬性）：讲解 15–25%，例题精讲 35–50%（**解析必须是页上最大块**），要点 8–12%，练习 15–25%。

**以下页型（1b–1e）尚未迁移到柱式**，仍按旧构造描述；迁移时按 §0 与 01 重做，不得在旧构造上打补丁。

## 1b. 页型：语篇精讲

整篇真题语篇当主角（ClearRevise 语料盒基因首次全尺寸上场）。单栏纵栈，**零新容器**，全部复用词典组件：

```
topic-head(篇目头，chip 挂卷别)  →  corpus(整篇含空 + 行号)  →  逐空解析(rationale 条目流)  →  keypoint(本篇考点归纳)  [→ note 可选]
```

- **corpus 空位**：下划线定宽 + 上标题号 + 括号提示词（与 drill-passage 同款语法）。整篇一盒禁断页；篇幅超版心高 45% 时在**段落边界**拆两盒，行号续排。
- **逐空解析**：复用答案册 `rationale` 双栏条目流，语篇页扩展一档——每条**可带证据摘录行**（serif-en 9pt 墨色，摘录空位前后各 3–6 词，空位下划线保留）。条目题号用空格号（如 61–70）。精讲场景证据行默认给；答案册对答案场景默认省。
- **keypoint 收尾**：本篇考点分布归纳（如「10 空 = 3 谓语 + 2 非谓语 + …」），给学生「这篇考了什么」的地图。
- 纵比指导：corpus 25–35%，逐空解析 50–60%（**仍是页上最大块**），要点 8–12%。一篇一页或一对页闭合。
- 黄族纪律：`--cream` 只出现在 corpus 盒。同页其余部分回到青 + 灰阶。

## 1d. 答案册

检测件答案的唯一居所（2026-08-25 裁决：先不与题同页，后改为**另订一册**）。单独 HTML / 单独 PDF，不接在练习专题正文后。页眉坐标 `data-no="A"`、`data-unit="答案与详解"`，其余页眉页脚语法同练习册正文页。

```
区头(topic-head 同构，标题「答案与详解」)  →  [单元组头 → answer-key → rationale 双栏条目流] ×n
```

- **单元组头**：与目录分组组头同构——主色实地小方（单元号白字）+ sans-ui 粗单元名。
- **answer-key**：`--ash` 底横排钥匙，贴组头下。
- **rationale**：双栏条目流，**必须双栏平衡**（`column-fill: balance` 对所有 rationale 生效——单列长龙是违规版式）。
- 多单元连排（各专题练习答案在此拼接）；组间距 ≥ 2×`gap-block`。密度预算同 §4。

## 1c. 册级件：封面 / 章扉 / 目录页

品牌语法的三个尺度放大场：折角记号（页眉 1.2mm → 章扉中号 → 封面全尺寸）、骑线坐标、色只给号。全部白底，只用青 + 墨 + 灰 + `--accent-wash`，无插画无照片。

**封面**（2026-08-25 A/B 裁决定稿 B 构图）：
- **右下角大折角**（与题干框单折角同角位，全书翻角方向一致）：主色实地直角三角贴角（直角边约 50mm），距斜边 1.5mm 处一条平行 0.5pt 主色细线当「翻痕」——页眉微型折角的全尺寸放大。
- 书名区（左上）：眉题「高中英语 · 语法填空」sans-ui 9.5pt 主色；书名「语法填空专练」sans-ui 特粗 40pt 级墨色；书名下一条 0.5pt 主色坐标线横贯版心，副题（如「真题单句讲练 + 语篇精讲」）8.5pt 墨 75% **骑线**。
- **左下内容块**：两三行 8.5pt 墨灰小字列册内单元与特色（如「01 谓语动词 · 时态 / 语态 / 主谓一致」），给版面第三落点，不抢书名。
- 底部居中：澄页落款 = 微型折角 + 「澄页」sans-ui 9pt 墨 60%。无页码无页眉。

**章扉**（整页，单元分隔）：
- 左上超大单元号（sans-ui 特粗 90pt 级主色）+ 单元名（墨 22pt 级，坐在号的右下基线）——**色只给号**的最大尺度。
- 中部：本单元考点 toc（沿用目录行语法，缩进一档；**行宽收到版心约 60%**，点线不跑全宽）。
- 底部：坐标线 + 折角落款（章扉版折角 3mm 级）。无页眉；占页码不显示页码。

**目录页**：沿用 toc 行语法（主色粗号 + 墨题名 + 30% 墨点线 + 页码），升级为**单元分组**：组头 = 主色实地小方（单元号白字）+ sans-ui 粗单元名，组内行缩进。页顶册名区 = 澄页落款 + 册名 + 坐标线。双栏。

## 1e. 页型：日卡（识记机）

A4 一天一页。版心纵切两半：上半只留题，下半只留钥匙，中缝对折。复用词典组件，只加两条：`fold`、`write`。

```
opener(周扉)  →  unit.day ×n
```

每个 `unit.day` 锁死为**恰好一页**（`break-after: page`，`break-inside: avoid`）。版心按 50 / 中缝 / 50 切，对折线钉在**纸面物理中线**（A4 148.5mm = 天头 16mm + 版心 132.5mm；`.fold` 的 `top` 取 131mm 让虚线视觉中心落在中线），不随题量上下漂。`.face` 高 129mm、`overflow: hidden`，装不下时切掉末条写线，不把题推进钥匙区。

| 槽 | 复用 | 日卡用法 |
|---|---|---|
| 周扉 | `opener` | 超大周号 + 七日 toc；落款写日期范围（单日周只写一天），不写「澄页」书名。不另出独立目录页。单日周 `data-days="1"`：周号仍在上头；日牌居中（「本周 1 天」+ 当天序号 + 日期科目）；落款放大落到下三分之一，不挂折角。第01周可在 toc 下挂裸 `aside` 写用法（三短段，10pt），其他周不挂 |
| 日头 | `topic-head` | `data-no` 当天序号；标题只写完整日期 + 周几，不挂科目 chip |
| 早读 | `stem` | 一只题干框装文1–3 + 理1–2（右下折角仍算本页一处品牌折角）。无 `solution`。条与条之间只靠字阶，不另开盒。化学方程式反应条件走 `rxn-arrow`（上条件 / 下催化剂） |
| 抽测 | `drill` + `drill-atoms` | 旗标写「抽测 · 数物化语+道法/历史」，不用「练一练」。题号悬挂，与科目 chip + 题干同一行；其下一条 `write` |
| 对折 | `fold`（新） | 主色 40% 虚线通栏，中嵌 sans-ui 8pt「对折朝下，写完再看」；左右边框各一条约 4.2mm × 0.75pt 主色短竖骑在虚线上作对纸记号。禁止三角（与页眉订口折角同构）。不计入每页两处折角 |
| 钥匙 | `answer-key` | 白底（黑白打印不铺灰）；文1–3、理1–2 各一行，抽测 1–5 分行。不印卡号。抽测条可挂复用 `note`（大纲 `备注`，只上钥匙） |

纵比：题区与钥匙区各约 50%，中缝不占教学信息。题区装不下时回到结构层减作答线长度，**不缩小字号、不把钥匙挤上半页**。

页眉页脚走澄页坐标线：spec tab 周码，骑线收齐「当天序号 + MM-DD 周X · 诗+理」（文理只在这里出现一次），刊名「东莞2027中考」。色只给号。

## 2. 组件词典

组件外形全书锁死——学生用 200ms 认容器，不靠读标签。新内容不发明新容器。

### 2b. 待迁移组件（旧构造，保留备查）

下表是 2026-08 版构造，**与 01 现行令牌冲突**（如 8pt 文字、灰字、描边框、斜缎带）。所在页型迁移时按 §0 重做，迁移前不得用于新产出的课页。

| schema | 旧组件构造 | 来源基因 |
|---|---|---|
| `tip` | **不得当全章解题总纲用**（2026-08-27 撤）。冠词章曾在目录后放一条 `tip` 概括全章判断顺序，语义不合：ⓘ 图标承诺的是一条随手提示，装的却是纲领，且纲领与各节 `subhead` 讲的是同一件事，读者两处都得读。总纲的位置在各节标题本身，不另设框 | — |
| `explain` 内 `item` | 2026-08-27 新增的**第五级**，用于冒号后「类别名 + 例词」型的三项以上列举（专名带 the 的三类、a + 抽象名词的指事 / 指人）。**1.2mm × 0.4mm 墨色 35% 细横条**前缀 + 类别名 sans-ui 600，正文字号；悬挂缩进 1.5em，例词折行与首行文字对齐而不缩回横条下。形状三级全错开：`subhead` 主色实心方 → `case` 主色圆点 → `item` 墨色细横条 | 由 ClearRevise 字阶再下延一档 |
| `explain` 内 `phrases` | 纯词条清单（无类别可分组、七项以上）不塞进句子，另立一块：左缩进 1.5em，词条间的**中点由 CSS 生成**（`span + span::before`），HTML 只排 `span` 不手写分隔符；每个 `span` 内 `white-space: nowrap`，短语不许在中途折行。已用于 1.4 第六条七个带 the 的短语、1.7 第一条九个带 a/an 的说法、1.3 十四个部位属性名词 | 试题研究词表带 |
| `explain` 内 `case` | 2026-08-27 新增的**第四级**，标讲解内部的并列情形（「一是…二是…三是…」）。墨色 sans-ui 600 + **1.5mm 主色圆点**前缀——比 `subhead` 降一档（那里是主色文字 + 2mm 实心方；方 → 圆、大 → 小，两级形状与尺寸都错开），比正文重一档，三级一眼可分。只在 `explain` 内用；一条 `case` 底下可挂例句行与注解。**不与 `subhead` 混用**：带独立例题、自成小节的用 `subhead`（如冠词 1.4 六条），只在同一条讲解里并列的情形用 `case` | 由 ClearRevise 字阶下延一档 |
| `answer-key` | 答案册单元组头下横排，`--ash` 底细条，sans-ui。「1. C  2. B …」。**不进练习册** | 试题研究速查 |
| `rationale` | 答案册详解节 = **双栏条目流**（栏间 1–1.2em）。每条无底无框：首行 sans-ui 粗题号（主色 9.5pt）+ source 芯片；次行原句 serif-en 9pt（保留空格下划线与提示词）；末行「故填」主色小标 + 粗斜体答案 + 中文一行理由 9pt。条目间 0.5pt 30% 灰细分隔线；条目内部禁断栏（`break-inside: avoid`）。密度目标：满页 ≥10 条/页 | 试题研究答案册（速查密度） |
| `corpus` | `--cream` 底、0.5pt 浅灰边、右下薄影、serif-en 正文、左缘每 5 行 7.5pt 灰行号。**衬线 + 奶油底 = 被分析物**，全书唯一语料容器 | ClearRevise 语料盒 |
| `sample-answer` | 语料盒下半截换 `--sample` 底，答句斜体，赋分 `[1]` 绿… 改用主色 | ClearRevise 示范答 |
| `tip` | 白底 0.75pt 主色描边圆角框；主色圆形图标（0.8em）**骑在框外左上角**；框内文字给图标让位 | ClearRevise 星标骑角 |
| `toc` 行 | 主色粗号 + 墨题名 + 30% 墨点线 + 页码。**色只给号** | 旺文社目录 |
| `fold` | 通栏主色 40% 虚线，中嵌「对折朝下，写完再看」sans-ui 8pt 主色。日卡左右各加约 4.2mm × 0.75pt 主色短竖骑虚线作对纸记号。不是品牌折角，禁止三角 | 令牌「对折自测中缝」第一次落地；Oxford Retrieval 中缝改成上下对折 |
| `write` | 一条 0.5pt 墨 35% 底线。日卡抽测覆写为 **1.4em**（题号与题干同行省下的行高还给写线；装不下先减这条，不缩字号）。只在日卡 `stem` / `drill-atoms` 里用，不当讲解装饰 | 作答空，印刷通例 |
| `toc-group` 作单元内分组头 | 2026-08-25：主色实地小方（`data-no` 写 `the` / `a/an` / `类` / `测`）+ sans-ui 粗组名，**居中**——与左齐的 `topic-head` 分层，不靠加大字号压。正文组头 12pt 切在该组首个 `topic` 前；单元目录内同构但降到 10.5pt，组内行走 `toc-group ol`（单栏、缩进一档、编号取 `li` 的 `data-no`）。答案册的组头不居中，作用域限 `.unit > .toc-group` 与 `.toc .toc-group` | 目录分组组头复用 |

## 3. 断页与流

- **考点从新页起**（课页）。
- `example`（题干 + 解析整体）、`keypoint`、`corpus`、表格：`break-inside: avoid`。例题**一律整体不断页**（2026-08-27 定）；代价是节末偶有约四分之一页留白，可接受，不为凑满版面切例题。
- **施工陷阱**：块内任何子元素上的 `break-after: avoid` 都会沿父级外传。例如在解析最后一段写 `break-after: avoid`，会让相邻两道例题之间也不许断页，两道题只能一起推到次页（2026-11-04 实测）。只用 `break-before: avoid` 把后块拴到前块上。
- `topic-head`、`subhead`、`case`、「练一练」旗标：`break-after: avoid`。标题留在页末、内容翻到次页是排版事故。
- `note`、`solution > aside`：`break-before: avoid`，紧跟目标块。
- 孤行寡行：中文 `orphans / widows: 2`；英文语料块 3。
- 页面尾部留白 > 30% 时，Agent 回到结构层调整（前移 drill 或拆 topic），不缩放字号。

## 4. 密度硬预算（渲染后自查清单）

1. 课页描边框 0；底色块只有要点卡一种；斜元素、投影 0。
2. 同一句指示符 ≤ 2；行间注 ≤ 每两句一条。
3. 一页组件种类 ≤ 7；讲解 / 例题页芯片 ≤ 3（练习页每题一枚题源，不计入）。
4. 块间距只取半格整数倍，任何两个组件不得贴身。
5. 英文语料无音节断行、无两端对齐。
6. 全页唯一色相是 `--accent`（黄族容器色除外）。
6b. 中译对照行与英文行锁齐（对照即对齐，否则只是邻置）。
7. 01 §7 验收指标全部通过（`指标.py`）。

- 参考实现：`渲染/方向稿/基础.css`（令牌、字体、基本版式）+ `主线.css`（课页组件）。`:root` 令牌照抄 01，组件照抄本文件 §2a。改视觉 = 先改 01 / 03，再同步 CSS；禁止只改 CSS。

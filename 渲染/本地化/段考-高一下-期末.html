非谓语

覆盖 6/6 卷，25 道

作状语

分词或不定式作状语；看与主语的关系

分词作状语时，它的逻辑主语就是句子的主语。与主语是主动关系用 -⁠ing，是被动关系用 -⁠ed，如 Compared to the whole universe, the earth seems so small（与整个宇宙相比，地球显得非常渺小）。

句末的 -⁠ing 形式多表示结果或伴随。分词的完成式 having done 表示动作先于谓语发生，如 Having retired from work for several years, he is used to the current leisure life。

Doing …, sb. did … | Having done …, sb. did …

例 12021 东莞市高一下期末句首分词作状语；与主语是被动关系

(compare) to the whole universe, the earth seems so small.

解析

句意：与整个宇宙相比，地球显得非常渺小。

成分：句首空作状语，compare 与主语 the earth 是被动关系，用过去分词 Compared。

故填 Compared。

例 22022 东莞市高一下期末分词作状语改写；与主语是主动关系

When the boy heard the good news of the Chinese team, he jumped out of bed. （⁠用⁠分⁠词⁠作⁠状⁠语⁠改⁠写⁠）

解析

句意：那个男孩听到中国队的好消息，立刻从床上跳了起来。

判断：heard 与主语 the boy 是主动关系，改写成现在分词 Hearing 作状语。

故填Hearing the good news of the Chinese team, the boy jumped out of bed.

作定语

后置修饰名词；主动用 to do，被动用 done

非谓语作定语放在被修饰的名词之后，相当于一个定语从句。名词是动作的承受者用过去分词，如 the lecture organized by our university（⁠由⁠学⁠校⁠组⁠织⁠的⁠讲⁠座⁠）。

序数词、最高级、only、the last 等修饰名词时，后面常接不定式作定语，如 China’s first teacher to give lessons in space。判断时看名词与动作的关系：名词是执行者，用主动形式；名词是承受者，用被动形式。

the first person to do sth. | n. + done

例 32022 东莞市高一下期末后置定语；与名词是被动，用 done

During the Spring Festival, people will wander along the streets (decorate) with red lanterns.

解析

句意：春节期间，人们会沿着挂满红灯笼的街道闲逛。

成分：空格修饰 streets，street 与 decorate 是被动关系，用过去分词作后置定语。

故填 decorated。

例 42023 东莞市高一下期末后置定语；序数词修饰用 to do

In 2013, spacewoman Wang Yaping became China’s first teacher (give) lessons in space.

解析

句意：2013 年，女航天员王亚平成为中国首位在太空授课的教师。

判断：teacher 前有序数词 first，后面的不定式作后置定语，表示授课这一动作。

故填 to give。

作宾补

宾语与宾补是主动；用 doing，被动用 done

keep、see、find 等词后，宾语与宾补之间若是主动关系，宾补用现在分词，如 keep sb. waiting；若是被动关系，宾补用过去分词，如 find the room cleaned up。

判断：看宾语是不是动作的执行者。宾语执行动作，用 doing；宾语承受动作，用 done。

例 52025 东莞市高一下期末宾补用现在分词；宾语主动执行动作

From the window, they saw that children were running happily around the park.
→ From the window, they saw happily around the park. （⁠同⁠义⁠句⁠转⁠换⁠）

解析

句意：他们从窗户望出去，看见孩子们在公园里欢快地奔跑。

判断：see 之后 children 与 run 是主动关系，宾补用现在分词。

故填 children running。

作主语

动名词短语作主语；谓语用单数

动名词短语作主语时，整个短语视作单数，谓语用单数，如 Practicing handwriting is of great significance to the students’ growth。修饰动名词的副词放在短语中间或末尾，不改变这一点。

固定搭配

insist on 后接 doing；tend to 后接动词原形

insist on 表示坚持做某事，on 之后接动名词，如 insist on doing sth.。tend to 后接动词原形，表示倾向于做某事，如 opportunities tend to appear along with challenges。

谓语被动易混

句中唯一的谓语；不用分词

句子中没有其他谓语时，空格就是谓语，要按时态和语态填，不能填分词。主语与动词是被动关系时，用对应时态的被动式，如现在完成时的被动 has been done。

空格修饰名词时，名词是动作的承受者就用 done，是执行者就用 doing 或 to do。空格作状语时，分词的逻辑主语必须是句子的主语。

定语从句

覆盖 6/6 卷，5 道

关系副词

先行词表时间地点；用 when 或 where

先行词是 time、day、place 这类表示时间或地点的名词时，关系词用 when 或 where，并在从句中作时间或地点状语，如 the time when early humans first started using tools。

判断：看从句缺什么成分。缺主语或宾语用 which、that、who；缺时间或地点状语用 when、where。

the time when sb. did | the place where sb. did

例 12023 东莞市高一下期末关系副词 where；先行词表地点

Chinatowns are popular tourist destinations visitors can experience traditional Chinese culture first hand.

解析

句意：唐人街是很受欢迎的旅游目的地，游客可以在那里亲身体验中国传统文化。

成分：先行词 destinations 表地点，从句 visitors can experience 缺地点状语，用 where。

故填 where。

非限制性

先行词后有逗号；关系词不能省

非限制性定语从句与先行词之间有逗号，对先行词作补充说明，关系词不能省略，如 Miss Brown, who teaches music at a university, will give us a lecture next Friday。

先行词指地点或时间时，逗号后用 where 或 when，如 Dongguan has beautiful parks, where families can spend quality time together。

关系副词看先行词：表示时间用 when，表示地点用 where。先行词后有逗号时为非限制性从句，关系词不能省。

覆盖 5/6 卷，5 道

形式宾语

find、make、believe 后；宾语是 it，真宾语在后

find、make、think、believe 等动词后面，宾语位置如果是 it，真正的宾语是后面的不定式或从句。结构是 find / make / believe + it + 形容词 + to do。

判断：动词后紧跟形容词，再接不定式或从句，宾语位置就填 it，如 You will find it rewarding to be a volunteer。

find it adj. to do | make it adj. for sb. to do

例 12022 东莞市高一下期末形式宾语；find it + adj. + to do

句意：你会发现做志愿者是很有收获的。

成分：find 之后的 it 是形式宾语，真正的宾语是后面的不定式 to be a volunteer。

故填 it。

例 22025 东莞市高一下期末形式宾语；make it + adj. + to do

故填 it。

形式主语

句首 it 作形式主语；真主语在句末

句首的 it 作形式主语，真正的主语是句末的不定式或 that 从句。

改写时，把主语从句或动名词短语挪到句末，句首换成 it。动名词主语要改成不定式（to do）放到句末，如 Spending too much time online is unhealthy 可写成 It is unhealthy to spend too much time online。

空格在 find、make、believe 之后，且后面是形容词加 to do 或从句，填 it；句首的 it 是形式主语，真正的主语在句末。

what 引导，缺成分；that 引导，不缺成分

状语从句

覆盖 3/6 卷，5 道

让步原因改写

despite、because 的改写；分词或介词替代从句

Despite、In spite of 表让步，相当于 although。Because 引导的原因从句，若主语与主句一致，可改写成分词短语作原因状语。

改写时要检查从句主语是否与主句主语一致：一致才能把从句改成分词短语，不一致不能简单地省略成分词。

时间条件从句

if 表示条件；just as 表示正当

if 引导的条件状语从句表示真实条件，主句用一般将来时，如 If you take exercise regularly, you will become slimmer than before。

just as 引导时间状语从句，表示“正当……的时候”。

so that 型

目的状语从句；可换成 in order to

so that 引导目的状语从句，从句中常有 can、will 等情态动词。两个主语一致时，可改写成 in order to 或 so as to 加动词原形，如 keep a balanced diet in order to improve his overall health。

so that sb. can do | in order to do

两个小句主语一致时，从句可改成分词或介词短语。if 表示真实条件，just as 表示正当，主语一致时 so that 的同义说法是 in order to 或 so as to。

倒装

覆盖 3/6 卷，3 道

only 句首

only 加状语位于句首；主句要倒装

only 加时间或条件状语位于句首时，主句要部分倒装，助动词或情态动词提前到主语之前，如 Only in this way can sb. succeed。

判断：句首是 only 加状语，主句有助动词或情态动词，就把它提前；主句谓语是实义动词时，借助 did、does 等助动词。

Only when …, did sb. do … | Only in this way can sb. do …

not only 型

not only 置于句首；主句倒装，but also 不倒装

not only 位于句首时，后面主句的助动词或情态动词要提前，如 Not only does the traffic issue affect our daily life, but it also puts people’s lives at risk。but also 之后的分句语序不倒装。

only 与状语位于句首时，主句倒装，助动词或情态动词提前。not only 位于句首同样倒装，but also 之后的分句不倒装。

强调句

覆盖 2/6 卷，2 道

强调句型

It is/was …that/who；去掉后句子仍完整

强调句的结构是 It is/was + 被强调部分 + that/who + 其余部分，其余部分保持原句的语序和时态。被强调的是状语或宾语时只用 that；被强调的是人并且作主语时，that 与 who 都可以。

判断：去掉 It is/was 和 that/who 后，句子仍然完整，就是强调句。

It is/was + 被强调部分 + that/who + 其余部分

去掉 It is/was 和 that 后句子仍完整，就是强调句；被强调的是状语或宾语时用 that，人作主语时 that 与 who 都可以。
